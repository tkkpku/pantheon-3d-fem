## 10. 结论链（供报告）
等厚 19.8° → 变厚度 4° → 加鼓座 14.6° → 加藻井 **74.2°** →
**藻井应力集中 = 裂缝达 ~57° 的最强/唯一致机**；损伤、厚度、鼓座均不是。

## 10.5 C7 最终模型（收官验证，2026-08-17）
- 全结构 = 鼓座+基座+140 方形藻井+变厚度穹顶（直边 SecondOrderLinear 保 0 倒转）
- 网格 `c7_drum_coffer.msh`（587,772 节点 / 389,337 单元），**DOF=1,763,316**，内存 67%（24GB 内安全）
- sw+sh（甲方案穹顶 only 收缩）：u_max=19.659mm，σ1=1.02 MPa，σ3=-1.90，穹顶开裂区 5.67%，**θ_top=74.2°**
- **与「仅藻井穹顶」74.2° 完全一致 → 鼓座/基座/变厚度均不改变裂缝顶端，藻井=唯一致机（方形尖角超 Masi 65.8°，真实圆角应更接近 57°）**

## 11. 本机 DOF 极限实证（8/17 实测，供 HPC 论据）
- dome lc0.55 = 1.83M dof ✅ 顺跑；C6 全结构 lc0.67 ≈ 3.1M dof ❌ OOM（96%+8GB swap）
- C6 全结构 lc0.75 = **2.2M dof ✅ 顺跑**（RSS 21.7GB/88% 无 swap, CPU 104%）
- **本机（24GB）dolfinx 安全上限 ≈ 2.3~2.5M dof**（约 9.9KB/dof）；「500万」远超 ~2 倍 → 需 HPC/≥32GB 机器/MPI
- C6 细网格 sw+sh θ_top=10.6°（粗 14.6°）→ 鼓座模型裂缝顶端稳定 ~10-15°，非 57° 机制
- 结论：500 万 DOF 是超算级需求，本机极限 ~2.5M（此实证作为「8/31 找老师超算中心」核心论据）
