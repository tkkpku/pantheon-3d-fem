# 万神殿裂缝「为何恰好止于 ~57°」研究报告

> 2026-08-17 生成 · 基于当日 FEniCSx/Gmsh 全链模型与 Masi et al. 2018 原文
> 数据出处：`docs/source/pantheon_结果数据存档_2026-08-17.md`；代码 `fem_solver/c4_dome_shrinkage.py` 等

## 1. 结论摘要

1. **裂缝是「子午向、张开型（mode I）、由环向拉应力驱动」的约束干缩裂缝**——下穹环向受拉（干缩被封闭圆环约束 + 自重泊松效应），超过古罗马混凝土极低抗拉强度 $f_t=0.08$ MPa 即开裂。
2. **裂缝止于「环向拉→压转变线」**——这是普适屏障：裂缝无法在环向受压区继续张开。**「恰好 57°」不是常数，而是真实万神殿结构在该应力状态下的环向转压纬度**。
3. **藻井不是裂缝的「原因」，而是「放大器」**：藻井方形尖角的应力集中把「孤立开裂点」抬到 74°（虚高），而**连贯裂缝带**在大收缩下只爬到 ~33°（我们模型）并始终贴着环向转压线（~30-38°）。Masi 全结构模型（更大收缩、施工序列）把转压线推到 47-66°，实测 57° 落其中。
4. **藻井经济性：作者「经济性差」的直觉基本成立**——8.09% 减重（~160-367 t）换来了全环开裂（14-15 条子午向裂缝至 57°）。但三个 nuance：裂缝不致命（壳→拱稳定转换，2000 年无恙）、致裂主因是**尖角几何而非减重本身**（圆角/阶梯藻井可兼得减重与低裂）、真实藻井主因是**装饰**，减重是附带收益。

## 2. 裂缝为何恰好止于 ~57°（机理）

### 2.1 驱动：约束干缩 → 环向受拉 → 子午向裂缝

- 干缩 = 负温度变化（自由应变 $\varepsilon_{sh}I$，$\varepsilon_{sh}\sim10^{-4}$，Masi 2018 文献量级）
- 穹顶是封闭圆环：想沿环向收缩却被自身闭合约束 → **环向拉应力 $\sigma_{\theta\theta}>0$**
- 环向拉力 → **子午向（沿经线）裂缝**（裂纹面垂直于最大主拉应力）
- 古罗马混凝土 $f_t=0.08$ MPa 极弱（Masi Table 1），自重+干缩组合轻易超过

### 2.2 终止：环向拉→压转变线（普适屏障）✅ 数值验证

裂缝在环向受拉区张开；一旦越过**环向转压线**（$\sigma_{\theta\theta}$ 由拉转压的纬度），裂缝无法继续张开，尖端停住。本日三模型六档实测：

| 模型 | ε_sh | 连通裂缝顶端 | 环向转压带 |
| --- | --- | --- | --- |
| 等厚 | 1e-4 | 19.8° | 37° |
| 等厚 | 1.5e-4 | 22.6° | 38° |
| 等厚 | 3e-4 | **33.2°** | 38° |
| 等厚 | **5e-4** | **37.4°** | **38°**（裂缝爬满屏障）|
| 变厚度 | 1e-4 | 4.0° | 30° |
| 变厚度 | **5e-4** | **37.8°** | **41°**（转压带上移）|
| 藻井 | 1e-4 | 2.7° | 31° |
| 藻井 | 3e-4 | **32.9°** | 37° |

**铁律：连通裂缝顶端 < 环向转压带，且随 ε_sh 增大同步爬升**（33.2<38、32.9<37、37.4≈38、37.8<41 等）。**关键：环向转压线本身随收缩量级上移**（变厚度 30°@1e-4 → 41°@5e-4）——收缩越大，环向受拉区越高，裂缝能爬得越高。裂缝顶端 = 「σ1 超 f_t 的最远连贯处」，转压线 = 它的移动上限屏障。

**C7 最终全结构（鼓座+基座+方形藻井+变厚度，1.76M DOF，ε_sh=1e-4）收官**：顶点 74.2°（孤立尖角散点）、**连通带 12.6°**、**环向转压带 30°** —— 连通带 < 转压带 ✓，74.2° 再度证实为孤立尖角散点而非连贯裂缝。

### 2.3 57° 从哪来：真实结构的转压线纬度

| 来源 | 转压线/裂缝顶端 | 说明 |
| --- | --- | --- |
| Flügge 理论（均匀半球，仅自重） | ~52° | 理想值 |
| 我们的简化模型（E=1.0 穹顶，ε_sh=1e-4~5e-4） | 30~41° | 收缩越大转压线越高（变厚度 30→41°）|
| **Masi 2018 全结构模型**（鼓座+基座+施工序列，五档收缩） | **47.4→65.8°**（θ_max）| 大收缩 + 全结构把转压线推高 |
| **Terenzio 1934 实测** | **~57°** | 真实结构的转压线纬度 |

**「恰好 57°」= 真实万神殿在真实收缩/自重状态下的环向转压纬度**。它与 Flügge 的 52° 同源（都是环向转压），偏差来自：变厚度、鼓座/基座约束、施工序列（模板支撑+拆模）、收缩量级（Masi 用到大 3 倍的收缩）。57° 落在 Masi 五档 θ_max=55.89°（第 3 档，ε_v/α=3.97 K）旁边——**文献自己就指出观测裂缝与第 3 档模拟吻合**。

### 2.4 藻井尖角散点 vs 连贯裂缝（口径对齐的澄清）

- **max 单点口径**：藻井模型 74.2°——但这是**孤立尖角奇异点**（每个藻井角一小撮 σ1>f_t 点，互不相连），不是裂缝。
- **连通簇口径**（最大连通开裂/损伤带顶端）：藻井模型 2.7°（ε_sh=1e-4）→ 32.9°（3e-4）——**连贯开裂带始终贴着转压线**。
- 结论：**真实裂缝是连贯的，量级由转压线决定（~57°），不是由尖角散点决定（74° 是判据假象）**。方形藻井尖角只是「把散点撒到 74°」，真实（圆角/阶梯）藻井的连贯裂缝仍止于转压线。

## 3. 裂缝类型 / 核心成因 / 安全风险

### 3.1 类型
- **方向**：子午向（meridional），从穹底（caveae 起拱带）向上沿经线；Terenzio 实测 14 条大裂，Masi 模拟 15 条（方位频率不变，对应穹底 15 个 caveae）
- **模式**：张开型（mode I，垂直于最大拉应力 $\sigma_{\theta\theta}$）
- **阶段**：早期（干缩主导，施工后不久——Terenzio 据砖印推断）

### 3.2 核心成因（按贡献排序）
1. **约束干缩**（主因）：早期混凝土失水收缩被封闭圆环几何约束 → 环向拉应力
2. **极低抗拉强度** $f_t=0.08$ MPa：古罗马轻骨料混凝土受拉极弱（Masi 实测）
3. **自重泊松效应**（次要）：子午压缩 → 环向想变粗 → 被环挡住 → 附加环向张力（文档3 已述）
4. **藻井尖角应力集中**（放大器，非必要条件）：方形藻井 90° 再入角 → 局部 σ1 奇异 → 开裂点散布更高

### 3.3 安全风险
| 风险 | 机制 | 严重度 |
| --- | --- | --- |
| **环箍作用丧失（拱扇化）** | 环向受拉区开裂后，穹顶从「闭合壳」退化为 ~15 个独立子午向「拱扇」，各扇以子午向压力传递（无拉力拱）| ⚠️ 结构行为改变但**稳定**（正是古代混凝土「无拉应力」设计哲学；2000 年未倒）|
| 裂缝开度 → 水侵入 | 雨水沿裂缝进入 → 冻融、碳酸化、钢筋/砖修复层劣化 | ⚠️ 耐久性、维护负担（罗马人多次用砖修补裂缝——Terenzio 记录了古代修复砖印）|
| 尖端应力集中 | 裂缝尖端在后续荷载（地震、徐变、沉降）下可再扩展 | ⚠️ 需监测；未出现灾难性扩展 |
| 推力重分布 | 拱扇化后拱脚推力分布改变（V1.0 有 3.5 MN/拱 数据）→ 鼓座/基础局部超载 | ⚠️ 历史已验证鼓座承担 |
| 整体稳定 | 裂缝不穿越环向受压带（>57°）→ 上部完整壳仍提供环箍 | ✅ 自限性：裂缝止于转压线，**结构自稳** |

**总判定**：裂缝是「壳→拱」的稳定形态转换，不是失稳前兆——这是罗马无筋混凝土穹顶能服役 1900 年的力学本质（Mark & Hutchinson、Masi 的共识）。风险集中在**耐久/维护与超载冗余度**，而非倒塌。

## 4. 藻井经济性评估（减重收益 vs 裂缝风险）

### 4.1 减重账
| 项 | 值 | 出处 |
| --- | --- | --- |
| V1.0 模型减重比 | **8.09%**（Simpson 积分+棱台公式）| 参数溯源表 / 科研日志 |
| V1.0 模型穹顶重 | 1987.8 t → 减重 ~160.8 t | 中继文档 8/10 |
| 真实穹顶质量 | ~4535 t → 8.09% ≈ **367 t** | leaudioguide（⚠️ 待测绘核实）|
| 按本模型几何核算 | 140 藻井挖除 ~340 m³ ≈ 460-540 t（8~12%，盒近似偏深）| 本日核算 |

### 4.2 收益（减重的安全价值）
- 自重↓8% → 子午压应力 σ3↓、拱脚推力↓（V1.0: 3.5 MN/拱）、鼓座/地基减负、材料省
- 对受压主导的穹顶，8% 减重直接翻译为 ~8% 的压应力裕度提升（抗压 5 MPa 裕度本就富余）

### 4.3 代价（裂缝风险）
- **连贯裂缝**：从无藻井的「~4-19° 局部」扩大到「至转压线 33-57° 的全环开裂」（14-15 条）
- **散点奇异**：方形尖角把开裂点散布到 74°
- 代价折算：耐久/维护成本、水侵入、超载冗余度损失、历史多次砖修补

### 4.4 综合判定（作者直觉「经济性差」——基本成立，三处 nuance）
**如果藻井只为减重：经济性确实差**——8% 减重换全环开裂，结构性价不对等。

**但必须说清三件事**：
1. **裂缝不致命**：壳→拱转换是稳定形态，穹顶因此存活 1900 年——「开裂」不等于「不安全」，只是耐久/冗余代价
2. **致裂主因是尖角几何，不是减重本身**：减重 8% 不必然致裂；**圆角/阶梯藻井**（真实罗马藻井带倒梯斜面+四级阶梯）可在相近减重下大幅降低应力集中——**「减重」与「致裂」可以解耦**。我们的方形盒近似是高估了裂缝风险的
3. **真实动机是装饰**：罗马藻井（caisson）首先是为穹顶内表面视觉（图案+轻量感）而设，减重是附带收益——以装饰为目的，8% 附带减重不算亏

**量化结论**：若以「每吨减重的裂缝代价」衡量，方形藻井 ≈ 367 t 减重 / 全环开裂，性价比差；圆角/阶梯藻井可将该比值改善一个量级。**建议**：报告与后续建模采用阶梯藻井（COFFER_STEPS 已有数据）复核——它才是罗马原物，也才配得上经济性评价。

## 5. 开放问题与下一步
1. **阶梯藻井复核**：COFFER_STEPS 四级阶梯的真实几何（非盒近似）→ 减重不变、奇异下降 → 验证「致裂可解耦」
2. **断裂能判据**（C4+ 升级：指数软化 + G_f=5 J/m² 正则化）→ 让裂缝按能量演化，直接输出连贯裂缝形态
3. **转压线全结构验证**：C7 最终模型（1.76M）的连通带+转压带收官数据（本日已跑）
4. **57° 定量复现**：用 Masi 五档收缩范围（ε_v/α 3.4~4.55 K）在 C7 上扫，看连通带顶端是否落进 47-66°（若命中 57° 附近即闭环）
