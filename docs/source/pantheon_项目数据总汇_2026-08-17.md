**核心科学结论**（详见研究报告）：
1. 裂缝=约束干缩驱动的子午向 mode I 开裂，止于**环向拉→压转变线**
2. **57° = 真实结构环向转压纬度**（随收缩量级上移；Flügge 52° 为自重均匀理想值）
3. 藻井尖角产生**孤立奇异散点**（74° 虚高），连贯裂缝带贴转压线（~33-41°）
4. 藻井经济性：8.09% 减重（~160-367t）换全环开裂，**性价比差（作者直觉成立）**，但致裂主因是尖角几何（圆角/阶梯可解耦）、裂缝不致命（壳→拱稳定）

## 7. 可继续挖掘 / 深化 / 普适化方向

**深化（同一问题做透）**：
1. **阶梯藻井复核**：COFFER_STEPS 四级阶梯真实几何（非盒近似）→ 减重不变、奇异下降 → 验证「减重与致裂可解耦」
2. **断裂能本构**：C4+ 升级（指数软化 + G_f=5 J/m² 正则化）→ 输出真实连贯裂缝形态与开度
3. **57° 定量复现**：用 Masi 五档收缩在 C7 上扫描，看连通带顶端是否落进 47-66°（命中 57° 即闭环）

**拓展（新问题）**：
4. **28 对称 vs 全模型**：1/28 切片若能解（换 dolfinx 版本/MPI），把裂缝形态与 Masi Fig.6 逐条对比（裂缝条数 14-15、方位频率）
5. **鼓座壁龛/门廊效应**：初步判断影响较小，可做一个对照算例量化「裂缝起始点 = caveae」假说
6. **施工序列全模拟**：Masi 的模板支撑+拆模分阶段——把「早期干缩+自重」时序化，看裂缝是否在拆模前就形成（Terenzio 的「早期裂缝」判断）
7. **徐变/长期**：干缩+徐变耦合的长期裂缝发展 vs 短期（Masi 用 ε_v 覆盖长期量级）

**普适化（结论推广）**：
8. **无筋混凝土薄壳的通用判据**：「裂缝止于环向转压线」对任何无筋混凝土穹顶（万神殿、圣彼得、圣索菲亚等）可做无量纲化：转压纬度 = f(几何比, 收缩量, 约束) → 提出**通用设计图/经验公式**，供古建评估与当代无筋壳体设计
9. **壳体减重与开裂的帕累托前沿**：把藻井「减重比×裂缝顶端」做成设计空间图（圆角半径/阶梯数/深度为轴）→ 「减重-开裂」权衡的普适结论
10. **方法学输出**：把「FEM + 文献参数标定 + 假说检验 + 口径对齐（连通簇/转压线）」这套流程写成可复用的**古建力学分析模板**（项目已积累 P-01~P-12 教材坑、AI-Leader 工作流）
