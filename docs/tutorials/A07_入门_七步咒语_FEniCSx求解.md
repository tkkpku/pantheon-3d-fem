## 第 1 节 七步咒语总览

```python
# ① 读网格
domain, cell_tags, facet_tags = gmshio.read_from_msh(str(msh_path), MPI.COMM_WORLD, gdim=3)

# ② 定义函数空间（未知数住在哪）
V = fem.functionspace(domain, ("Lagrange", 2, (3,)))

# ③ 贴边界条件（钉死拱脚）
base_facets = facet_tags.find(400)
dofs = fem.locate_dofs_topological(V, 2, base_facets)
bc = fem.dirichletbc(fem.Constant(domain, (0.0,0.0,0.0)), dofs, V)

# ④ 材料脾气
E = fem.Constant(domain, 14.8e9); nu = fem.Constant(domain, 0.2)
lam = E*nu/((1+nu)*(1-2*nu)); mu = E/(2*(1+nu))

# ⑤ 弱形式（K u = f 的积分版）
a = ufl.inner(lam*ufl.tr(epsilon(u))*I + 2*mu*epsilon(u), epsilon(v)) * ufl.dx   # 左端 K
L = ufl.dot(b, v) * ufl.dx                                                       # 右端 f（自重）

# ⑥ 求解
problem = petsc.LinearProblem(a, L, bcs=[bc], petsc_options={"ksp_type":"cg",...})
uh = problem.solve()

# ⑦ 后处理（位移→应力→统计）
```

**七步各管一件事**：读→住→钉→脾气→方程→解→用。**和 Gmsh 六步骨架一样，背下来是所有求解器的容器。**

## 第 2 节 逐行翻译（新手最容易晕的四行）

**② `fem.functionspace(domain, ("Lagrange", 2, (3,)))`** ——这行在说三件事：

- `"Lagrange"`：用「拉格朗日插值」猜角点之间的值（第 4 课的插值思想）；
- `2`：二阶——每条边上多一个中点，猜得更准（万神殿锁定的 CG2 单元）；
- `(3,)`：每个节点有 3 个未知数（x/y/z 三个方向的位移）。

翻译成人话：**「我要一个空间，里面每个点装着 3 个位移数，用二阶曲线猜点与点之间的值。」**

**③ `facet_tags.find(400)`** ——找「编号 400 的面」（第 5 课贴的拱脚标签）。`locate_dofs_topological` 找出这个面上的全部未知数编号，`dirichletbc` 把它们全部钉成 0。**「钉死」在数学上=「把这些未知数从方程组里删掉」**（第 4 课讲过）。

**④ Lamé 常数** ——材料脾气的换算：

$$\lambda = \frac{E\nu}{(1+\nu)(1-2\nu)}, \qquad \mu = \frac{E}{2(1+\nu)}$$

你不需要记公式，只需记住：**E 和 ν（脾气）→ λ 和 μ（写方程用的形式）**，两步换算而已。

**⑤ 弱形式两行** ——对照第 4 课：

- `a` 那行 = 左端刚度矩阵 K 的积分版（`ufl.inner(应力, 应变)` = 「应力×虚应变的内功」，`ufl.dx` = 在整个体积上积分）；
- `L` 那行 = 右端力向量 f（`ufl.dot(b, v)` = 自重做的功）。

**`u` 和 `v` 是什么**：u 是「待求的位移」（试函数），v 是「测试函数」——第 0 课的「勺子」。**写弱形式就是写「让 u 变化一点点（v），能量怎么变」**——v 是那个「一点点」。

▢ **你试试 2**：找到 `fem_solver/c1_dome_selfweight.py`，把七步各自对应到代码行号。找不全？对照本节行号注释——**这一步「找到七步」本身就是要练的能力。**

⚠️ **新手常犯**：把 ⑤ 的 `ufl.dx`（体积积分）和 `ufl.ds`（面积分）搞混。**口诀：dx = 身体里（体积），ds = 皮肤上（表面）。** 罚函数、接触那些都发生在「皮肤上」。

## 第 3 节 求解器背后的战争：直接法 vs 迭代法

第 ⑥ 步里藏着一个选择（万神殿 8/16 的关键战役）：

```python
petsc_options={"ksp_type": "cg", "pc_type": "hypre", "pc_hypre_type": "boomeramg"}
```

**直接法（默认）**：像解二元一次方程的「代入消元」——一步到位，但要记住所有中间步骤。**矩阵越大，记忆爆掉**（97 万 DOF 时内存爆炸）。

**迭代法（cg+BoomerAMG）**：像「爬山」——先朝大致方向走一步，看看离山顶近没近，再修正方向，反复走到山顶。**不记中间步骤，省内存，但要「走很多步」**（实测 22 次迭代收敛）。

**BoomerAMG 的白话**：爬山前先看一张**模糊的地图**（把问题在粗化版本上先解一遍），再拿细地图走小路。**先看地图再走小路 = 快很多。**

**选型铁律（万神殿实战）**：小模型（几万 DOF）直接法省心；大模型（几十万起）必须迭代法——**「先摸清武器库再选武器」**（项目调研过 matrix-free/低秩/ROM 全谱系，最后选最成熟的 cg+amg）。

## 第 4 节 从位移到应力：后处理三件套

解出位移只是开始。真正要回答「会不会裂」还要三步：

**① 位移统计**：

```python
u_mag = np.sqrt(np.sum(uh.x.array.reshape(-1,3)**2, axis=1))  # 每个节点的位移长度
u_max_mm = u_mag.max() * 1000.0                                # 最大位移（毫米）
```

`uh.x.array` 是解向量（每个节点 3 个数排成一行）。**reshape(-1,3) 后每行求长度**——0.84 毫米就是这么来的。

**② 应力投影**（教材坑 P-05 的正确姿势）：

```python
S = fem.functionspace(domain, ("Lagrange", 1, (3,3)))   # 应力空间：3×3 张量
sigma_h = fem.Function(S)
X = S.element.interpolation_points()                     # 求值点坐标
sigma_h.interpolate(fem.Expression(sigma(uh), X))        # 位移→应力
```

**为什么应力空间是 1 阶而位移是 2 阶**：应力 = 位移的「导数」——求一次导降一阶。**数学上的微分层级，代码里的空间阶数。**

**③ 主应力判据**：

```python
principal = np.linalg.eigvalsh(sigma_nodes)   # 3×3 应力矩阵的特征值（升序）
s1_max = principal[:,-1].max()/1e6            # σ1：最大主应力（拉）
s3_min = principal[:,0].min()/1e6             # σ3：最小主应力（压）
```

**主应力白话**：应力张量（3×3 矩阵）旋转到某个「最舒服的角度」会变成对角阵，对角上三个数就是主应力。**σ1 管开裂（>0.08 MPa 危险），σ3 管压碎（<-5 MPa 危险）**——「特征值」三个字背后就是这个旋转。

▢ **你试试 4**：为什么 `eigvalsh` 返回的「最后一列」是 σ1、「第一列」是 σ3？（提示：升序排列——最小的在前。再想想：最小主应力=最压，压是负号。）

⚠️ **新手常犯**：把应力单位搞混。代码里全是 Pa，输出换算成 MPa 要除 1e6。**量级检查**（第 3 课增补）：位移毫米级、应力 MPa 级——差 1000 倍就是单位错了。

## 第 5 节 一次真实的「看起来对、实际错」（教材坑 P-07 三连）

8/17 干缩求解器一天内连续三次「结果看起来合理但错了」——这是本课最有价值的病历：

| 坑 | 症状 | 真凶 | 破案方法 |
| --- | --- | --- | --- |
| P-07a 符号反 | 应力全体抬升 0.18 MPa | 干缩项正负号写反（热膨胀是减号，干缩是加号） | **一维自检**：两端固支杆 → σ=E·ε_sh 受拉为正——符号错了自检立刻不对 |

## 第 8 节 第一步的完整解剖：读网格（gmshio.read_from_msh）

第 2 节给了第一步一行代码，这里拆开揉碎：

```python
domain, cell_tags, facet_tags = gmshio.read_from_msh(
```

**三个返回值的身份**（全部来自第 5 课合同）：

**MPI.COMM_WORLD 的白话**：并行计算里所有进程的「总对讲机」——单进程时它就是「唯一的进程」；多进程时它是「全体会议」。**现在用单进程（COMM_WORLD=自己），代码却保持 MPI 兼容**——这是为了将来上超算不用改代码（万神殿的 500 万 DOF 计划就是为 MPI 留的口子）。

## 第 9 节 第二步的完整解剖：函数空间（未知数的家）

```python
V = fem.functionspace(domain, ("Lagrange", 2, (3,)))
```

**三个参数三个含义**（第 2 节的展开版）：

| 参数 | 含义 | 万神殿选择 | 为什么 |
| --- | --- | --- | --- |
| "Lagrange" | 插值族（形函数类型） | Lagrange | 节点插值，最通用 |
| 2 | 阶数 | 2 | 二阶 CG2（总纲锁定，第 4 课第 17 节） |
| (3,) | 形状（分量数） | 3 | 位移矢量 u=(ux,uy,uz) |

**形状参数的花样**（老教材 §3.1 家族）：
- `()` 或省略 → 标量空间（温度、压力、损伤场 D）；
- `(3,)` → 矢量空间（位移 u）；
- `(3,3)` → 张量空间（应力 σ，第 6 节见过）。

**函数空间的本质**：**「未知数住在哪、用什么姿势猜」的声明**。声明之后，FEniCSx 为每个自由度分配编号（dofmap）——**自由度编号就是第 4 课「门牌号」的软件实现**。

**第二个关键空间**（第 6 节预告过，这里正式亮相）：

```python
S = fem.functionspace(domain, ("Lagrange", 1, (3,3)))   # 应力投影空间
```

**为什么应力空间是 1 阶**：应力 = 位移的导数——P2 位移求导后是 P1 应力。**「求一次导，降一阶」**——微积分在有限元空间上的直接投影。

⚠️ **新手常犯**：把空间当「网格」——**空间是「网格+插值规则」的组合**。同一网格可以声明无数个空间（P1 标量、P2 矢量、P1 张量……），它们共享节点但各有各的自由度编号。

## 第 10 节 第三步的完整解剖：边界条件三行背后的全部

```python
base_facets = facet_tags.find(400)                       # ① 找面
dofs = fem.locate_dofs_topological(V, 2, base_facets)    # ② 找自由度
bc = fem.dirichletbc(fem.Constant(domain, (0.0,0.0,0.0)), dofs, V)   # ③ 钉死
```

**① find(400)**：从 facet_tags 里筛出「标签 400」的所有单元（面）——**第 5 课贴的合同在这里兑现**。返回的是「面的编号数组」。

**② locate_dofs_topological(V, 2, facets)**：找「这些面上」的「V 空间」的全部自由度——**参数 2 是「实体维度=面」**（0 点/1 线/2 面/3 体）。这就是「钉死哪个区域的哪些未知数」的完整表达。

**③ dirichletbc 的三要素**：值（(0,0,0) 钉成零）、位置（dofs）、空间（V）。**Dirichlet 边界条件 = 强制位移**——固支就是「强制位移=0」。

**「钉死」在数学上的动作**（第 4 课第 12 节的回响）：dolfinx 内部用「删行删列」或其等价实现——**被钉的自由度从方程组消失，变成了已知数**。

**边界条件的完整谱系**（老教材 §4 家族）：
- **Dirichlet（强制位移）**：钉死位移值——拱脚固支（本行）；
- **Neumann（强制面力）**：皮肤上加力——没在万神殿用（自重是体力不是面力）；
- **Robin（弹簧边界）**：皮肤上加弹簧——罚函数对称约束的近亲（第 31 节）；
- **对称约束**：u·n=0——法向钉死、切向自由（第 31 节 C5）。

**fail fast 检查**（万神殿每求解器必备，第 3 课规矩的求解版）：

```python
if base_facets.size == 0:
    raise RuntimeError("find(400) 为空：物理组没贴好，回 geometry/minimal_dome_demo.py 检查")
```

**「什么错了 + 去哪修」**——万神殿最有价值的报错信息之一。删掉这三行，错误会变成几小时后莫名其妙的矩阵奇异。

## 第 11 节 第四步的完整解剖：材料脾气与三个中间量

```python
E = fem.Constant(domain, 14.8e9)     # 弹性模量：全场一个数的「常量」
nu = fem.Constant(domain, 0.2)       # 泊松比
lam = E*nu/((1+nu)*(1-2*nu))         # Lamé 第一常数
mu = E/(2*(1+nu))                    # Lamé 第二常数（=剪切模量）
```

**fem.Constant 是什么**：一个「全场恒定的数」的 UFL 包装——**写进弱形式之前，所有数都要有 UFL 身份**（普通 Python 数进不了 UFL 表达式）。第 4 课第 19 节的脾气家族，到这里变成代码。

**两个 Lamé 常数的换算检查**（第 4 课第 19 节练习的答案）：
- E=14.8e9、ν=0.2 → λ = 14.8e9×0.2/(1.2×0.6) = 4.11e9、μ = 14.8e9/2.4 = 6.17e9；
- **物理含义各一**：μ=剪切模量（抗搓动）、λ 是「体积与剪切耦合」的中间量（单独无直觉，成对出现）。

**为什么不用 E、ν 直接写本构**：数学上可以（本构有 E-ν 形式），但 **λ-μ 形式最简洁**（σ=λtr(ε)I+2με 一行写完）——**「脾气参数」与「公式参数」分开**，是材料建模的通行做法。

**脾气场的升级版**（第 4 课第 37 节的代码实体化，c6 用）：

```python
E_field = fem.Function(W)             # E 从「常量」变成「场」
def fill(x):
    z = x[2]
    E = np.where(z > 0.0, E_SHRINKAGE, 0.0)     # 穹顶 1.0 GPa
    E = np.where((z <= 0.0) & (z > -H_DRUM), E_WALL, E)   # 鼓座 7.0
    E = np.where(z <= -H_DRUM, E_FOUNDATION, E)           # 基座 13.5
    return E
E_field.interpolate(lambda x: fill(x))
```

**Constant → Function 的升级链**：全场一个数（Constant）→ 随位置变化（Function+interpolate）——**「脾气」从常量升级成场的完整路径**（第 4 课第 37 节的理论在这落地）。

## 第 12 节 第五步的完整解剖：弱形式两行的逐词解读

```python
u = ufl.TrialFunction(V)     # 试函数：待求的位移
v = ufl.TestFunction(V)      # 测试函数：第 0 课的「勺子」

def epsilon(w): return ufl.sym(ufl.grad(w))
def sigma(w):   return lam*ufl.tr(epsilon(w))*ufl.Identity(3) + 2*mu*epsilon(w)

a = ufl.inner(sigma(u), epsilon(v)) * ufl.dx    # 左端（刚度）
L = ufl.dot(b, v) * ufl.dx                       # 右端（荷载）
```

**逐词翻译表**（第 2 节的升级版）：

| 代码 | 数学 | 白话 |
| --- | --- | --- |
| `ufl.TrialFunction(V)` | u | 待求的位移场 |
| `ufl.TestFunction(V)` | v | 勺子（每个点上的权重） |
| `ufl.grad(w)` | ∇w | 位移的梯度（3×3） |
| `ufl.sym(...)` | ½(∇w+∇wᵀ) | 对称化——剔除旋转，只剩变形 |
| `ufl.tr(...)` | 迹 | 体积应变（对角线之和） |
| `ufl.Identity(3)` | I | 单位张量 |
| `ufl.inner(A, B)` | A:B | 双点积（「应力做功」） |
| `ufl.dx` | dV | 体积积分微元 |
| `ufl.dot(b, v)` | b·v | 体力做的功 |

**两行的物理朗读**：
- `a` = 「在整个身体里，应力对『一点点位移』做的内功」——**身体抵抗变形的全部倔强**；
- `L` = 「在整个身体里，重力对『一点点位移』做的外功」——**外部想把身体拉下去的全部力气**。

**左=右** 就是「内功=外功」——虚功原理。**万神殿六个求解器，全部是这两行的变奏**（c4 右端加干缩项、c4plus 的 lam/mu 换成场、c5 左端加罚函数）。

## 第 13 节 最小可运行求解器：C1 的完整讲解版

把七步拼成完整可跑代码（c1 求解器的教学版，逐块注释）：

```python
import sys
from pathlib import Path
import numpy as np
from mpi4py import MPI
sys.path.insert(0, str(Path(__file__).resolve().parent.parent))
from config.params import NU_CONCRETE, DENSITY_STEPS, G, MESH_DIR, RESULT_DIR

from dolfinx import fem
from dolfinx.fem import petsc
from dolfinx.io import gmshio, VTXWriter
import ufl

# ===== ① 读网格 =====
domain, cell_tags, facet_tags = gmshio.read_from_msh(
    str(MESH_DIR / "c0_shell_groups.msh"), MPI.COMM_WORLD, gdim=3)
print("体物理组:", np.unique(cell_tags.values), " 面物理组:", np.unique(facet_tags.values))

# ===== ② 函数空间 =====
V = fem.functionspace(domain, ("Lagrange", 2, (3,)))

# ===== ③ 边界条件：拱脚固支 =====
base_facets = facet_tags.find(400)
if base_facets.size == 0:
    raise RuntimeError("find(400) 为空：回 geometry/minimal_dome_demo.py 检查")
dofs = fem.locate_dofs_topological(V, 2, base_facets)
bc = fem.dirichletbc(fem.Constant(domain, (0.0, 0.0, 0.0)), dofs, V)

# ===== ④ 材料脾气 =====
E = fem.Constant(domain, 14.8e9); nu = fem.Constant(domain, NU_CONCRETE)
lam = E*nu/((1+nu)*(1-2*nu)); mu = E/(2*(1+nu))
g = fem.Constant(domain, G)
rho = fem.Constant(domain, DENSITY_STEPS[-1][1])   # 单层 1600（C1 简化）
b = ufl.as_vector([0.0, 0.0, -rho*g])              # 自重：z 负方向

# ===== ⑤ 弱形式 =====
u = ufl.TrialFunction(V); v = ufl.TestFunction(V)
def epsilon(w): return ufl.sym(ufl.grad(w))
def sigma(w):   return lam*ufl.tr(epsilon(w))*ufl.Identity(3) + 2*mu*epsilon(w)
a = ufl.inner(sigma(u), epsilon(v)) * ufl.dx
L = ufl.dot(b, v) * ufl.dx

# ===== ⑥ 求解 =====
problem = petsc.LinearProblem(a, L, bcs=[bc],
    petsc_options={"ksp_type": "cg", "pc_type": "hypre",
                   "pc_hypre_type": "boomeramg", "ksp_rtol": 1e-8})
uh = problem.solve()

# ===== ⑦ 后处理 =====
u_mag = np.sqrt(np.sum(uh.x.array.reshape(-1,3)**2, axis=1))
print("最大位移 =", u_mag.max()*1000.0, "mm")   # 期待 ≈0.838 mm
```

```bash
# 期待输出：最大位移 = 0.8380 mm，σ1 = 0.0666 MPa，σ3 = -0.7991 MPa
```

**三个「对答案」的瞬间**：① 位移是毫米级（量级检查）；② 0.838 与教材数据一致（对照检查）；③ 最大位移在穹顶顶部（位置检查）——**三查全过，你的第一个 FEM 求解就成功了。**

## 第 15 节 UFL 完整语法课：写弱形式的全部词汇

第 12 节的逐词表是「常用词」。这里是**完整词典**（老教材第 6 章 + 万神殿实测）：

**代数运算**：`+ - * /`（逐元素）——`lam*tr(eps)` 就是常数乘张量。

**微分算子**：
| 代码 | 数学 | 用途 |
| --- | --- | --- |
| `ufl.grad(f)` | ∇f | 梯度（标量→矢量；矢量→张量） |
| `ufl.div(f)` | ∇·f | 散度（干缩项的灵魂） |
| `ufl.sym(A)` | ½(A+Aᵀ) | 对称化（几何方程） |
| `ufl.curl(f)` | ∇×f | 旋度（电磁/流体用，本项目没用） |

**代数/张量运算**：
| 代码 | 数学 | 用途 |
| --- | --- | --- |
| `ufl.dot(a, b)` | a·b | 点积（矢量；矢量·张量） |
| `ufl.inner(A, B)` | A:B | 双点积（应力做功） |
| `ufl.tr(A)` | tr(A) | 迹（体积应变） |
| `ufl.det(A)` / `ufl.inv(A)` | det / A⁻¹ | 行列式/逆（大变形用，本项目没用） |
| `ufl.Identity(3)` | I | 单位张量 |

**积分微元**：
| 代码 | 积分域 | 白话 |
| --- | --- | --- |
| `ufl.dx` | 体积 | 身体里 |
| `ufl.ds` | 外表面 | 皮肤上 |
| `ufl.dS` | 内部面 | 器官之间的膜（界面/接触） |

**条件与逻辑**（第 2 节 P-04 的坑位）：`ufl.conditional(cond, a, b)`、`ufl.ge/le/gt/lt`——**dolfinx 0.8 里对 numpy 数组报错**，万神殿全部用 callable+np.where 替代。

**函数与常数**：
| 代码 | 身份 | 何时用 |
| --- | --- | --- |
| `fem.Constant(domain, 值)` | 全场一个数 | 单个 E、ν、g |
| `fem.Function(V)` | 一个场 | 分区 E(x)、rho(x)、损伤 D(x) |
| `ufl.TrialFunction/TestFunction` | 未知数/勺子 | 弱形式两端 |

**把「场」带进 UFL 的黄金法则**：场（Function）可以直接参与 UFL 运算（`lam_of(E_field)` 返回 UFL 表达式）——**「常量能做的，场都能做」**。c3/c4plus 的损伤模量场、c6 的分区脾气场全靠这条。

## 第 16 节 密度分层与 callable 插值：场的三种写法

万神殿密度从「单层常数」到「四层阶梯」的实现史，是「场」的三种写法的完整课：

**写法一：全场常数（C1 最简）**

```python
rho = fem.Constant(domain, 1600.0)
b = ufl.as_vector([0.0, 0.0, -rho*g])
```

**写法二：callable 插值（C2 分层，项目标准姿势）**

```python
W_rho = fem.functionspace(domain, ("Lagrange", 1))
rho = fem.Function(W_rho)
def rho_fill(x):                          # x: (3,N) 坐标数组，每列一个点
    return np.where(x[2] >= 0.0, 1350.0, 1600.0)
rho.interpolate(rho_fill)
```

**写法三：表达式（万神殿绕开的坑，P-02/P-04）**

```python
x = ufl.SpatialCoordinate(domain)
rho_expr = ufl.conditional(ufl.ge(x[2], 0.0), 1600.0, 1350.0)   # 0.8 里对数组报错
```

**三种写法的取舍**：
- 写法一：最简单，只适合全场均匀；
- 写法二：**最稳**——Python 函数 + np.where，跨版本兼容（P-04 教训后的统一姿势）；
- 写法三：最「UFL 原生」，但 dolfinx 0.8 的 conditional 对 numpy 数组有坑。

**interpolate 传入的 x 是什么形状**：`(3, N)`——**3 行 = x/y/z 坐标，N 列 = N 个求值点**。所以 `x[2]` 是「所有点的 z 坐标数组」。**「行=分量、列=点」的布局约定**（与 P-07b 的坐标布局坑同源）。

**P-02 的完整故事**（老教材 §7.3 的方向坑）：教材原文 `conditional(ge(z,0), 1600, 1350)` + 注释「z>=0 下半部 1600」——**z≥0 数学上是上半部**，代码行为 = 上重下轻，与 Masi「上轻下重」矛盾。万神殿用 tools/verify_p02_density.py 实测坐实（卷七）——**「怀疑教材 → 写脚本实测 → 落判决书」是本项目最值得抄的学习习惯。**

## 第 17 节 载荷三件套：体力、面力、特征应变

万神殿用过的三种载荷，全部进法：

**载荷一：体力（自重）——项目主载荷**

```python
b = ufl.as_vector([0.0, 0.0, -rho*g])     # 每立方米的重量，方向 -z
L = ufl.dot(b, v) * ufl.dx                # 在体积上积分
```

**「分摊」是自动的**：弱形式的体积积分自动把「每个积分点的自重」加权到自由度——**不需要手动把单元重量分给角点**（第 4 课第 13 节的手动分摊，UFL 一行代劳）。

**载荷二：面力（皮肤上的压力）——本项目没用但必备**

```python
t = fem.Constant(domain, (0.0, 0.0, -1e5))    # 表面压强 100kPa 向下
L += ufl.dot(t, v) * ufl.ds                    # 在皮肤上积分
```

**载荷三：特征应变（干缩/温度）——c4 的灵魂**

第 4 课第 18 节的完整推导，代码化为：

```python
eps_sh = fem.Constant(domain, 6.0e-5)         # 干缩应变（恒为正，收缩）
I3 = ufl.Identity(3)
# 右端：自重（可选）+ 干缩等效荷载
L = (ufl.dot(b, v) - eps_sh*(3*lam+2*mu)*ufl.div(v)) * ufl.dx
```

**干缩项的逐符号朗读**：`-eps_sh*(3λ+2μ)*div(v)`——
- `eps_sh`：收缩量（自由应变的大小）；
- `(3λ+2μ)`：体积模量 ×3（把体积应变换成应力的换算）；
- `div(v)`：测试函数的散度——**「勺子搅动的体积变化」**；
- 负号：从右端荷载扣掉——**「收缩产生的内力，等效于一个反向的体积荷载」**。

**为什么干缩「想缩」会变成「被拉」**（第 4 课 P-07 的物理，重温一次）：穹顶闭环，收缩被自己挡住 → 挡不住的部分变成弹性变形（被拉）→ 拉应力 σ=E·ε_sh。**代码里那个负号，就是「收缩=负的膨胀」的记账。**

## 第 18 节 干缩求解器完整案例：c4 的三档设计

c4（dome_shrinkage）是万神殿求解器家族中最有教学价值的一个——**三档荷载 + 口径三件套 + 符号自检**，全在一个文件里。逐层讲解：

**第一层：三档荷载（归因分析的标准设计）**

```python
if load == "sw":     L = ufl.dot(b, v) * ufl.dx                                # 纯自重
elif load == "sh":   L = -eps_sh*(3*lam+2*mu)*ufl.div(v) * ufl.dx             # 纯干缩
else:                L = (ufl.dot(b, v) - eps_sh*(3*lam+2*mu)*ufl.div(v)) * ufl.dx  # 组合
```

**为什么拆三档**：sw = C2 复刻（sanity check：应复现 0.7071mm）；sh = 归因（干缩单独贡献多少）；sw+sh = 主算。**「拆开跑一遍，再合起来跑一遍」——线弹性叠加原理的工程化**（文件头 L22 的自检：u(sw+sh)=u(sw)+u(sh) 场级精确成立）。

**第二层：后处理口径配对（P-07c 的修复）**

```python
def sigma_el(w):   return lam*ufl.tr(epsilon(w))*I3 + 2*mu*epsilon(w)       # 不含干缩
def sigma_full(w):
    eps_mech = epsilon(w) + eps_sh*I3        # 含干缩的力学应变（+号！）
    return lam*ufl.tr(eps_mech)*I3 + 2*mu*eps_mech
sigma_post = sigma_el if load == "sw" else sigma_full   # 口径随荷载切换
```

**为什么 sw 档必须用 sigma_el**：sw 档的荷载里没有干缩，如果后处理用 sigma_full，等于**把干缩应力白加进纯自重结果**——8/17 首跑 σ1 假性跳 0.0562→0.36 的元凶。**「前处理荷载与后处理应力必须配对」——P-07c 的一课价值千金。**

**第三层：符号自检（文件头的一维验证）**
「两端固支杆 → u=0，σ = E(0+ε_sh) = +E·ε_sh（受拉）✓」——**推导完立刻退化验证**（第 4 课军规）。c4 文件头把推导+自检+量级（E·ε_sh=182kPa 与 V1.0 一致）全部写成文档字符串——**「代码即论文」的示范**。

## 第 23 节 解向量解剖：uh.x.array 的每一字节

第 6 节的 `uh.x.array` 展开成完整解剖课：

**uh 是什么**：dolfinx 的 Function——**「自由度编号 → 数值」的映射表**。uh.x 是 PETSc 向量（底层存储），uh.x.array 是它的 numpy 视图（**零拷贝**——改 array 就是改解）。

**布局铁律**（P-07b 教训的核心）：

```python
uh.x.array.reshape(-1, 3)    # 每 3 个连续元素 = 一个节点的 (ux, uy, uz)
```

**「块布局」**：矢量空间（3 分量）的解向量按「节点 1 的 3 分量、节点 2 的 3 分量……」连续排列。**reshape(-1,3) 的前提就是知道这个布局**——P-07b 的教训：张量空间的坐标查询 API 布局与预期不符，所以**任何 reshape 前先确认布局**（assert 尺寸能整除）。

**三个常用解剖动作**：

```python
u_mag = np.sqrt(np.sum(uh.x.array.reshape(-1,3)**2, axis=1))   # 每点位移长度
u_max = u_mag.max()                                            # 全场最大（标量）
i_max = u_mag.argmax()                                         # 最大值的位置编号
```

**「位置」的两层含义**：i_max 是「自由度序号」，要变回「几何位置」需要 dof 坐标（S.tabulate_dof_coordinates，第 24 节）——**「编号」与「坐标」是两套账**，靠 tabulate 翻译。

**为什么万神殿统计位移用矢量空间解**：u_mag 才是「物理位移」（不随坐标旋转变）。**只看 ux 或 uz 会漏**——比如穹顶顶部主要沿 -z 下沉，看 ux 会以为没动。

## 第 24 节 应力投影的完整链路：从位移到 σ1

第 6 节的三行投影，展开成八步全链路：

```python
# ① 声明应力空间（P1 张量）
S = fem.functionspace(domain, ("Lagrange", 1, (3,3)))
sigma_h = fem.Function(S)

# ② 求值点：元素插值点（每个单元的「采样位置」）
X = S.element.interpolation_points()      # (N,3)

# ③ 表达式：把位移代入本构（UFL 表达式）
sigma_expr = fem.Expression(sigma(uh), X)

# ④ 投影：在插值点上采样，写入应力场
sigma_h.interpolate(sigma_expr)

# ⑤ 取裸数组，reshape 成 (每点, 3, 3) 张量
sigma_nodes = sigma_h.x.array.reshape(-1, 3, 3)

# ⑥ 特征值（升序）：eigvalsh 对对称矩阵
principal = np.linalg.eigvalsh(sigma_nodes)

# ⑦ 主应力：最后一列 σ1、第一列 σ3
s1 = principal[:, -1]; s3 = principal[:, 0]

# ⑧ 统计：极值 + 判据
s1_max = s1.max()/1e6; s3_min = s3.min()/1e6
crack_idx = s1 > FT_CONCRETE
```

**每一步的「为什么」**：
- ② **interpolation_points 而非任意点**：插值点的选择保证「投影误差最小」（数学上是最优采样）；
- ③ **Expression(expr, X)**：0.8 新 API（P-05）——把 UFL 表达式「冻结」在指定点上求值；
- ④ **interpolate 而非 assign**：interpolate 走投影（带插值），assign 是直接覆盖——**要「从 uh 算应力」必须 interpolate**；
- ⑥ **eigvalsh 而非 eig**：symmetric + 升序——**eigvalsh 对对称矩阵更快更稳，且保证升序**（σ1 固定最后一列）。

**布局的 P-07b 自适应**（c4 的完整防御）：

```python
Xg = np.asarray(S.tabulate_dof_coordinates())
n_pts = sigma_nodes.shape[0]
if Xg.ndim == 2 and Xg.shape[0] == n_pts:      Xp = Xg        # 按点去重
elif Xg.ndim == 2 and Xg.shape[0] == 9*n_pts:  Xp = Xg.reshape(-1,9,3)[:,0,:]  # 9N 兜底
else: raise RuntimeError(f"坐标布局未识别：{Xg.shape} vs {n_pts}")
```

**「不信任 API 文档、运行时自适应」**——dolfinx 0.8 时代的生存法则（第 2 节增补的完整版）。

## 第 26 节 位移与应力的「双空间」关系：P2 与 P1 的桥

第 24 节的投影背后，是「位移空间 P2」与「应力空间 P1」的完整关系——**FEM 后处理最易混的概念**：

| 空间 | 阶 | 自由度位置 | 含义 |
| --- | --- | --- | --- |
| V（位移） | P2 | 顶点 + 边中点 | 解出来的原始场 |
| S（应力） | P1 | 顶点 | 投影出来的派生场 |

**为什么应力降阶**：σ = C:ε(u) = C:sym(∇u)——u 是 P2（每单元二次多项式），∇u 是 P1（求导降一阶），σ 就是 P1。**「求导降阶」是微积分在 FEM 里的直译**（第 9 节回响）。

**投影的两种哲学**（老教材 §8 的深度）：
- **节点插值（本项目）**：在 P1 插值点上直接算 σ(u)——简单快，但 σ 在单元间不连续（每单元算自己的）；
- **L2 投影**：解一个「找最接近 σ(u) 的 P1 场」的最小二乘问题——更光滑，但要多解一个方程。

**万神殿选节点插值的原因**：统计量（σ1 极值、开裂区占比）对投影方式不敏感；连通域口径进一步稀释了局部误差。**「够用」原则（第 5 课 Q10 的回响）。**

**双空间的一个实用推论**：**u 的最大位移点 ≠ σ 的最大应力点**——位移最大在「离约束最远」处，应力最大在「应力集中」处（藻井尖角）。**两个最大值各有各的物理位置**——别混着找。

## 第 29 节 无拉伸损伤：为什么线弹性不够用

第 4 课留下一个悬案：C1 的 σ1=0.1572 MPa **远超** f_t=0.08——线弹性算出「材料早该裂了」，却假装它没裂。**物理不自洽**。

**线弹性的「死不认账」**：本构 σ=C:ε 里没有「强度」——σ1 可以算到无穷大，材料永远不坏。**真实混凝土**：σ1 超过 f_t，材料开裂、刚度打折、应力重分配。**两者的差别就是「损伤本构」要补的东西。**

**万神殿的 Rankine 损伤模型**（c3 求解器文件头 L5-8）：

$$D = 1 - \left(\frac{f_t}{\sigma_1}\right)^2 \quad (\sigma_1 > f_t \text{ 处}), \qquad E(x) = E_0(1-D)$$

**逐项白话**：
- **Rankine 判据**：只看 σ1 超不超 f_t（最拉的方向决定开裂）；
- **D（损伤变量）**：0=完好、1=全坏——σ1=f_t 时 D=0（临界）、σ1→∞ 时 D→1（彻底坏）；
- **E(x)=E₀(1-D)**：坏掉的地方脾气打折——**「裂了的混凝土变软」**；
- **弥散损伤**：D 是空间场（每个点一个数），不是离散裂缝线——**「把裂缝抹成一片软区」**（工程上叫 smeared crack）。

**三条工程护栏**（文件头常量）：
```python
DAMAGE_CAP = 0.9     # D 封顶 0.9：防 E→0 刚度奇异
FTOL = 1e-3          # 损伤场收敛容差（L∞）
S1_PROTECT = 1e3     # σ1 极小处保护值：防除零
```

**护栏的物理**：D=1 时 E=0 → 刚度矩阵出现「零行」→ 奇异。**封顶 0.9 = 承认「彻底坏」但保留 10% 数值刚度**——工程与数学的妥协。

## 第 30 节 fixed-point 迭代：非线性问题的「笨办法」

损伤让问题变成非线性（刚度依赖解）。万神殿用**最温柔的非线性解法——fixed-point**（c3 求解器 L96-132 完整讲解）：

```python
D_field = fem.Function(Q1)          # 损伤场，初始 0
E_field = fem.Function(Q1)
E_field.interpolate(lambda x: np.full(x.shape[1], E0))   # 初始 E=E0（无损伤）

for it in range(max_iter):          # ← 外循环（非线性）
    problem = petsc.LinearProblem(a, L, bcs=[bc], petsc_options={...})
    uh = problem.solve()            # ← 内循环（线性，cg+amg）

    sigma_h.interpolate(fem.Expression(sigma_w(uh), X))
    s1 = np.linalg.eigvalsh(sigma_nodes)[:, -1]       # 算当前 σ1

    s1_pos = np.maximum(s1, S1_PROTECT)               # 保护
    D_new = np.maximum(1.0 - (FT/s1_pos)**2, 0.0)     # Rankine 更新
    D_new = np.minimum(D_new, DAMAGE_CAP)             # 封顶
    D_old = D_field.x.array.copy()
    D_new = np.maximum(D_new, D_old)                  # 不可逆！
    delta = float(np.max(np.abs(D_new - D_old)))      # 收敛度量
    D_field.x.array[:] = D_new
    E_field.x.array[:] = E0 * (1.0 - D_field.x.array) # 退化模量场

    if delta < FTOL: break                            # ‖ΔD‖∞ < 1e-3 收敛
```

**算法白话（四步循环）**：猜 D=0 → 解线弹性 → 算出 σ1 → 按 Rankine 更新 D → 再解 → 直到 D 不变。**「猜-解-更新-再猜」**——fixed-point（不动点）的名字：解就是「更新规则的不动点」。

**三个关键细节逐个讲**：
1. **不可逆（`np.maximum(D_new, D_old)`）**：裂缝合不回去——**损伤只能涨不能退**（物理：开裂不可逆）；
2. **收敛度量 delta**：两轮 D 的最大变化——<1e-3 说明「再解也差不多」；
3. **E_field 与 D 同空间直接写数组**：P1 标量空间 dof 布局一致 → **免插值直写**（第 4 课布局铁律的实战）。

**为什么收敛（物理直觉）**：损伤把 σ1 截回 f_t 附近后，下一轮的 D 更新量迅速衰减——**「限压阀」的自稳机制**。实测：3 次迭代收敛（8/16 三档）。

**与牛顿法的对比**（选型理由）：牛顿法收敛快（二次）但需要切线刚度（复杂）；fixed-point 收敛慢（线性）但**每步只是线弹性**（复用现有代码）。**「够用+简单」压过「快+复杂」——万神殿的选型哲学又一次出现。**

## 第 37 节 57° 口径三件套：角度、连通、转压

c4/c6 后处理的三件套是万神殿**最值钱的代码**（卷十一结论的全部证据链）。逐一深度讲解：

**口径一：角度映射（把坐标变成「拱脚起算的纬度」）**

```python

phi_z_deg = np.degrees(np.arccos(np.clip(Xp[:,2]/r, -1, 1)))   # 从 z 轴起算的角度

```

**两套角度的换算**：φ_z（从 z 轴/天窗轴起算，0°=天窗、90°=赤道）→ spring 角（从拱脚起算，0°=拱脚、90°=天窗）。**为什么用 spring 角**：Masi Table 2 与 Terenzio 57° 都是「above the springing」口径——**统计口径必须对齐文献口径**（否则 57° 无从对比）。

**clip(-1,1) 的保险**：浮点误差会让 z/r 轻微超出 [-1,1]，arccos 直接 NaN——**「夹紧」是数值三角的标配动作**。

**口径二：最大连通裂缝簇（BFS 图论课）**

第 5 节讲过的 BFS，这里是完整代码 + 图论原理：

```python
c2v = domain.topology.connectivity(3, 0)
nv = domain.topology.index_map(0).size_local   # 顶点总数
adj = [[] for _ in range(nv)]                   # 邻接表：每个点连着谁
for c in range(c2v.num_nodes):                  # 遍历每个四面体
    v = c2v.links(c)                            # 该单元的 4 个顶点
    for i in range(4):
        for j in range(i+1, 4):                 # 4 顶点两两连边
            a, b = int(v[i]), int(v[j])
            adj[a].append(b); adj[b].append(a)  # 无向图
# BFS：从每个未访问的开裂点洪泛标记整个连通簇
# 取最大簇的顶端角 = 真实裂缝带口径
```

**图论白话**：网格是一个「图」——顶点是图节点、四面体棱是图边。**「哪些开裂点连成一片」= 图的连通分量分解**。BFS（广度优先搜索）= 从一点出发，先把所有邻居标记、再邻居的邻居……像水波扩散。

**为什么必须连通口径**（第 5 节的重温+数据）：74.2° 是孤立尖角散点（每个藻井角一小撮互不相连），**不是裂缝**；最大连通簇顶端 12.6° 才是连贯裂缝带。**「单点极值会骗人，连通域不说谎」——图论拯救判据。**

**口径三：环向转压带（57° 假说的核心量）**

```python
theta_pts = np.arctan2(Xp[:,1], Xp[:,0])        # 每点方位角
e_th = np.stack([-np.sin(theta_pts), np.cos(theta_pts), np.zeros_like(theta_pts)], axis=1)
s_theta = np.einsum("ni,nij,nj->n", e_th, sigma_nodes, e_th)   # σ_θθ = e_θ·σ·e_θ
band = np.clip(np.floor(angle_from_spring).astype(int), 0, 89)  # 1° 纬度带
for k in range(90):
    m = band == k
    if m.sum() > 10 and s_theta[m].mean() > 0.0:   # 该带均值受拉
        hoop_transition_deg = float(k+1)
```

**einsum 的白话**：`"ni,nij,nj->n"` = 对每个点 n，算 e_θ·σ·e_θ（爱因斯坦求和记号——**重复下标自动求和**）。环向单位向量 e_θ=(-sinθ, cosθ, 0)（第 5 课方位角的兄弟）。

**转压带的物理**：按 1° 带取 σ_θθ 均值，**最高「均值受拉」的带 = 环向拉→压转变纬度 = 理论裂缝屏障**。铁律（8/17 八组算例）：**连通裂缝顶端 < 转压带，且随 ε_sh 增大同步爬升**——裂缝止于环向转压线是普适屏障。

## 第 38 节 裂缝判据的三层口径：散点、连通、转压

把三件套合成一张「口径决策表」——**同一份数据，三层口径三种读数**（卷十一的方法论核心）：

| 口径 | 统计量 | 藻井模型读数 | 物理身份 |
| --- | --- | --- | --- |
| max 单点 | σ1>f_t 的最远点 | 74.2° | 孤立奇异散点——**不是裂缝** |
| 最大连通簇 | 连通开裂带顶端 | 12.6° | 真实连贯裂缝带 |
| 环向转压带 | σ_θθ 均值转压纬度 | 30° | 裂缝的移动上限（屏障） |

**三层的关系（铁律）**：连通带 < 转压带（裂缝停在屏障前）；散点可远超（奇异不守物理）。**判据的正确用法**：
- 问「裂缝爬到哪」→ 连通簇口径；
- 问「理论上限在哪」→ 转压带口径；
- **别用散点口径下任何结论**（74.2° 的唯一用途：证明尖角奇异存在）。

**口径对齐的通用教训**（红队攻击面 1 的防守核心）：**「统计口径决定结论」**——写报告/画图/答辩前先声明口径。**「我用的是连通域口径，不是最大值」——这句话是 FEM 工程师的专业护照。**

## 第 43 节 课堂问答集（FEniCSx 新手 12 问）

**Q1：FEniCSx 和 COMSOL/ANSYS 什么关系？**
同类（有限元求解器）；FEniCSx 开源+代码级控制，商业软件 GUI+黑箱封装。**万神殿选开源的理由：可版本化、可参数化、零成本**（红队攻击面 8 的完整版）。

**Q2：dolfinx/ufl/basix 三件套各管什么？**
dolfinx=求解框架（网格/空间/组装/求解）；ufl=公式语言（弱形式）；basix=单元库（形函数）。**「骨架/语言/积木」分工。**

**Q3：为什么我的求解一秒报错但教程要跑几分钟？**
报错 = 矩阵没组装或 BC 缺失；教程的几分钟 = 组装+迭代。**「秒级报错」和「分钟级求解」是两个世界。**

**Q4：函数空间里的 "Lagrange" 还有别的吗？**
有：DG（间断伽辽金）、RT（Raviart-Thomas，流体）、Nedelec（电磁）……**每个族为一种物理量身定制**。结构力学用 Lagrange 就好。

**Q5：怎么知道自己的解对不对？**
五层防线（量纲→直觉→对称→趋势→文献）+ 反力=mg + 三条标度律。**「解出来了」≠「解对了」。**

**Q6：为什么应力和位移要用两个空间？**
微分的阶数差（第 26 节）。**「求导降阶」四个字。**

**Q7：MPI 现在不用，为什么要写 MPI.COMM_WORLD？**
为并行留接口——**「现在单进程，将来多进程，代码一行不改」**（500 万 DOF 计划）。

**Q8：fixed-point 和 Newton 什么时候用哪个？**
fixed-point：简单问题、图省事（万神殿）；Newton：强非线性、要速度（接触/大变形）。**「先 fixed-point 跑通，再谈 Newton」是稳妥路线。**

**Q9：损伤模型和断裂力学什么关系？**
损伤=弥散（抹成软区）；断裂力学=离散（裂缝线+尖端奇异+能量释放率）。**万神殿的 Rankine 是入门版；G_f 正则化+指数软化是升级方向（遗留清单 #2）。**

**Q10：为什么 .bp 不是 .vtu？**
VTXWriter 的 ADIOS2 格式是为大规模并行 I/O 设计的（.vtu 是串行时代的格式）。**「格式跟着算力时代走」。**

**Q11：学到什么程度算会 FEniCSx？**
能独立完成「改边界条件→改本构→改荷载→跑通→验证量级」的完整循环。**万神殿的 12 个坑你能独立排查 8 个，就算会了。**

**Q12：这课和找工作什么关系？**
有限元是结构/机械/土木/航空航天岗的通用硬技能；**「开源 FEniCSx + 商业软件至少一种」是仿真岗的标配**。万神殿练的是「原理级理解」——换任何软件都快。

## 第 49 节 进阶专题：E 敏感性扫描的完整设计

c1 的 --e 参数背后是 8/15「方案 A」的完整故事——**一个参数不确定时怎么办**：

**问题**：穹顶弹模有两个候选（14.8 GPa 工作值 vs 1.0 GPa 文献龄期值），差 14.8 倍，选哪个？

**方案 A（项目决策）**：不猜，扫三档 {1.0, 7.0, 14.8} GPa，用理论当裁判：

| E (GPa) | u_max (mm) | σ1 (MPa) | u×E 守恒 |
| --- | --- | --- | --- |
| 1.0 | 12.4023 | 0.0666 | 12.40 |
| 7.0 | 1.7718 | 0.0666 | 12.40 |
| 14.8 | 0.8380 | 0.0666 | 12.40 |

**两个结论**：① σ 与 E 无关（静定——第 4 课 Q7 的物证）；② u×E 守恒（比值 1.000）——**「位移∝1/E」三档精确验证**。

**代码里的自动校验**（c1 求解器 L177-182，值得全文抄）：

```python
if len(results) >= 2:
    r0, r1 = results[0], results[1]
    print(f"理论校验：σ1 应基本不变（{r0['s1_max_MPa']:.4f} vs {r1['s1_max_MPa']:.4f} MPa）")
    ratio = (r1["u_max_mm"]*r1["E_GPa"]) / (r0["u_max_mm"]*r0["E_GPa"])
    print(f"位移×E 应守恒：u_max×E 比值 = {ratio:.3f}（≈1 即验证通过）")
```

**「把物理理论写进代码当自动校验」**——比值偏离 1 就报警（单位错/BC 错/本构错，全都逃不过这一比值）。**参数不确定时的三步法**：不猜 → 扫档 → 用理论或文献仲裁。

**方案 A 的最终落地**：自重算例 σ 与 E 无关（哪个 E 都行）；干缩算例 σ∝E 必须用文献值——**8/17 定 E_SHRINKAGE=1.0 GPa**（卷四完整版）。**「不同物理场景用不同参数」——参数管理的最高段位。**

## 第 51 节 进阶专题：反力检查的完整实现（检验清单最硬一关）

第 4 课第 13 节讲过原理（反力=mg），这里是 dolfinx 的实现方案（万神殿**计划中未完整落地**的环节，如实标注 🔴）：

```python
# 方案：对固支面 400 上的每个自由度，反算其「支座反力」
# 原理：反力 = 该自由度的平衡方程残差（K u = f 中约束行被删前的值）
# dolfinx 0.8 实现要点：
#   1. 记录 dirichletbc 的 dofs
#   2. 组装不含 BC 的 K、f（或用 assemble_vector 取残差）
#   3. 对每个被约束 dof：r_i = (K u - f)_i = 支座反力
#   4. 竖向分量求和 → 与总重 mg 对比，误差 < 1%
```

**为什么这一关「最硬」**：位移云图可以「看起来正常」而荷载/约束双重错误互相抵消——**只有反力检查能把它们分开**（检验清单 v1 第 1 层原文：「误差 > 1% 意味着任何后续分析都不可信」）。

**验证链的诚实口径**：本项目**没有执行反力=mg 检查的记录**（科研日志无此项）——这是验证链的已知缺口（见文档「诚实边界」）。**本节的实现方案是留给读者的「下一课」预备**：COMSOL/ANSYS 里反力检查是标准动作，dolfinx 里需要手动组装残差。

**量级预演**（手算先行）：总重 mg = 2.46e7×9.81 ≈ 241 MN 量级——**如果反力算出 24 MN（差 10 倍），立刻查密度单位**。量纲分析永远先于数值对比。

## 第 53 节 附录：求解器「跑批」实战手册（8/17 战役的批处理档案）

```bash
# 五档 ε_sh 扫描（c4 主算）

  python fem_solver/c4_dome_shrinkage.py --load sw+sh --e 1.0e9 --eps-sh $sh

  python fem_solver/c4_dome_shrinkage.py --load $load --e 1.0e9 --eps-sh 1.0e-4
done
```

**跑批五纪律**（8/17 实战沉淀）：
1. **每档留痕**：输出重定向到日志（`>> output/c4_scan.log 2>&1`）——事后可查；
2. **命名自动**：out_tag 由参数拼出（第 25 节命名契约）——不会覆盖；
3. **结果登记**：每档跑完立即记进数据存档（卷九台账就是边跑边记的）；
4. **先小后大**：先 2.0m 粗网格验证参数区间，再上细网格（防烧时间）；
5. **作废隔离**：参数变更后旧结果移 _invalidated 留底（8/17 的 9 套旧干缩结果）。

**「跑批不是体力活，是档案工程」**——每一条命令可复现、每一个结果可追溯、每一套作废有记录。**这三条做到，几十个算例才不变成一团乱麻。**
