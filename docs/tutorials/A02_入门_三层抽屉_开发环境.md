> 写给：第一次接触「配环境」这个词的大一学生。
> 承诺：读完这篇，你能看懂任何「环境报错」在说什么，并能把万神殿的环境装起来。
> 前置：入门第 0 课（可选）。

---

## 先给一张地图

「配环境」三个字吓退过无数初学者，但它其实只有一个问题：**软件要的东西，你的电脑没放在它找得到的地方。**

本课用一个比喻讲透：**你的电脑是一座三层抽屉柜**。

- 最底层抽屉（Windows）——系统本身；
- 第二层抽屉（WSL2）——在 Windows 里嵌了一个小 Linux；
- 最上层抽屉（conda 环境）——在小 Linux 里给「万神殿项目」单独划的一个小房间。

**为什么 FEniCSx 装不进最底层抽屉？** 因为它的开发者只为 Linux 造了零件，Windows 抽屉装不上。所以我们要在第二层抽屉里装它。**大部分「环境问题」的本质：把软件放进了错误的抽屉。**

---

## 第 1 节 三层抽屉各装什么

```
┌─────────────────────────────────┐
│ conda 环境 pantheon-fem          │ ← 项目专属房间：dolfinx/gmsh/pyvista 一家子住这里
├─────────────────────────────────┤
│ WSL2（Ubuntu-22.04）             │ ← 小 Linux：所有计算软件的「老家」
├─────────────────────────────────┤
│ Windows 11                       │ ← 你的日常：浏览器/游戏/微信
└─────────────────────────────────┘
```

每层一个职责：Windows 负责你的日常，WSL2 负责「跑计算软件」，conda 负责「把不同项目的软件互相隔离」。

**为什么要隔离？** 想象两个项目：一个要 Python 3.11 的 dolfinx，另一个要 Python 3.8 的老库。放在同一个房间会打架——conda 给每个项目一个独立房间，各住各的。**「环境」这个词的准确含义：一个被隔离的房间，里面住着某个项目需要的全部软件版本。**

▢ **你试试 1**：打开 PowerShell，输入 `wsl -l -v`。你看到的就是第二层抽屉的「名字牌」。记下它——万神殿项目的第二层抽屉叫 **Ubuntu-22.04**（不是 Ubuntu，这是个真实的坑，8/14 踩过）。

⚠️ **新手常犯**：装环境时把命令输在错误的抽屉里。判断口诀：**conda 命令只在 WSL 里敲；pip/conda install 只装进激活后的环境**。Windows 的 PowerShell 和 WSL 的终端是两个世界。

## 第 2 节 一次真实的「装不上」：pip 三连 404

万神殿项目 8/11 的真实遭遇（这个故事能帮你理解所有「装不上」）：

1. 按教程用 pip 装 fenics-dolfinx → 清华源 404；
2. 换阿里源 → 404；
3. 换官方源 → **还是 404**。

**真相**：fenics-dolfinx 根本不在 PyPI（pip 的仓库）里——它只发布在 conda-forge（conda 的仓库）。**「装不上」最常见的三种原因，按概率排序：**

| 原因 | 症状 | 解法 |
| --- | --- | --- |
| 软件不在这个仓库里 | 三个源全 404 | 换仓库（pip → conda-forge） |
| 网络到不了仓库 | 超时/连接失败 | 换国内镜像（清华/阿里） |
| 版本号不存在 | 明确说 version not found | 查仓库实际有什么版本 |

▢ **你试试 2**：把你见过的任何一个「装不上」报错，按上表三选一分类。分不出来也没关系——**分类思维本身比答案重要**，下次报错先问「仓库对了吗？网络通了吗？版本存在吗？」

⚠️ **新手常犯**：报错后立刻换命令重试十遍。**错误信息会告诉你原因，先读三秒再动手**——「404」和「超时」和「version not found」是三个不同的病，药不一样。

## 第 3 节 一条命令装全套：setup_env_wsl.sh 里有什么

万神殿项目把整个安装过程写成了一个脚本（`tools/setup_env_wsl.sh`），运行它就行。这个脚本干了五件事，每件都值得你认识：

1. **检查** Miniconda（conda 的安装器）在不在，不在就从清华镜像下载；
2. **配置** conda 走清华镜像（国内网络纪律：优先清华，失败回退官方）；
3. **建房间**：`conda create -p ... python=3.11 fenics-dolfinx=0.8.0 mpich meshio pyvista numpy scipy matplotlib`——**版本号锁死**（dolfinx 的 API 变得快，锁版本 = 教材代码永远能跑）；
4. **补装** gmsh：conda 的 gmsh 不带 Python 接口，要用 pip 再装一遍（一个真实的「双仓库」案例）；
5. **自检**：跑 `env_check.py`，10 项全绿才算装完。

**装完 ≠ 装好**。第 5 步才是「完成」的定义——万神殿项目的规矩是「装完即验，不是装完即用」。

▢ **你试试 3**：打开 `tools/setup_env_wsl.sh` 数一数有几处 `if [ ! -x ... ]`。这种「先检查再动手」的写法叫**幂等**——脚本跑两遍不会坏。你以后写安装脚本，抄这个习惯。

## 第 4 节 每天的日常：三条咒语

装完之后，你每天只反复用三条命令：

```bash
# ① 进第二层抽屉（在 PowerShell 里敲）
wsl

# ② 激活房间（进了 WSL 后敲）
source ~/miniconda3/etc/profile.d/conda.sh && conda activate pantheon-fem

# ③ 自检（激活后敲）
cd /mnt/c/Users/tan83/Desktop/codex/01_学习研究/pantheon-3d-fem && python3 verification/env_check.py
```

**第三条命令里的 `/mnt/c/` 是什么？** WSL 里访问 Windows 的 C 盘，路径要写成 `/mnt/c/...`——**两个抽屉之间的门牌翻译规则**。Windows 说 `C:\Users\...`，WSL 说 `/mnt/c/Users/...`，说的是同一个地方。

▢ **你试试 4**：在 WSL 里 `ls /mnt/c/Users/tan83/Desktop`，再在 PowerShell 里 `dir C:\Users\tan83\Desktop`——两个抽屉看到的是同一张桌面。

⚠️ **新手常犯**：路径里的 `/` 和 `\`。Windows 用反斜杠 `\`，Linux/WSL 用正斜杠 `/`。**在哪个抽屉说话，用哪个抽屉的标点。**

## 第 5 节 环境的「体检报告」怎么读

`env_check.py` 输出 10 行，每行是一个软件的体检结果。长这样：

```
✅ numpy         v2.x      ← 装好了，版本看得见
❌ dolfinx       导入失败   ← 没装 / 装错房间了
```

**全绿（10/10）才开工**——任何一个 ❌ 都会在你跑求解器时变成看不懂的报错。**先体检再跑步，是环境层最重要的习惯。**

真实案例：8/14 有一天 `conda` 命令突然失效，报「command not found」——不是环境坏了，是 `.bashrc`（WSL 的「开机自启清单」）里少了 conda 的注册行。修法是 `conda init bash` + **重开终端**。**「修完要重开」是环境修复的隐藏步骤**，一半的「修了没用」都是没重开。

## 第 7 节 三层抽屉的内部解剖：每个抽屉里有什么

第 1 节的比喻升级成「内部结构图」——**知道每层里有什么，才知道错误从哪层来**：

**最底层 Windows 11**：系统本身 + PowerShell（你的日常终端）。**Windows 的职责到此为止**——它不装任何计算软件（FEniCSx 不认它）。

**第二层 WSL2（Ubuntu-22.04）**：
- 一个**完整的 Linux**嵌在 Windows 里（不是模拟器，是真正的 Linux 内核跑在虚拟机里）；
- 有自己的终端、自己的文件系统、自己的用户（tan83）；
- **「两套世界的门牌翻译」**：Windows 的 `C:\Users\tan83\...` = WSL 的 `/mnt/c/Users/tan83/...`。

**第三层 conda 环境（pantheon-fem）**：
- 一个文件夹：`/home/tan83/miniconda3/envs/pantheon-fem/`；
- 里面有独立的 Python 3.11 + 全部包；
- **「激活」= 把这个文件夹的路径提到最前**（activate 的本质就是改 PATH 环境变量）。

**PATH 是什么**（环境问题的万能钥匙）：**「命令去哪找」的清单**。你在终端敲 `python3`，系统按 PATH 清单逐个文件夹找——找到哪个用哪个。**「装了两个 Python 结果用了旧的」= PATH 顺序问题**。`which python3` 一条命令看清真相。

▢ **你试试 6**：激活环境后跑 `which python3`，再退出激活跑一次——**两条路径一对比，你就亲眼看见了「激活」在做什么。**

⚠️ **新手常犯**：在 Windows 的 PowerShell 里敲 `conda activate`——conda 装在 WSL 里，Windows 不认识。**「哪个抽屉里的工具，在哪个抽屉里用」。**

## 第 8 节 国内网络生存指南：镜像的原理与纪律

第 3 节的镜像回退链，这里讲「为什么」：

**镜像是什么**：官方仓库（如 PyPI、conda-forge）的**国内完整副本**——清华 TUNA、阿里云、中科大等高校/大厂维护，同步官方内容。

**为什么国内直连官方慢/断**：网络出口到海外的链路长且不稳定——**镜像把「跨国下载」变成「国内下载」**。

**三级回退纪律**（万神殿 setup_env_wsl.sh 的完整版）：
1. **首选清华 TUNA**（最全最稳）；
2. **失败回退官方**（脚本里的 `|| curl 官方源`）；
3. **再失败换阿里云/中科大**（手动改配置）。

**pip 与 conda 的镜像配置各一处**：
```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple   # pip
# .condarc 里写 channels: - https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge/  # conda
```

**一个真实案例的价值**（8/11 D1）：fenics-dolfinx 三源 404——**镜像忠实同步官方，官方没有的镜像也没有**。所以「换镜像救不了『包不存在』」——**404 是仓库问题，超时才是网络问题**（第 2 节三分类的深化）。

▢ **你试试 7**：查你本机的 pip 配置：`pip config list`。有 index-url 吗？没有的话按上面命令配一个（清华源）。

## 第 9 节 环境十二问（新手真实会问的）

**Q1：WSL 和虚拟机有什么区别？** WSL2 就是微软深度定制的虚拟机——**「官方出品、开机即用、文件互通」的虚拟机**。

**Q2：为什么不用 Docker？** 老教材文档0 有完整论证：Docker 隔离更彻底但文件互通/GPU/维护都更麻烦——**WSL2 对学生项目是甜点位**。

**Q3：conda 和 pip 什么关系？** 两个不同的包管理器（conda 管 conda-forge 生态、pip 管 PyPI 生态）——**万神殿两个都用**（conda 装 dolfinx、pip 补 gmsh），各管各的仓库。

**Q4：环境坏了重装还是修？** 先修（错误信息会指路）；**修不动就 `conda env remove -p <路径>` 重来**——环境是「可再生的」，别为它熬夜（setup 脚本 10 分钟重建）。

**Q5：版本号锁死（dolfinx=0.8.0）的意义？** API 会变——**锁版本 = 教材代码永远能跑**；升级是新任务，不是顺手的事。

**Q6：为什么 C 盘不够装？** conda 环境几个 GB——万神殿把环境放 WSL 内部磁盘（剩 920GB）、项目放 C 盘（27GB 时仍够）。**「环境大、项目小」的分布原则。**

**Q7：activate 报 conda not found？** bashrc 没注册（8/14 真坑）——`conda init bash` + **重开终端**。

**Q8：GPU 对 FEM 有用吗？** 求解没用（FEniCSx 纯 CPU），渲染有用（PyVista）——**「有好显卡=算得快」是 FEM 新手第一大幻觉**（8/11 科研日志）。

**Q9：多少内存能跑多大模型？** 约 9.9KB/DOF——24GB ≈ 250 万 DOF 上限（8/17 实测）。**先算账再建模。**

**Q10：怎么验证环境装对了？** env_check 10/10 + 跑通一个最小算例（C0 几何 59 行）。

**Q11：换电脑怎么迁移环境？** 重跑 setup 脚本（幂等）+ git clone 项目——**「环境可再生、代码可克隆」是环境的最高境界**。

**Q12：学到什么程度算会配环境？** 能看懂任何报错的「层」（Windows/WSL/conda/网络），能三分类（仓库/网络/版本）定位——**分类思维比记忆命令值钱**。
