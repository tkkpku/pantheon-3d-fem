## 第 1 节 云图的原理：给每个小块涂颜色

云图（colormap/contour）的原理朴素得惊人：

```
1. 每个节点算出一个数（比如位移长度 0.84mm 或应力 0.08MPa）
2. 定一条「颜色尺子」：最小值=蓝，最大值=红
3. 每个小块（四面体）按它的数在尺子上的位置涂色
4. 涂完 = 云图
```

**一张云图 = 一张「涂了颜色的网格」**。颜色越红数值越大，越蓝越小。所以看云图只有三个动作：**看颜色（大小）、看位置（哪里）、看色标（多大）**。

**色标（colorbar）是图的「图例」**——没有色标的云图没有意义（红色到底是多少？0.1 还是 100？没人知道）。

▢ **你试试 1**：打开任意一张万神殿截图或教程里的云图，先找三样东西：色标在哪、单位是什么、最大值是多少。找不到任何一样 → 这张图不合格。

⚠️ **新手常犯**：把「颜色红」当成「危险」。**红色只是数值大，危险与否要看阈值**——万神殿里 0.08 MPa 就该标红（已超抗拉强度），但很多工程图里 0.08 MPa 是安全蓝。**颜色是相对的，色标才是绝对的。**

## 第 3 节 图怎么骗人：万神殿被图骗的一次（最重要的一节）

8/17 决战日，满藻井模型的第一张云图是这样的：**σ1 超限区一路爬到 74.2°**——远超文献上限 65.8°。当时的第一反应是「模型错了」。

**破案过程**：放大看 74.2° 的超限区——发现是**一堆互不相连的小斑点**，每个藻井尖角一小撮，像撒了一把芝麻。真正的连贯开裂带只有 12.6°。

**结论**：74.2° 不是裂缝，是「尖角奇异的散点」——云图用「有没有超限」的口径把它们和真裂缝画成了一种颜色，**图骗了我们**。

**修法**：改用「连通域口径」——只把**彼此相连**的超限区算作裂缝带（BFS 算法找最大连通簇），散点剔除。同一份数据，两张图，两个故事：

| 口径 | 结果 | 真相 |
| --- | --- | --- |
| 超限散点（max 单点） | θ=74.2° | 孤立奇异点，不是裂缝 |
| 最大连通带 | θ=12.6° | 真实连贯裂缝 |

**这节课的教训**：**图不仅会展示真相，也会用「口径」包装假象。** 看任何云图先问：这个统计口径是什么？极值还是连通域？散点还是区域？——**这是万神殿项目里最贵的一课，价值超过所有画图技巧。**

▢ **你试试 3**：找一张你以前见过的「看起来很厉害」的数据图，问自己三个问题：口径是什么？有没有被孤立点带偏？换一种统计会变成什么样子？

## 第 4 节 实用三件套：对比、切面、动画

**对比图（clim 一致铁律）**：多算例对比时，所有图的色标范围必须相同。否则「一样的红色」在不同图里代表不同数值——**对比就废了**。万神殿五档 ε_sh 扫描的图全部共用同一 clim。

**切面（看内部）**：穹顶是实心的，云图只画表面看不到内部。用 `slice` 沿子午面切一刀，内部应力分布一览无余。**「表面光鲜」不等于「内部健康」——切一刀才知道。**

**动画（看过程）**：固定视角、逐帧渲染不同荷载档，连成动画。损伤演化、裂缝扩展这类「过程」只有动画能讲。

▢ **你试试 4**：把五档 ε_sh 的结果各画一张图，统一 clim 后并排放——观察开裂区怎么随收缩量「长大」。**这一排图就是「裂缝对收缩敏感」的视觉证据。**

⚠️ **新手常犯**：WSL 里直接开 PyVista 交互窗口——黑屏或报错（没有显示器）。**离屏渲染**（offscreen）+ 截图才是 WSL 的正道：`pyvista.OFF_SCREEN = True`。

## 第 6 节 最小可运行代码：第一张云图的完整课

第 1 节的原理讲完了，现在是**复制即跑**的完整代码（文档6 第 2 章的讲解版）：

```python
import pyvista as pv

# ① 读结果（.bp 目录）
mesh = pv.read("output/results/c1_E14.8_sigma.bp")

# ② 查看有哪些字段（体检第一步）
print(mesh.array_names)     # 期待看到应力相关的字段名

# ③ 算一个标量场（比如 σ1 或应力幅值）
#    .bp 里的张量场需要先转标量才能上色
mesh["sigma_mag"] = ...     # 视字段而定（见下文）

# ④ 画云图
plotter = pv.Plotter(window_size=[1200, 900])
plotter.add_mesh(mesh, scalars="sigma_mag", cmap="coolwarm",
                 clim=[0, 0.12], show_edges=False)
plotter.add_scalar_bar(title="应力 (MPa)", n_labels=5)
plotter.view_isometric()
plotter.show()
```

**五个新手必懂的点**：
1. **pv.read 直接读 .bp 目录**（不是 data.0）——PyVista 认识 ADIOS2 格式；
2. **array_names 先看字段**——万神殿的 sigma.bp 里是张量场，**上色前要转标量**（σ1/幅值/Mises 等）；
3. **clim=[0, 0.12]**：色标范围手动锁死——**第 3 节的「图骗人」防线**（不锁就随数据自动缩放）；
4. **add_scalar_bar**：色标是合同的图例——**没色标=没意义**（第 1 节）；
5. **view_isometric**：等轴视角——默认视角经常斜得看不出结构。

**WSL 离屏版**（第 4 节的完整姿势）：

```python
pv.start_xvfb()
plotter = pv.Plotter(window_size=[1200, 900], off_screen=True)
...
plotter.screenshot("c1_sigma.png")
```

**off_screen=True + screenshot** = WSL 无显示器的标准出图流。**「能出图」和「能交互看图」是两件事**——脚本截图可复现，交互窗口看心情。

## 第 7 节 三个常用标量：σ1、幅值、Mises 的物理差异

把张量场投影成标量，三种选择三种物理（万神殿用第一种）：

| 标量 | 计算 | 物理 | 万神殿用途 |
| --- | --- | --- | --- |
| σ1（最大主应力） | 特征值最大 | 最拉——**开裂判据** | ✅ 主力（σ1>f_t 开裂区） |
| 位移幅值 | √(ux²+uy²+uz²) | 位移大小 | ✅ 位移云图 |
| von Mises | 复杂组合 | 塑性判据（金属） | 不用（混凝土看主应力） |

**为什么混凝土不用 Mises**：Mises 是「剪切能判据」——金属屈服用；**混凝土受拉开裂看 σ1、受压压碎看 σ3**（第 4 课第 21 节）。**「判据跟着材料走」——画图之前先想清楚这个材料怕什么。**

**在 PyVista 里算 σ1**（.bp 张量场的处理）：

```python
import numpy as np
sigma = mesh.active_scalars.reshape(-1, 3, 3)   # 张量场
s1 = np.linalg.eigvalsh(sigma)[:, -1]           # σ1（升序最后一列）
mesh["s1"] = s1
```

**与第 6 课第 24 节完全同构**——**「后处理逻辑一套，表达工具两种」**（dolfinx 侧算统计、PyVista 侧画图）。

## 第 8 节 阈值过滤：一张图回答「哪里会裂」

第 2 节的进阶玩法，完整代码：

```python
import pyvista as pv
import numpy as np

mesh = pv.read("output/results/c4_ml_swpsh_E1.0_sh1.00e-04_sigma.bp")
# 算 σ1（第 7 节）
sigma = mesh.active_scalars.reshape(-1, 3, 3)
mesh["s1"] = np.linalg.eigvalsh(sigma)[:, -1] / 1e6   # 转 MPa

# 阈值过滤：只留 σ1 > 0.08 MPa 的开裂区
crack = mesh.threshold(value=0.08, scalars="s1")      # 只保留超限单元

# 双图层：全壳半透明 + 开裂区不透明红色
p = pv.Plotter(off_screen=True, window_size=[1200, 900])
p.add_mesh(mesh, color="tan", opacity=0.3)            # 全壳（背景）
p.add_mesh(crack, color="red")                        # 开裂区（主角）
p.add_scalar_bar(title="σ1 (MPa)")
p.screenshot("crack_zone.png")
```

**threshold 的白话**：按数值切一刀——**「只留下超限的部分」**。双图层（半透明壳+红色开裂区）是万神殿报告的标准画法：**「背景给上下文，红色给答案」。**

**这张图与 57° 结论的关系**：开裂区沿经线从拱脚往上爬、止于某纬度——**红色区域的顶端角就是 θ_top 的可视化**。第 3 节的「散点 vs 连通带」陷阱在这张图上看得最清：**红色若是一堆互不相连的小斑，那是散点不是裂缝**。

## 第 9 节 切面：看穿实心穹顶

第 4 节讲过「切一刀看内部」。完整代码（沿子午面切）：

```python
sliced = mesh.slice(normal=(0, 0, 1), origin=(0, 0, 0))     # 水平切
# 或子午切面：
sliced = mesh.slice(normal=(0, 1, 0), origin=(0, 0, 0))     # y 向竖切
```

**两个切法两个用途**：
- **水平切**（normal=(0,0,1)）：看「某一高度的环向分布」——藻井那层的应力圈；
- **子午切**（normal=(0,1,0)）：看「从拱脚到天窗的剖面」——裂缝沿经线的爬升。

**万神殿报告的标准剖面**：子午切 + σ1 上色 + 阈值过滤——**一张剖面图同时展示「裂缝在哪、爬多高、停在哪」**（卷十一结论的视觉版）。

## 第 11 节 视角与相机：让图「说人话」的姿势课

同一份数据，视角不同故事不同——**视角是图的「语气」**：

| 视角 | 代码 | 适合看什么 |
| --- | --- | --- |
| 等轴 | view_isometric() | 全局形状（第一眼） |
| 俯视 | view_xy() | 28 扇区对称、藻井排布 |
| 侧视 | view_yz() | 剖面轮廓、厚度渐变 |
| 自定义 | camera_position=[(x,y,z),(tx,ty,tz),(0,0,1)] | 裂缝区特写 |

**camera_position 三要素**：相机位置、注视点、朝上方向——**「站哪、看哪、头朝哪」**。特写裂缝带：相机移到拱脚外侧、注视裂缝区、头朝 +z。

**万神殿报告的用图惯例**：
- 首页图：等轴 + 半透明壳（「这是万神殿」）；
- 结论图：子午剖面 + σ1（「裂缝长这样」）；
- 细节图：藻井特写 + 网格线（「尖角在这里」）。

**「一图一事」原则**：每张图只讲一个故事（全局/裂缝/细节），**别让一张图背三个任务**（背不动就三张）。

## 第 12 节 渲染管线：PyVista 与 VTK 的关系

PyVista 的底层是 **VTK**（可视化工具包，C++ 工业库）——**PyVista 是 VTK 的「人话包装」**：

```
你的数据 → PyVista（Python 友好接口）→ VTK 管线（过滤/映射/渲染）→ 屏幕/文件
```

**管线的三个环节**（文档6 第 1 章的深度版）：
1. **数据源**：读文件（pv.read）或造数据（pv.PolyData）；
2. **过滤器**：threshold/slice/transform——**「加工数据」的一步**（第 8/9 节的阈值和切面都是过滤器）；
3. **映射与渲染**：标量→颜色→光照→出图。

**为什么知道管线有用**：报错时能定位环节——**「数据源没读进来」与「过滤器参数错」与「渲染配置错」是三个不同层的病**。debug 顺序：先 print 数据（源）→ 再查过滤结果 → 最后调渲染。

**UnstructuredGrid**（文档6 的核心概念）：**「不规则网格」的数据结构**——四面体网格每个单元形状位置都不同（对比结构化网格的整齐方块）。**FEM 结果都是 UnstructuredGrid**——这就是为什么需要 VTK 这种通用管线而非简单绘图库。

▢ **你试试 11**：在 Python 里 `print(mesh)` 看你的网格类型与规模（n_points/n_cells）——**读得懂这个摘要，就知道数据在哪个环节。**

## 第 13 节 常见错误集（PyVista 八场景）

| # | 错误 | 症状 | 排查 |
| --- | --- | --- | --- |
| 1 | 张量场上色 | cannot plot tensor / 乱色 | 先投影 σ1/幅值（第 7 节） |
| 2 | clim 未锁 | 对比图颜色骗人 | 统一 clim=[min,max]（第 3 节） |
| 3 | WSL 开交互窗 | 黑屏/报 DISPLAY 错 | off_screen + screenshot（第 6 节） |
| 4 | 读 .bp 失败 | file not found / 读不出 | 路径给目录名；先 array_names 体检 |
| 5 | 色标无单位 | 图「没意义」 | add_scalar_bar(title="σ1 (MPa)") |
| 6 | 阈值没转单位 | threshold 切错 | σ1 先 /1e6 转 MPa 再切 |
| 7 | 视角斜 | 结构看不出 | view_isometric 起手 |
| 8 | 图模糊 | 截图分辨率低 | window_size=[1600,1200] 起 |

**两个「口径级」错误**（比技术错误更危险）：
- **散点当裂缝**（第 3 节）：红色小斑 ≠ 裂缝——连通性检查；
- **颜色当结论**：「红色=危险」的直觉误用——**红不红看 clim，危不危险看阈值**（第 1 节）。

## 跋 · 三句话

一、图是数据的口译员——口译错了，数据再对也白搭。

三、最贵的图不是最好看的，是最诚实的：**散点就是散点，连通才是裂缝。**
