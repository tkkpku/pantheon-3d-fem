## 先给一张地图

图有两种命运：**装饰**（放在 PPT 里好看）和**证据**（放在报告里证明结论）。区别不在美观，在**图回答的问题**：

| 装饰图 | 证据图 |
| --- | --- |
| 「看，我画了条曲线」 | 「看，这条曲线证明网格收敛了」 |
| 只有线条 | 有判据线、有数值标注、有结论文字 |
| 换组数据也能画 | 数据一换结论就变——图跟着结论走 |

万神殿项目有三张「证据级」图值得抄：**网格收敛图、Richardson 误差区间图、双轴敏感性图**。本课逐一拆解，每张都配真实数据。

## 第 1 节 网格收敛图：项目的「身份证」

数据（C1 三档，E=14.8 GPa，万神殿实测）：

| 网格尺寸 h (m) | 2.0 | 1.0 | 0.5 |
| --- | --- | --- | --- |
| 最大位移 u (mm) | 0.8380 | 0.8390 | 0.8392 |
| 应力极值 σ1 (MPa) | 0.0666 | 0.1142 | 0.1572 |

**画法四要点**（每条都是证据级的细节）：

1. **x 轴是「网格尺寸」且从粗到细**（2.0 → 0.5）——读者一眼看出「往右=算得更细」；
2. **位移与应力分两张图或双轴**——量级差太多，画一起位移就看不见了；
3. **标注收敛判据线**（相邻两档变化 <2% 即达标）——没有判据线的收敛图只是三条点；
4. **把结论写进图里**：「u 收敛到 0.8392（三档变化 0.14%）」「σ1 极值不收敛（单点极值非收敛量）」——**图上的文字 = 图要证明的结论**。

**这张图的戏剧性**：同一组数据，位移收敛、应力极值不收敛——**一张图同时展示「什么可信」和「什么不可信」**。这就是证据图的最高形态：它不替你遮掩，它替你分拣。

▢ **你试试 1**：手画（或 matplotlib 画）这张收敛图，把上表六个数字全标上去，再写上两句结论。**标完数字+写完结论，你才算「画完」了这张图。**

⚠️ **新手常犯**：x 轴画成「第 1 档/第 2 档/第 3 档」这种顺序编号。**x 轴必须是物理量（h），否则看不出「收敛速度」。**

## 第 2 节 Richardson 误差区间：不跑第三档也能估误差

两档网格（2.0m / 1.0m）跑完，能不能不跑 0.5m 就估计「精确值」和误差？能——利用误差衰减规律 $e \propto h^p$：

$$u_{exact} \approx u_{fine} + \frac{u_{fine}-u_{coarse}}{r^p-1}, \qquad r=\frac{h_{coarse}}{h_{fine}}=2$$

代入实测：u_fine=0.8390、u_coarse=0.8380、p=2 → 外推 0.8391；p=3 → 外推 0.8393。

**关键动作——双假设画区间**：p=2 和 p=3 两个估计都画出来，**区间 [0.8391, 0.8393] 就是「精确值的可信范围」**。后来 0.5m 档实测 0.8392——稳稳落在区间内。**用「两档数据+理论阶」预测第三档，第三档验证——这就是数值分析的自我证明。**

▢ **你试试 2**：用计算器把上面的外推算一遍（p=2 和 p=3 各一次），再对比 0.5m 实测 0.8392。**算出来对得上，你就亲手完成了一次 Richardson 外推。**

## 第 3 节 双轴敏感性图：两种响应一张图讲清

万神殿 V1.0 的经典问题：**藻井挖得越深，两类裂缝的改善各有多少？**

| 深度因子 | 0.6× | 0.8× | 1.0× | 1.2× | 1.4× |
| --- | --- | --- | --- | --- | --- |
| JCIR%（交界裂缝改善） | 4.8 | 6.4 | 8.1 | 9.8 | 11.4 |
| MCFR%（子午裂缝改善） | 3.4 | 4.6 | 5.8 | 7.0 | 8.2 |

**画法三要点**：

1. **双 y 轴**（yyaxis left/right）：两个量量级不同但趋势相关，双轴同框才能看出「斜率差」——JCIR 长得快、MCFR 长得慢；
2. **柱+折线区分身份**：JCIR 是**恒等关系**（每 1% 减重精确换 1% 改善），画柱状强调「确定性」；MCFR 是**派生量**（收缩拖后腿），画折线强调「趋势」；
3. **物理解释写图上**：「JCIR == B (identity)」「Shrinkage-dominant」——**图自己会讲物理，观众不用翻报告**。

**这张图证明的结论**：藻井减重对两类裂缝的疗效不同（8.1% vs 5.8%），且差异来自收缩占比（29%）。**一张图 = 一个假说检验的完整叙事。**

## 第 4 节 证据图的七条军规（万神殿验收标准）

| # | 军规 | 反例 |
| --- | --- | --- |
| 1 | 轴标签带单位 | `u_max` → 不合格；`u_max (mm)` → 合格 |

## 第 6 节 最小可运行代码：收敛图的完整实现

第 1 节的四要点，代码化（复制即跑）：

```python
import matplotlib.pyplot as plt

# 万神殿 C1 三档实测数据
h   = [2.0, 1.0, 0.5]                      # 网格尺寸（x 轴：物理量！）
u   = [0.8380, 0.8390, 0.8392]             # 最大位移 mm
s1  = [0.0666, 0.1142, 0.1572]             # σ1 极值 MPa

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(11, 4))

# 左图：位移收敛
ax1.plot(h, u, "o-", color="steelblue", label="u_max")
ax1.set_xlabel("网格尺寸 h (m)"); ax1.set_ylabel("u_max (mm)")
ax1.set_title("位移：三档收敛")
for x, y in zip(h, u):                     # 关键数值标图上
    ax1.annotate(f"{y:.4f}", (x, y), textcoords="offset points", xytext=(0, 8))
ax1.invert_xaxis()                          # 粗→细（h 从大到小）

# 右图：应力极值不收敛
ax2.plot(h, s1, "s--", color="firebrick", label="σ1 极值")
ax2.set_xlabel("网格尺寸 h (m)"); ax2.set_ylabel("σ1 (MPa)")
ax2.set_title("σ1 极值：不收敛（单点极值）")
ax2.invert_xaxis()

plt.tight_layout()
plt.savefig("grid_convergence.png", dpi=300)
```

**逐行要点**：
1. **`invert_xaxis()`**：x 轴反向——**「往右=算得更细」**的读图直觉（第 1 节要点 1）；
2. **`annotate` 标数值**：0.8380/0.8390/0.8392 直接写图上——**证据图的数值必须可见**（要点 4）；
3. **左右分图**：位移与应力量级差太多，同图会互相淹没（要点 2）——**「一图一事」原则**（第 7 课同款）；
4. **`dpi=300`**：投稿底线。

**这张图讲的故事**：左边三条点几乎平（收敛✅）、右边三条点往上蹿（不收敛⚠️）——**「什么可信、什么不可信」一图道尽**（第 1 节的戏剧性，代码实现）。

▢ **你试试 6**：跑通这段代码，然后做两个实验：① 删掉 invert_xaxis 看读数变多别扭；② 把两图合一（单轴）看位移被压得多扁。**亲手感受「要点」为什么是要点。**

⚠️ **新手常犯**：x 轴用 [1,2,3] 这种档位编号——**档位编号不是物理量，看不出收敛速度**（第 1 节要点 1 的完整版）。

## 第 7 节 半对数误差图：收敛阶的直线读法

第 2 节的 Richardson 用「数」表达收敛；**log-log 图用「直线」表达**——斜率就是收敛阶 p：

```python
import numpy as np
import matplotlib.pyplot as plt

h = np.array([2.0, 1.0, 0.5])
u = np.array([0.8380, 0.8390, 0.8392])
u_exact = 0.83925                          # Richardson 三档外推值
err = np.abs(u - u_exact)                  # 每档误差

plt.loglog(h, err, "o-", label="实测误差")
plt.loglog(h, 0.0005*h**2, "--", label="斜率 p=2 参考线")
plt.loglog(h, 0.00005*h**3, "--", label="斜率 p=3 参考线")
plt.xlabel("h (m)"); plt.ylabel("误差 (mm)")
plt.legend()
plt.savefig("error_loglog.png", dpi=300)
```

**log-log 图的读法**：幂律 e∝h^p 在双对数坐标下是**直线**，**斜率 = p**。实测点落在 p=2 与 p=3 参考线之间 → **实测收敛阶 2.32 一望可知**（第 4 课公式的视觉版）。

**两条参考线的意义**：p=2（H1 范数理论阶）与 p=3（L2 理论阶）是「理论承诺的走廊」——**实测点落在走廊里 = 单元按承诺干活**；落在走廊外 = 有 bug 或进了奇异场。

▢ **你试试 7**：画出这张 log-log 图，用直尺量实测点的斜率，对照 p=2.32。**「用图量阶」与「用公式算阶」互相印证，就是证据图的精髓。**

## 第 8 节 误差棒与区间：让「不确定」可见

第 2 节的 Richardson 区间 [0.8391, 0.8393] 画成图：

```python
x = [1.0]                                  # 细网格档
y = 0.8390
yerr_low = 0.8390 - 0.8391                 # 下界（p=2 外推）
yerr_high = 0.8393 - 0.8390                # 上界（p=3 外推）
plt.errorbar(x, y, yerr=[[yerr_low], [yerr_high]],
             fmt="o", capsize=5, label="u_fine ± Richardson 区间")
plt.axhline(0.83925, ls=":", color="gray", label="三档外推精确值")
```

**errorbar 的白话**：给点加上「可能范围」的胡子——**「不确定」本身就是数据**（第 2 节双假设区间的可视化）。

**为什么证据图要画误差**：单点结论（0.8390）给人「精确」的错觉；区间结论（[0.8391, 0.8393]）说出真话：**「我大概知道答案在哪，误差这么小」**。**「诚实的不确定」比「虚假的精确」高级一个维度。**

## 第 9 节 常见错误集（Matplotlib 八场景）

| # | 错误 | 症状 | 排查 |
| --- | --- | --- | --- |
| 1 | 轴无单位 | 图「没意义」 | set_xlabel("h (m)") 标配 |
| 2 | x 轴档位编号 | 看不出收敛 | x=物理量 h |
| 3 | 对比图坐标不一 | 双图不可比 | 统一 ylim/双轴 |
| 4 | 数值不上图 | 「差不多」式结论 | annotate 标关键数 |
| 5 | 判据线缺失 | 收敛图=三条孤点 | axhline 画 <2% 线 |
| 6 | 结论写图外 | 图与报告脱节 | 图上/图注写结论 |
| 7 | dpi 低 | 投稿被退 | 300 起 |
| 8 | 数据不可回溯 | 无法复核 | 图注标数据源文件 |

**两个「口径级」错误**（与第 7 课同源）：
- **散点当趋势**：三条点就画折线——**点太少时折线是幻觉**（万神殿三档收敛图用 o- 是「示意」，报告里要声明只有三档）；
- **对数轴误读**：log 轴上「等距」≠「等差」——**log 图看斜率，不看间距**。

## 第 11 节 柱状图与双轴图的完整实战：敏感性分析可视化

第 3 节的双轴图原理，完整代码（V1.0 fig04a 的 Matplotlib 复刻）：

```python
import matplotlib.pyplot as plt

factor = [0.6, 0.8, 1.0, 1.2, 1.4]        # 深度缩放因子
JCIR   = [4.8, 6.4, 8.1, 9.8, 11.4]       # 交界裂缝改善率 %
MCFR   = [3.4, 4.6, 5.8, 7.0, 8.2]        # 子午裂缝改善率 %

fig, ax1 = plt.subplots(figsize=(8, 4.5))

ax1.bar(factor, JCIR, width=0.08, color="forestgreen", alpha=0.8, label="JCIR")
ax1.set_xlabel("深度因子"); ax1.set_ylabel("JCIR (%)", color="forestgreen")
ax1.set_ylim(0, 14)
ax1.axvline(1.0, ls="--", color="k", lw=0.8)        # 基准线

ax2 = ax1.twinx()                                    # 双轴！
ax2.plot(factor, MCFR, "bs-", label="MCFR")
ax2.set_ylabel("MCFR (%)", color="steelblue")
ax2.set_ylim(0, 14)

ax1.text(0.62, 5.2, "JCIR == B（恒等关系）", color="forestgreen")
ax1.text(0.62, 3.0, "收缩拖后腿", color="steelblue")
plt.savefig("sensitivity.png", dpi=300)
```

**逐行要点**（第 3 节的深化）：
1. **`twinx()`**：双 y 轴的正确姿势——**两个量共享 x、各用自己的 y**；
2. **柱（JCIR）vs 线（MCFR）**：恒等关系画柱（确定性）、派生量画线（趋势性）——**图的形式表达数据的身份**；
3. **`axvline(1.0)`**：基准线（实际设计深度）——**「我们的位置」必须标出来**；
4. **物理解释写图上**（text 标注）——**图自己会讲物理**（第 3 节要点 3）。

**这张图证明的结论**：两条曲线斜率不同（JCIR 陡、MCFR 缓）——**「藻井减重对两类裂缝疗效不同」一图道尽**，且差距（8.1 vs 5.8）肉眼可读。

▢ **你试试 10**：跑通代码，做两个实验：① 双轴 ylim 改不同（如左 0-14 右 0-20）看斜率视觉被扭曲；② 柱和线互换身份，感受「形式与身份」的错位感。

⚠️ **新手常犯**：双轴图两轴的量纲搞反——**「谁配左轴谁配右轴」由物理主次决定**：恒等/主结论放左轴（第一眼），派生量放右轴。

2. **右图阶梯**：前四档 0%、第五档骤升——**「阈值现象」的视觉定义**（裂缝是开关量，第 6 课第 19 节）。

**对比图的两条铁律**（第 3 节 ylim 一致的代码版）：**坐标一致**（不锁 ylim 就各图各尺度，对比作废）；**标注一致**（每个子图同款轴标签格式）。
