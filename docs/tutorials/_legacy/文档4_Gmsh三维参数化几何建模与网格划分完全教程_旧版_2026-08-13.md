## 1. 工具基础总览：Gmsh 是什么

### 1.1 Gmsh 的定位

Gmsh 是一个**开源的三维有限元网格生成器**，由比利时列日大学的 Christophe Geuzaine 和 Jean-François Remacle 开发。它提供：

| 功能 | 本项目使用方式 |
|---|---|
| **几何建模** | Python API（`gmsh.model.occ`）创建参数化几何 |
| **网格划分** | 自动四面体划分（非结构化网格） |
| **物理组标记** | 给不同的面和体打标签，供 FEniCSx 识别 |
| **网格导出** | 导出 `.msh` 文件（FEniCSx 可直接读取） |

### 1.2 为什么不用 Abaqus/ANSYS？

| | Gmsh + FEniCSx | Abaqus / ANSYS |
|---|---|---|
| **费用** | 免费开源 | 商业许可（数十万/年） |
| **自动化** | Python API，完全可编程 | GUI 为主，脚本自动化受限 |
| **透明度** | 源码公开，每一步可审查 | 黑箱求解器 |
| **学习价值** | 理解 FEM 底层逻辑 | 学会操作软件 |
| **学术界认可** | 广泛用于计算力学研究 | 工业界为主 |

### 1.3 Gmsh 的两种使用方式

| 方式 | 适用场景 | 本项目使用 |
|---|---|---|
| **GUI 交互式** | 手动调整几何、预览网格 | 调试阶段偶尔用 |
| **Python API** | 参数化建模、自动化工作流 | **主力使用** |

本教程只关注 **Python API**。因为万神殿穹顶的几何非常复杂（变厚度球壳 + 五层藻井 + 鼓座），手动在 GUI 里建模是不可能的。必须用代码参数化构建。

### 1.4 Gmsh Python API 的基本编程模式

所有 Gmsh Python 脚本遵循这个模板：

```python
import gmsh

# 1. 初始化 Gmsh
gmsh.initialize()

# 2. （可选）创建一个新模型并命名
gmsh.model.add("pantheon_dome")

# 3. 几何建模 → 网格划分 → 导出
#    ... 你的建模代码 ...

# 4. 生成网格
gmsh.model.mesh.generate(3)   # 3 = 三维

# 5. 导出
gmsh.write("output/meshes/dome.msh")

# 6. 清理
gmsh.finalize()
```

### 2.2 OCC 内核：Gmsh 的几何引擎

Gmsh 内置了两个几何内核：
- **Built-in 内核**（`gmsh.model.geo`）：.geo 脚本语言，功能有限
- **OpenCASCADE (OCC) 内核**（`gmsh.model.occ`）：工业级 CAD 内核，支持所有布尔操作

**本项目全部使用 OCC 内核。** 原因：布尔操作（加法/减法/相交）是万神殿建模的基础——球壳、藻井挖除、鼓座装配都需要。

使用 OCC 内核时，**每次修改几何后必须调用 `gmsh.model.occ.synchronize()`**。这是 OCC 的「延迟评估」机制：几何操作先记录在队列中，`synchronize()` 时才真正执行并更新 Gmsh 的内部数据结构。

### 2.3 理解 Gmsh 的实体模型

Gmsh 中的几何实体分为四级：

| 维度 | 实体类型 | 创建命令示例 | 本项目中使用 |
|---|---|---|---|
| 0D | **点 (Point)** | `addPoint(x, y, z)` | 网格尺寸控制点 |
| 1D | **线 (Curve)** | `addLine(p1, p2)`, `addCircleArc(...)` | 藻井边界 |
| 2D | **面 (Surface)** | `addPlaneSurface(...)` | 物理组标记（内表面、外表面等） |
| 3D | **体 (Volume)** | `addSphere(...)`, `addBox(...)` | 穹顶体、鼓座体 |

每个实体创建后返回一个整数 **tag**（标签），用于后续引用。

> **重要约定**：Gmsh 的 tag 是**模型内唯一但不连续**的整数。不要假设 tag 从 1 开始递增——始终用变量保存返回值。

## 4. 🟢 入门操作：布尔运算

布尔运算是 Gmsh OCC 内核的**核心能力**。几乎所有复杂几何都是通过基本几何体的布尔组合构建的。

### 4.1 布尔加法（Fuse / Union）

```python
# 把两个体合并成一个
gmsh.model.occ.fuse(
    [(3, tag_A)],   # 第一个体（3 = 三维实体）
    [(3, tag_B)],   # 第二个体
)
```

### 4.2 布尔减法（Cut）——本项目最常用的操作

```python
# 从体 A 中减去体 B
result = gmsh.model.occ.cut(
    [(3, dome_tag)],          # 被减体（穹顶球壳）
    [(3, coffer_tag)],        # 减去的体（藻井挖除体）
)

# result 是一个 (outDimTags, outDimTagsMap) 的元组
# outDimTags[0] 是被切割后的体（被减体剩余部分）
# outDimTags[1] 如果存在，是切出来的那个体（减去的部分）
```

> ⚠️ **关键注意**：`cut` 的返回格式比较复杂。第 0 个元素是输出几何体的列表，每个元素是 `(dim, tag)` 元组。

### 4.3 布尔相交（Intersect）

```python
# 取两个体的公共部分
gmsh.model.occ.intersect(
    [(3, tag_A)],
    [(3, tag_B)],
)
```

### 4.4 布尔运算示例：球壳 = 外球 − 内球

```python
import gmsh

gmsh.initialize()
gmsh.model.add("shell_demo")

R_INNER = 22.03
T_BASE = 5.90
R_OUTER = R_INNER + T_BASE   # 外球半径 = 内径 + 厚度

# 创建外球和内球
outer_sphere = gmsh.model.occ.addSphere(0, 0, 0, R_OUTER)
inner_sphere = gmsh.model.occ.addSphere(0, 0, 0, R_INNER)

gmsh.model.occ.synchronize()

# 外球 − 内球 = 球壳
# ⚠️ removeObject=False 保留内球，removeTool=True 删除内球
cut_result = gmsh.model.occ.cut(
    [(3, outer_sphere)],
    [(3, inner_sphere)],
    removeObject=True,
    removeTool=True,
)

gmsh.model.occ.synchronize()

# 获取球壳体的 tag
shell_dimtags = cut_result[0]
for dim, tag in shell_dimtags:
    if dim == 3:   # 体
        shell_tag = tag
        print(f"球壳体 tag: {shell_tag}")

gmsh.model.mesh.generate(3)
gmsh.write("shell.msh")
gmsh.finalize()
```

## 6. 🟢 入门操作：物理组标记

### 6.1 为什么需要物理组

Gmsh 的网格导出时会包含「物理组」(Physical Group) 信息。FEniCSx 读取网格后，根据物理组标签来施加边界条件和材料属性。

```
没有物理组：                        有物理组：
  所有面都是匿名面                   面 100：Oculus 边缘
  所有体都是匿名体                   面 200：内表面
  → FEniCSx 无从下手                面 300：外表面
                                    面 400：拱脚面（施加边界条件）
                                    体 500：穹顶体（施加材料属性）
```

### 6.2 标记物理组

```python
# 标记物理面（2D）
# gmsh.model.addPhysicalGroup(dim, tag_list, physical_tag, name)

# 例如：标记拱脚面（假设它的 tag 是 42）
gmsh.model.addPhysicalGroup(2, [42], tag=400, name="base_surface")

# 标记物理体（3D）
gmsh.model.addPhysicalGroup(3, [shell_tag], tag=500, name="dome_body")
```

### 6.4 如何找到正确的面 Tag？

布尔操作后，面的 tag 会变化。最可靠的方法是基于几何位置来判断：

```python
# 获取所有面的 tag 和包围盒
surfaces = gmsh.model.getEntities(dim=2)

for dim, tag in surfaces:
    # 获取该面的包围盒
    bbox = gmsh.model.occ.getBoundingBox(dim, tag)
    x_min, y_min, z_min, x_max, y_max, z_max = bbox

    # 根据位置判断这个面是什么
    z_center = (z_min + z_max) / 2

    if abs(z_center + 22.03) < 0.01:    # 在 z = -22.03 附近 → 底面
        bottom_faces.append(tag)
    elif abs(z_center - 8.95) < 0.5:    # 在 z ≈ 8.95 附近 → Oculus 面
        oculus_faces.append(tag)
```

## 8. 🟡 项目刚需：参数化球面构建

### 8.1 为什么需要参数化

万神殿穹顶的内表面是一个球面（R = 22.03m），但**球心不在檐口平面上**——球心偏内侧 0.37m（Aliberti 2017, p.366）。这个细节对拱脚的几何形状有影响。

更重要的是，我们将来可能需要调整球面半径（做敏感性分析），所以不能硬编码坐标，必须从参数计算。

### 8.2 球面坐标与笛卡尔坐标的转换

```python
import numpy as np

def spherical_to_cartesian(r, phi, theta):
    """
    球坐标 → 笛卡尔坐标

    Args:
        r: 径向距离 [m]
        phi: 子午角 [弧度]，从 Z 轴（球顶）起算
             0° = Oculus（正上方）
             90° = 拱脚（赤道面）
        theta: 环向角 [弧度]，从 X 轴逆时针

    Returns:
        (x, y, z): 笛卡尔坐标

    坐标约定：
        Z 轴向上（指向 Oculus）
        X, Y 在水平面
        原点在球心
    """
    x = r * np.sin(phi) * np.cos(theta)
    y = r * np.sin(phi) * np.sin(theta)
    z = r * np.cos(phi)
    return x, y, z
```

### 8.3 关键角度的计算

```python
from config.params import GeometryParams as GP

# Oculus 边缘对应的子午角
phi_oculus = np.arcsin(GP.D_OCULUS / (2 * GP.R_INNER))
# D_oculus = 8.95m, R_inner = 22.03m
# phi_oculus = arcsin(8.95 / 44.06) = arcsin(0.2031) ≈ 0.2045 rad ≈ 11.7°

# Oculus 边缘的 z 坐标
z_oculus = GP.R_INNER * np.cos(phi_oculus)
# = 22.03 * cos(0.2045) ≈ 21.57 m（从球心起算）

# 拱脚面（赤道面）z = 0（球心处），z = -22.03（球心在下，穹顶在球心上方）
# 实际上穹顶从 Oculus 到拱脚，对应 φ ∈ [φ_oculus, π/2]
```

## 9. 🟡 项目刚需：变厚度球壳建模

### 9.1 厚度函数

万神殿穹顶的厚度从 Oculus 处的 ~1.50m 逐渐增加到拱脚处的 ~5.90m：

```python
def thickness_at_phi(phi):
    """
    返回子午角 φ 处的穹顶厚度 [m]
    φ = 0° → Oculus（t ≈ 1.50m）
    φ = 90° → 拱脚（t = 5.90m）
    """
    phi_oculus = np.arcsin(GP.D_OCULUS / (2 * GP.R_INNER))
    phi_max = np.pi / 2

    # 线性变厚度
    t = GP.T_OCULUS + (GP.T_BASE - GP.T_OCULUS) * (phi - phi_oculus) / (phi_max - phi_oculus)

    return np.clip(t, GP.T_OCULUS, GP.T_BASE)
```

### 9.2 变厚度球壳的 Gmsh 实现

变厚度球壳 = 外球面 − 内球面。但外球面**不是**一个同心球面——因为厚度随 φ 变化！

外表面上的点 = 内表面上对应点沿法向（径向）向外偏移 `thickness_at_phi(φ)` 的距离。

对于球面，法向 = 径向，所以外表面上点的坐标是：

```
r_outer(φ) = R_INNER + thickness_at_phi(φ)
```

**简化方案**（本项目采用）：由于厚度变化相对平缓（1.5m → 5.9m 跨 80° 子午角），可以用两个不同半径的球面做布尔减法，然后接受「实际厚度在拱脚处比设计值略小、在 Oculus 处略大」的微小误差。严格方案需要在后续工作中实现（用 NURBS 曲面拟合外表面）。

```python
# 简化方案：使用平均厚度对应的外球面半径
T_AVG = (GP.T_OCULUS + GP.T_BASE) / 2   # ≈ 3.70m
R_OUTER_APPROX = GP.R_INNER + T_AVG     # ≈ 25.73m

outer_sphere = gmsh.model.occ.addSphere(0, 0, 0, R_OUTER_APPROX)
inner_sphere = gmsh.model.occ.addSphere(0, 0, 0, GP.R_INNER)

# 外球 - 内球 = 球壳
gmsh.model.occ.cut([(3, outer_sphere)], [(3, inner_sphere)])
```

> ⚠️ 这个简化方案的厚度误差在 ±2m 范围内。对于最终精确模型，需要实现严格变厚度外表面（用 `addSurfaceFilling` 或 NURBS）。

## 10. 🟡 项目刚需：Oculus 开口切割

穹顶顶部有一个直径 8.95m 的圆洞（Oculus）。在 Gmsh 中，用一个圆柱体去切掉球壳的顶部：

```python
import gmsh
import numpy as np
from config.params import GeometryParams as GP

def cut_oculus_opening(dome_shell_tag):
    """
    在穹顶顶部切割出 Oculus 开口。

    Args:
        dome_shell_tag: 穹顶球壳体的 tag

    Returns:
        切割后穹顶体的 tag(s)
    """
    phi_oculus = np.arcsin(GP.D_OCULUS / (2 * GP.R_INNER))
    z_oculus = GP.R_INNER * np.cos(phi_oculus)

    # 创建一个圆柱体，从 z_oculus 延伸到远上方
    # 圆柱半径 = Oculus 半径 + 余量（确保完全切穿球壳）
    r_cut = GP.D_OCULUS / 2 + 2.0   # 半径 4.475 + 2.0 = 6.475m
    cut_cylinder = gmsh.model.occ.addCylinder(
        0, 0, z_oculus - 1,    # 底面略低于 Oculus 面
        0, 0, 30,              # 向上延伸 30m（远高于穹顶顶部）
        r_cut
    )

    gmsh.model.occ.synchronize()

    # 球壳 − 圆柱 = 有洞的穹顶
    result = gmsh.model.occ.cut(
        [(3, dome_shell_tag)],
        [(3, cut_cylinder)],
        removeObject=True,
        removeTool=True,
```

## 11. 🟡 项目刚需：五层阶梯藻井的几何挖除

### 11.1 藻井的几何特征（来自 Aliberti 2017）

每个藻井是一个嵌在球壳内表面上的倒梯形凹槽：

```
    子午方向（φ 方向）
    ↑
    │  ┌─────────────┐  ← 顶宽（较窄）
    │  │             │
    │  │   藻井凹槽   │  ← 向内凹陷 ~0.23m
    │  │             │
    │  └─────────────┘  ← 底宽（较宽）
    │
    └──→ 环向（θ 方向）
```

关键几何规则（Aliberti 2017）：
- 上部连接面：**径向**设置（正交于球面）
- 下部连接面：向球心前方某点**汇聚**
- 内部面：**平面**（非球面，偏差仅 2-3cm）
- 子午肋（藻井间的分隔肋）：bisector 精确汇聚于球心

### 11.2 简化藻井建模策略

对于 V2.0 的初始版本，我们采用一个实用简化：**用长方体近似藻井凹槽**。

```python
def create_coffer_cutout(level, sector):
    """
    为指定的藻井（层级 + 扇区）创建挖除几何体。

    Args:
        level: 藻井层号 (0-4, 0=最底)
        sector: 扇区号 (0-27)

    Returns:
        coffer_solid_tag: 藻井挖除体在 Gmsh 中的 tag
    """
    from config.params import GeometryParams as GP

    # 获取该层藻井尺寸
    w_bottom = GP.COFFER_WIDTH_BOTTOM[level]
    w_top = GP.COFFER_WIDTH_TOP[level]
    h = GP.COFFER_HEIGHT[level]
    depth = GP.COFFER_MAX_DEPTH   # 0.23m

    # 计算藻井中心在球面上的位置
    phi_oculus = np.arcsin(GP.D_OCULUS / (2 * GP.R_INNER))
    # 五层藻井从 φ_oculus 分布到 φ=π/2
    phi_range = np.pi/2 - phi_oculus
    phi_center = phi_oculus + phi_range * (level + 0.5) / GP.N_COFFER_LEVELS
    theta_center = sector * (2 * np.pi / GP.N_SECTORS)

    # 藻井中心在笛卡尔坐标系中的位置（内表面上）
    x_c, y_c, z_c = spherical_to_cartesian(GP.R_INNER, phi_center, theta_center)

    # 径向方向（向外）
    r_dir = np.array([x_c, y_c, z_c]) / GP.R_INNER

    # 子午方向（φ 方向，在球面上）
    phi_dir = np.array([
        np.cos(phi_center) * np.cos(theta_center),
        np.cos(phi_center) * np.sin(theta_center),
        -np.sin(phi_center)
    ])

    # 环向（θ 方向）
    theta_dir = np.array([
        -np.sin(theta_center),
        np.cos(theta_center),
        0
    ])

    # 创建藻井挖除体：一个沿径向向内延伸的长方体
    # 简化：在藻井中心位置创建一个 box，然后旋转到球面方向
    w_avg = (w_bottom + w_top) / 2

    # 在原点创建 box
    box = gmsh.model.occ.addBox(
        -w_avg/2, -h/2, -depth,
        w_avg, h, depth
    )

    # 旋转 box：
    # - 原 box 的 z 方向 → 径向向内（-r_dir）
    # - 原 box 的 x 方向 → 环向（theta_dir）
    # - 原 box 的 y 方向 → 子午向（phi_dir）
    gmsh.model.occ.rotate(
        [(3, box)],
        0, 0, 0,              # 旋转中心
        0, 0, 1,              # 旋转轴（原 z 轴）
        np.degrees(theta_center)  # 旋转角度
    )

    # 平移到内表面位置
    inner_point = spherical_to_cartesian(
        GP.R_INNER - depth/2, phi_center, theta_center
    )
    gmsh.model.occ.translate(
        [(3, box)],
        inner_point[0], inner_point[1], inner_point[2]
    )

    return box
```

## 13. 🟡 项目刚需：几何装配

几何装配 = 穹顶 + 鼓座。需要确保两部分的交界面完全匹配。

```python
def assemble_full_model():
    """
    将穹顶和鼓座装配在一起，返回组合模型的 tag。

    关键：装配时不使用布尔加法（否则交界面会消失）。
    我们保留两个独立的体，但在网格划分时让 Gmsh 在交界面上
    共享节点（conformal mesh）。
    """
    # 1. 创建穹顶
    dome_tag = build_dome_with_coffers_and_oculus()

    # 2. 创建鼓座
    drum_tag = build_drum_geometry()

    gmsh.model.occ.synchronize()

    # 3. 使用 fragment 操作代替 fuse
    # fragment 让两体共享交界面但不融合：
    # - 交界面上的网格节点会被两个体共享（conformal）
    # - 但两个体保持独立（可以分别标记物理组）
    all_entities = gmsh.model.getEntities(dim=3)
    gmsh.model.occ.fragment(
        [(3, tag) for _, tag in all_entities],
        []  # 不额外切割
    )

    gmsh.model.occ.synchronize()

    return dome_tag, drum_tag
```

**为什么用 `fragment` 而不是 `fuse`？**

- `fuse`：两个体合并成一个体 → 交界面消失 → 无法分别标记穹顶体和鼓座体 → 无法分析二者之间的传力
- `fragment`：两体保持独立，但交界面共享节点 → FEniCSx 可以在交界面上施加绑定约束 → 穹顶和鼓座在 FEM 中耦合但不合并

```python
quality = gmsh.model.mesh.getQuality()

# 对于四面体网格，质量度量 "Gamma" 值在 [0, 1] 之间
# Gamma ≈ 1: 正四面体（最佳）
# Gamma < 0.1: 严重畸形的单元（需要改进）

n_bad = sum(1 for q in quality if q < 0.1)
n_good = sum(1 for q in quality if q > 0.5)

print(f"网格质量统计:")
print(f"  总单元数: {len(quality)}")
print(f"  高质量单元 (Gamma > 0.5): {n_good} ({100*n_good/len(quality):.1f}%)")
print(f"  低质量单元 (Gamma < 0.1): {n_bad} ({100*n_bad/len(quality):.1f}%)")

if n_bad > len(quality) * 0.01:   # > 1% 低质量单元
    print("⚠️ 警告：低质量单元过多，建议检查几何和网格设置")
```

### 17.3 提高网格质量的技巧

1. **避免极小的几何特征**：藻井凹角的圆角半径 ≥ 0.05m
2. **使用 `Mesh.Optimize`**：`gmsh.option.setNumber("Mesh.Optimize", 1)`
3. **使用 `Mesh.OptimizeThreshold`**：设置优化阈值
4. **网格平滑**：`gmsh.option.setNumber("Mesh.Smoothing", 10)`（平滑迭代次数）

## 18. 📦 最小完整案例：简化穹顶建模全流程

下面是一个**可以独立运行**的最小完整案例：创建一个简化穹顶（均匀厚度球壳 + Oculus 开口，无藻井，无鼓座），划分网格，导出。

```python
#!/usr/bin/env python3
"""
万神殿穹顶 · 最小完整案例
==========================
简化穹顶建模全流程：
  1. 创建均匀厚度球壳（R_inner=22.03m, t=5.90m）
  2. 切割 Oculus 开口（直径 8.95m）
  3. 标记物理组（内表面、外表面、拱脚面）
  4. 划分二阶四面体网格
  5. 导出 .msh 文件
  6. 用 PyVista 预览

运行：
  cd pantheon-3d-fem
  source .venv/bin/activate
  python3 geometry/minimal_dome_demo.py
"""

import numpy as np
import gmsh
from pathlib import Path

# ============================================================
# 参数（硬编码在示例中，正式项目请从 config/params.py 导入）
# ============================================================
R_INNER = 22.03       # 内球面半径 [m]  — Aliberti (2017)
T_SHELL = 5.90        # 球壳厚度 [m]      — Mark & Hutchinson (1986)
D_OCULUS = 8.95       # Oculus 直径 [m]   — Moore (1995)
MESH_SIZE = 1.0       # 全局网格尺寸 [m]（演示用粗网格）
OUTPUT_DIR = Path("output/meshes")
OUTPUT_DIR.mkdir(parents=True, exist_ok=True)

# ============================================================
# 主流程
# ============================================================
def main():
    print("=" * 60)
    print("  万神殿穹顶 · 最小完整案例 · Gmsh 建模")
    print("=" * 60)

    # 1. 初始化 Gmsh
    gmsh.initialize()
    gmsh.model.add("pantheon_minimal_dome")

    # 2. 创建均匀厚度球壳
    print("\n[1/5] 创建球壳几何...")
    R_OUTER = R_INNER + T_SHELL

    outer_sphere = gmsh.model.occ.addSphere(0, 0, 0, R_OUTER)
    inner_sphere = gmsh.model.occ.addSphere(0, 0, 0, R_INNER)

    gmsh.model.occ.synchronize()
    print(f"  外球 tag={outer_sphere}, 内球 tag={inner_sphere}")

    # 外球 - 内球 = 球壳
    result = gmsh.model.occ.cut(
        [(3, outer_sphere)],
        [(3, inner_sphere)],
    )
    gmsh.model.occ.synchronize()

    # 获取球壳体的 tag
    shell_tag = None
    for dim, tag in result[0]:
        if dim == 3:
            shell_tag = tag
    print(f"  球壳体 tag={shell_tag}")

    # 3. 切割 Oculus 开口
    print("\n[2/5] 切割 Oculus 开口...")
    phi_oculus = np.arcsin(D_OCULUS / (2 * R_INNER))
    z_oculus = R_INNER * np.cos(phi_oculus)
    print(f"  Oculus 子午角: {np.degrees(phi_oculus):.1f}°")
    print(f"  Oculus 边缘 z 坐标: {z_oculus:.2f} m")

    # 切割圆柱
    r_cut = D_OCULUS / 2 + 3.0
    cut_cyl = gmsh.model.occ.addCylinder(
        0, 0, z_oculus - 1,
        0, 0, 30,
        r_cut
    )

    gmsh.model.occ.synchronize()

    result2 = gmsh.model.occ.cut(
        [(3, shell_tag)],
        [(3, cut_cyl)],
    )
    gmsh.model.occ.synchronize()

    # 更新 shell_tag
    for dim, tag in result2[0]:
        if dim == 3:
            shell_tag = tag
    print(f"  切割后球壳体 tag={shell_tag}")

    # 4. 标记物理组
    print("\n[3/5] 标记物理组...")

    # 获取所有面
    all_surfaces = gmsh.model.getEntities(dim=2)
    print(f"  总面数: {len(all_surfaces)}")

    outer_faces = []
    inner_faces = []
    base_faces = []

    for dim, tag in all_surfaces:
        bbox = gmsh.model.occ.getBoundingBox(dim, tag)
        x_min, y_min, z_min, x_max, y_max, z_max = bbox

        # 面的中心
        z_center = (z_min + z_max) / 2
        # 面到原点的平均距离（近似判断内/外表面）
        r_center = np.sqrt(
            ((x_min + x_max) / 2)**2 +
            ((y_min + y_max) / 2)**2 +
            z_center**2
        )

        if z_center < -20:   # 底面附近
            base_faces.append(tag)
        elif r_center > R_INNER + T_SHELL / 2:   # 外表面
            outer_faces.append(tag)
        elif r_center < R_INNER + T_SHELL / 2:   # 内表面
            inner_faces.append(tag)

    # 创建物理组
    if inner_faces:
        gmsh.model.addPhysicalGroup(2, inner_faces, tag=200, name="dome_inner")
        print(f"  内表面物理组 (tag=200): {len(inner_faces)} 个面")
    if outer_faces:
        gmsh.model.addPhysicalGroup(2, outer_faces, tag=300, name="dome_outer")
        print(f"  外表面物理组 (tag=300): {len(outer_faces)} 个面")
    if base_faces:
        gmsh.model.addPhysicalGroup(2, base_faces, tag=400, name="dome_base")
        print(f"  拱脚面物理组 (tag=400): {len(base_faces)} 个面")

    # 物理体
    gmsh.model.addPhysicalGroup(3, [shell_tag], tag=1000, name="dome_body")
    print(f"  穹顶体物理组 (tag=1000): 1 个体")

    # 5. 划分网格
    print("\n[4/5] 划分网格...")
    gmsh.option.setNumber("Mesh.CharacteristicLengthMax", MESH_SIZE)
    gmsh.option.setNumber("Mesh.ElementOrder", 2)   # 二阶单元

    gmsh.model.mesh.generate(3)

    # 网格统计
    node_tags, _, _ = gmsh.model.mesh.getNodes()
    elem_types, elem_tags, _ = gmsh.model.mesh.getElements()
    n_elements = sum(len(t) for t in elem_tags)

    print(f"  节点数: {len(node_tags)}")
    print(f"  单元数: {n_elements}")

    # 质量统计
    try:
        quality = gmsh.model.mesh.getQuality()
        print(f"  最小质量: {min(quality):.3f}")
        print(f"  平均质量: {np.mean(quality):.3f}")
    except:
        print("  (质量统计不可用)")

    # 6. 导出
    print("\n[5/5] 导出网格...")
    output_path = OUTPUT_DIR / "minimal_dome.msh"
    gmsh.write(str(output_path))
    print(f"  网格已导出: {output_path}")

    print("\n" + "=" * 60)
    print("  ✅ 建模完成！")
    print(f"  网格文件: {output_path}")
    print("=" * 60)

    gmsh.finalize()

    # 7. PyVista 预览
    print("\n生成 PyVista 预览...")
    try:
        import pyvista as pv
        import meshio

        msh = meshio.read(str(output_path))
        for cell in msh.cells:
            if cell.type == "tetra10":     # 二阶四面体
                # PyVista 目前不完全支持 tetra10 的可视化
                # 取前 4 个节点作为一阶四面体显示
                tetra_data = cell.data[:, :4]
                cells_pv = [("tetra", tetra_data)]
                grid = pv.UnstructuredGrid(cells_pv, msh.points)
                grid.plot(
                    show_edges=True,
                    color="tan",
                    title="万神殿简化穹顶 · 网格预览",
                    window_size=[800, 600]
                )
                break
    except ImportError:
        print("  PyVista/meshio 未安装，跳过预览")

if __name__ == "__main__":
    main()
```

## 19. 常见错误与坑点

### 19.1 布尔操作后几何丢失

**症状**：执行 `cut` 后，穹顶或其一部分消失了。

**原因**：
1. 两个几何体没有真正相交——藻井挖除体可能完全在球壳外面或里面
2. `removeObject`/`removeTool` 参数设置不当，把不想删的体也删了

**排查**：
```python
# 在 cut 之前，先检查两体是否相交
gmsh.model.occ.synchronize()

# 获取两体的包围盒
bbox1 = gmsh.model.occ.getBoundingBox(3, dome_tag)
bbox2 = gmsh.model.occ.getBoundingBox(3, coffer_tag)

# 检查包围盒是否重叠
overlap_x = bbox1[0] < bbox2[3] and bbox2[0] < bbox1[3]
overlap_y = bbox1[1] < bbox2[4] and bbox2[1] < bbox1[4]
overlap_z = bbox1[2] < bbox2[5] and bbox2[2] < bbox1[5]

if not (overlap_x and overlap_y and overlap_z):
    print("⚠️ 两个几何体不相交！检查坐标计算。")
```

### 19.2 物理组标记遗漏

**症状**：FEniCSx 读取网格后找不到某些物理组。

**原因**：`addPhysicalGroup` 时使用的面 tag 在布尔操作后失效了（面的 tag 会变化）。

**解决方案**：**始终在布尔操作全部完成后**才标记物理组。基于几何位置（包围盒/法向）来识别面，而不是硬编码 tag。

### 19.3 网格尺寸设置不当导致畸形单元

**症状**：藻井凹角处出现极扁的四面体（Gamma < 0.05）。

**原因**：藻井凹角的几何约束太紧——同时有球面弯曲和直角转折，自动划分器难以处理。

**解决方案**：
1. 在藻井凹角处设置局部更小的网格尺寸（≈ 0.15m）
2. 考虑在凹角处加小圆角（半径 ≈ 0.05m）
3. 使用 `Mesh.CharacteristicLengthFromCurvature = 1` 让曲率大的地方自动加密

### 19.4 交界面网格不连续

**症状**：穹顶底面和鼓座顶面的网格节点不重合。

**原因**：两个体分开划分网格，Gmsh 不知道它们应该在交界面上共享节点。

**解决方案**：使用 `fragment` 操作（而非 `fuse`），确保交界面的网格 conformal。

### 19.5 28周期对称切片后几何不完整

**症状**：对称切片后穹顶被切坏，藻井只剩半个。

**原因**：切割平面恰好穿过藻井的中间——在设计对称切片时，切割面应该沿子午肋（藻井之间的分隔带）而不是穿过藻井本身。

**解决方案**：
- 扇区中心角 = 360°/28 = 12.857°
- 对称面1：θ = -6.4285°（第一个藻井的左边）
- 对称面2：θ = +6.4285°（第一个藻井的右边）
- 这样每个对称扇区包含**一个完整的藻井**
