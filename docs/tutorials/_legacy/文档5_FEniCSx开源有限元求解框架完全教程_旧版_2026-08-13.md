## 1. 工具基础总览：FEniCSx 是什么

### 1.1 FEniCSx = 三个组件的协作

| 组件 | 全称 | 干什么 |
|---|---|---|
| **DOLFINx** | Dynamic Object-oriented Library for FINite elements | FEM 求解引擎：读取网格、组装矩阵、求解线性/非线性系统、IO |
| **UFL** | Unified Form Language | 弱形式描述语言：用 Python 语法写数学公式（积分、导数） |
| **Basix** | Basis Function Library | 有限元基函数：定义单元类型（Lagrange、Nédélec 等）、阶次、自由度 |

```
你在 Python 中写的 UFL 代码（弱形式）
    │
    ▼
UFL 编译成 C++ 可执行代码
    │
    ▼
DOLFINx 调用 Basix 计算基函数
    │
    ▼
DOLFINx 组装全局刚度矩阵
    │
    ▼
PETSc 求解线性方程组 K·u = f
    │
    ▼
返回位移场 → 计算应力 → 导出 .vtu
```

### 1.2 FEniCSx vs 商业软件

| | FEniCSx | COMSOL / Abaqus |
|---|---|---|
| **操作方式** | 全代码（Python） | GUI + 脚本 |
| **弱形式** | 手动编写（最大灵活性） | 内置物理场（有局限性） |
| **本构模型** | 自己实现（完全控制） | 内置库（但不能改） |
| **求解器** | PETSc（开源，功能强大） | 商业求解器（黑箱） |
| **并行** | MPI 天然支持 | 需额外许可 |
| **学习曲线** | 陡峭（需要理解 FEM 原理） | 平缓（会操作软件即可） |
| **适合场景** | 研究、新模型开发、教学 | 工业标准品设计 |

## 4. 🟢 入门操作：Dirichlet 边界条件

### 4.1 什么是 Dirichlet 边界条件

> **Dirichlet BC = 指定某些自由度（通常是位移）的值为已知值。**

最常见的：结构某处被固定 → 该处位移 = 0。

### 4.2 找到要施加边界条件的面

```python
import numpy as np

# 方法：利用 Gmsh 中标记的物理组标签
# 假设拱脚面在 Gmsh 中被标记为物理组 tag=400

def find_facets_by_tag(facet_tags, target_tag):
    """找到所有标记为 target_tag 的面"""
    indices = np.where(facet_tags.values == target_tag)[0]
    return indices

base_facets = find_facets_by_tag(facet_tags, 400)
print(f"拱脚面包含 {len(base_facets)} 个网格面")
```

### 4.3 施加位移为零的边界条件

```python
import dolfinx.fem
import numpy as np

# 找到拱脚面上所有节点
base_dofs = dolfinx.fem.locate_dofs_topological(
    V,                    # 函数空间
    mesh.topology.dim - 1,  # 面 = 维度-1 = 2
    base_facets           # 面的索引
)

# 定义边界值函数：所有位移分量 = 0
u_zero = dolfinx.fem.Function(V)
u_zero.x.array[:] = 0.0   # 全部置零

# 创建 Dirichlet BC
bc_base = dolfinx.fem.dirichletbc(u_zero, base_dofs)
```

### 4.4 更灵活的边界条件

```python
# 只约束某个方向（如只约束 Z 方向位移）
import ufl

def z_zero_boundary(x):
    """返回一个 (3,) 数组，只约束 Z 方向"""
    values = np.zeros((3, x.shape[1]))
    values[2, :] = 0.0   # Z = 0（不约束 X 和 Y）
    return values

# 更优雅的方式：使用 lambda + Function
V_scalar = dolfinx.fem.functionspace(mesh, ("Lagrange", 1))
u_D = dolfinx.fem.Function(V_scalar)
u_D.interpolate(lambda x: np.zeros_like(x[0]))   # 所有位置 = 0
```

## 5. 🟢 入门操作：求解泊松方程（入门级弱形式）

在进入线弹性之前，先用最简单的**泊松方程**（热传导/静电场）来理解 UFL 弱形式的写法：

**强形式**：−Δu = f（在区域 Ω 内），u = 0（在边界上）

**弱形式**（在 FEniCSx 中）：

```python
import dolfinx
import ufl
from mpi4py import MPI

# 1. 创建网格和空间
comm = MPI.COMM_WORLD
mesh = dolfinx.mesh.create_unit_square(comm, 8, 8)
V = dolfinx.fem.functionspace(mesh, ("Lagrange", 1))

# 2. 定义试函数 u 和测试函数 v
u = ufl.TrialFunction(V)
v = ufl.TestFunction(V)

# 3. 定义源项 f
f = dolfinx.fem.Constant(mesh, 1.0)    # f(x) = 1 处处相等

# 4. 弱形式
# 左边 a(u, v) = ∫ ∇u · ∇v dx
a = ufl.dot(ufl.grad(u), ufl.grad(v)) * ufl.dx

# 右边 L(v) = ∫ f · v dx
L = f * v * ufl.dx

# 5. Dirichlet BC（所有边界 u=0）
def boundary(x):
    return np.isclose(x[0], 0) | np.isclose(x[0], 1) | \
           np.isclose(x[1], 0) | np.isclose(x[1], 1)

boundary_dofs = dolfinx.fem.locate_dofs_geometrical(V, boundary)
u_D = dolfinx.fem.Function(V)
u_D.x.array[:] = 0.0
bc = dolfinx.fem.dirichletbc(u_D, boundary_dofs)

# 6. 求解
problem = dolfinx.fem.petsc.LinearProblem(a, L, bcs=[bc])
uh = problem.solve()

print(f"求解完成！max(u) = {uh.x.array.max():.6f}")
```

**关键理解**：
- `ufl.TrialFunction(V)`：未知函数 u（我们要解的）
- `ufl.TestFunction(V)`：测试函数 v（弱形式中的「任意函数」）
- `ufl.grad(u)`：∇u（u 的梯度）
- `ufl.dot(a, b)`：a 和 b 的内积
- `ufl.dx`：体积积分测度
- `ufl.ds`：面积积分测度

### 6.2 位移函数（解）

```python

uh = dolfinx.fem.Function(V)

# uh 是一个 3D 矢量场
# uh.sub(0) = x 方向位移 u_x
# uh.sub(1) = y 方向位移 u_y
# uh.sub(2) = z 方向位移 u_z

# 可以用 .x.array 访问底层数值数组
displacement_values = uh.x.array   # shape: (n_dofs,)
```

### 6.3 为什么用二阶 Lagrange 元

对于线弹性问题（二阶偏微分方程），二阶单元的收敛速率是 O(h³)，一阶单元是 O(h²)。在弯曲壳体问题中，一阶单元容易产生**剪切闭锁（shear locking）**——由于单元内位移是线性的，无法准确表示纯弯曲变形，导致虚假的剪切应变，使结构「过于刚硬」。

二阶单元可以在每个四面体内表示二次位移场，能更好地捕捉弯曲变形。

## 7. 🟡 项目刚需：线弹性弱形式编写（UFL）

### 7.1 完整的线弹性弱形式

这是本项目的**核心代码**——万神殿穹顶自重分析的数学表述：

```python
import ufl
import dolfinx
import numpy as np

def build_linear_elastic_forms(V, mesh, E, nu, rho, g):
    """
    构建线弹性弱形式。

    弱形式（虚功原理）：
      ∫_Ω σ(u) : ε(v) dx = ∫_Ω f · v dx + ∫_∂Ω t · v ds

    左边：内力虚功
    右边：外力虚功（体积力 f + 面力 t）

    Args:
        V: 矢量位移函数空间
        mesh: FEniCSx 网格
        E: 弹性模量 [Pa]
        nu: 泊松比 [-]
        rho: 密度 [kg/m³]
        g: 重力加速度 [m/s²]（正值，向下为 -Z）

    Returns:
        a: 双线性形式（左边 → 刚度矩阵）
        L: 线性形式（右边 → 荷载向量）
    """
    # --- Lamé 常数 ---
    mu = E / (2 * (1 + nu))                # 第二 Lamé 常数 [Pa]
    lam = E * nu / ((1 + nu) * (1 - 2*nu)) # 第一 Lamé 常数 [Pa]

    # --- 试函数 u 和测试函数 v ---
    u = ufl.TrialFunction(V)
    v = ufl.TestFunction(V)

    # --- 应变张量 ε(u) = ½(∇u + ∇u^T) ---
    # ufl.sym 取对称部分，ufl.grad 对矢量函数给出 3×3 梯度矩阵
    def epsilon(w):
        return ufl.sym(ufl.grad(w))

    # --- 应力张量 σ(u) = λ·tr(ε)·I + 2μ·ε ---
    def sigma(w):
        return (
            lam * ufl.tr(epsilon(w)) * ufl.Identity(3)   # 体积部分
            + 2.0 * mu * epsilon(w)                        # 偏量部分
        )

    # --- 左边（双线性形式）：内力虚功 = ∫ σ(u) : ε(v) dx ---
    # ufl.inner 对二阶张量做全收缩（Frobenius 内积）
    a = ufl.inner(sigma(u), epsilon(v)) * ufl.dx

    # --- 右边（线性形式）：外力虚功 ---

    # 自重体积力：f = (0, 0, -ρg)
    # 重力在 -Z 方向！
    f = dolfinx.fem.Constant(mesh, (0.0, 0.0, -rho * g))

    # 体积力做功：∫ f · v dx
    L = ufl.dot(f, v) * ufl.dx

    # 如果还有面力（如后期加的干缩等效荷载），在 L 中追加：
    # L += ufl.dot(surface_traction, v) * ufl.ds(subdomain_id=...)

    return a, L
```

### 7.2 逐步解释 UFL 中的关键操作

```python
# 1. ufl.grad(u)
# 对矢量场 u = (u_x, u_y, u_z)，grad(u) 返回 3×3 矩阵：
#   [∂u_x/∂x,  ∂u_x/∂y,  ∂u_x/∂z]
#   [∂u_y/∂x,  ∂u_y/∂y,  ∂u_y/∂z]
#   [∂u_z/∂x,  ∂u_z/∂y,  ∂u_z/∂z]

# 2. ufl.sym(grad(u))
# 取对称部分 = (grad(u) + grad(u)^T) / 2
# 这给出应变张量 ε（小变形假设下）

# 3. ufl.tr(epsilon(u))
# 张量的迹 = ε_xx + ε_yy + ε_zz = 体积应变

# 4. ufl.Identity(3)
# 3×3 单位矩阵

# 5. ufl.inner(sigma, epsilon)
# 二阶张量的全收缩（double contraction）
# σ : ε = Σ_i Σ_j σ_ij ε_ij

# 6. ufl.dx
# 体积积分测度（在整个网格域上积分）
# ufl.dx(1) → 只在物理组标签为 1 的子域上积分

# 7. ufl.ds
# 面积积分测度（在边界面上积分）
# ufl.ds(400) → 只在物理组标签为 400 的面上积分
```

### 7.3 验证弱形式的正确性

在写完弱形式后，可以通过量纲分析来验证：

```
[a] 的物理量纲：
  σ 的量纲 = Pa = N/m²
  ε 的量纲 = 无量纲
  dx 的量纲 = m³
  → ∫ σ:ε dx 的量纲 = N/m² × m³ = N·m = J（能量）
  → 正确！左边是能量量纲。

[L] 的物理量纲：
  f 的量纲 = N/m³（体积力密度）
  v 的量纲 = m（位移，测试函数的量纲与试函数相同）
  dx 的量纲 = m³
  → ∫ f·v dx 的量纲 = N/m³ × m × m³ = N·m = J
  → 正确！右边也是能量量纲。
```

### 8.2 密度梯度（本项目实际需要）

万神殿穹顶的密度沿子午线变化（Masi et al. 2018）：

```python
def create_density_field(mesh, V_scalar):
    """
    创建随子午角 φ 变化的密度场。

    密度函数 ρ(φ)：
      0°–12°: 1350 kg/m³（顶部轻质浮石）
      12°–25°: 1650 kg/m³（过渡区）
      25°–40°: 1900 kg/m³（中下部）
      40°–90°: 2100 kg/m³（底部致密玄武岩）

    Args:
        mesh: FEniCSx 网格
        V_scalar: 标量函数空间（如 Lagrange 1 阶）

    Returns:
        rho_field: 密度场 Function
    """
    import numpy as np

    def rho_function(x):
        """
        根据坐标计算密度。
        x[0], x[1], x[2] = 笛卡尔坐标
        原点在球心，Z 向上
        """
        r = np.sqrt(x[0]**2 + x[1]**2 + x[2]**2)
        phi = np.arccos(x[2] / r)   # 子午角（从 Z 轴起算）
        phi_deg = np.degrees(phi)

        rho = np.zeros_like(phi_deg)
        rho[phi_deg <= 12] = 1350.0
        rho[(phi_deg > 12) & (phi_deg <= 25)] = 1650.0
        rho[(phi_deg > 25) & (phi_deg <= 40)] = 1900.0
        rho[phi_deg > 40] = 2100.0

        return rho

    rho_field = dolfinx.fem.Function(V_scalar)
    rho_field.interpolate(rho_function)

    return rho_field
```

在弱形式中使用密度场：

```python
# 体力 = (0, 0, -ρ(x,y,z) × g)
# 注意：这里 ρ 是空间变化的场，不是常数

f_z = -rho_field * g    # UFL 表达
```

### 9.3 对称边界条件（28周期对称模型）

```python
def apply_symmetry_bc(V, mesh, theta_0, theta_slice):
    """
    在对称面 θ=θ_0 上，法向（环向）位移为零。

    Args:
        theta_0: 对称面的环向角 [弧度]
        theta_slice: 扇区角度（2π/28）
    """
    import numpy as np
    import dolfinx.fem

    def symmetry_boundary_1(x):
        """θ = theta_0 对称面"""
        theta = np.arctan2(x[1], x[0])
        return np.isclose(theta % (2*np.pi), theta_0, atol=1e-3)

    def symmetry_boundary_2(x):
        """θ = theta_0 + theta_slice 对称面"""
        theta = np.arctan2(x[1], x[0])
        return np.isclose(theta % (2*np.pi),
                         (theta_0 + theta_slice) % (2*np.pi),
                         atol=1e-3)

    # 找到对称面上的节点
    dofs_1 = dolfinx.fem.locate_dofs_geometrical(V, symmetry_boundary_1)
    dofs_2 = dolfinx.fem.locate_dofs_geometrical(V, symmetry_boundary_2)

    # 对称约束：环向位移 = 0
    # 环向方向矢量 = (-sinθ, cosθ, 0)
    # 需要在边界条件的定义中体现
    # （这比较复杂，简化处理：对 X 和 Y 方向同时约束）
    u_zero = dolfinx.fem.Function(V)
    u_zero.x.array[:] = 0.0

    bc_sym_1 = dolfinx.fem.dirichletbc(u_zero, dofs_1)
    bc_sym_2 = dolfinx.fem.dirichletbc(u_zero, dofs_2)

    return [bc_sym_1, bc_sym_2]
```

## 11. 🟡 项目刚需：应力张量后处理输出

### 11.1 从位移场计算应力张量

```python
import ufl
import dolfinx

def compute_stress_tensor(uh, V_tensor, mesh, E, nu):
    """
    从位移场 uh 计算全场应力张量。

    步骤：
      1. 计算应变张量 ε = sym(grad(uh))
      2. 通过本构关系计算应力 σ = λ·tr(ε)·I + 2μ·ε
      3. 将 σ 投影到张量函数空间

    Args:
        uh: 位移场解
        V_tensor: 张量函数空间（9 分量或 6 分量对称）
        mesh: 网格
        E: 弹性模量 [Pa]
        nu: 泊松比 [-]

    Returns:
        sigma_h: 应力张量场 Function
    """
    mu = E / (2 * (1 + nu))
    lam = E * nu / ((1 + nu) * (1 - 2*nu))

    # 应变张量
    epsilon = ufl.sym(ufl.grad(uh))

    # 应力张量（本构关系）
    sigma_expr = lam * ufl.tr(epsilon) * ufl.Identity(3) + 2.0 * mu * epsilon

    # 投影到函数空间
    sigma_h = dolfinx.fem.Function(V_tensor)
    sigma_expr_proj = dolfinx.fem.Expression(
        sigma_expr,
        V_tensor.element.interpolation_points()
    )
    sigma_h.interpolate(sigma_expr_proj)

    return sigma_h
```

### 11.2 提取各应力分量

```python
def extract_stress_components(sigma_h, mesh):
    """
    从应力张量场提取各分量和主应力。

    Args:
        sigma_h: 应力张量场（9分量，3×3 矩阵）

    Returns:
        dict: 包含各应力分量的 numpy 数组
    """
    n_points = mesh.geometry.x.shape[0]
    coords = mesh.geometry.x

    # 在各节点上评估应力张量
    sigma_values = sigma_h.x.array.reshape(-1, 3, 3)

    stresses = {
        "sigma_xx": sigma_values[:, 0, 0],
        "sigma_yy": sigma_values[:, 1, 1],
        "sigma_zz": sigma_values[:, 2, 2],
        "tau_xy": sigma_values[:, 0, 1],
        "tau_yz": sigma_values[:, 1, 2],
        "tau_zx": sigma_values[:, 2, 0],
    }

    # 计算主应力（对每个节点）
    principal_stresses = np.zeros((n_points, 3))
    for i in range(n_points):
        sigma_3x3 = sigma_values[i]
        eigvals = np.linalg.eigvalsh(sigma_3x3)   # 对称矩阵的特征值
        principal_stresses[i] = np.sort(eigvals)[::-1]  # σ₁ ≥ σ₂ ≥ σ₃

    stresses["sigma_1"] = principal_stresses[:, 0]
    stresses["sigma_2"] = principal_stresses[:, 1]
    stresses["sigma_3"] = principal_stresses[:, 2]

    # 开裂判定：σ₁ > f_t
    F_T = 0.08e6  # 0.08 MPa
    stresses["cracked"] = stresses["sigma_1"] > F_T

    return stresses, coords
```

## 12. 🟡 项目刚需：等效干缩荷载施加

### 12.1 热应变类比法

干缩效应可以等效为一项初始应变 ε_sh。为了在 FEniCSx 中实现而不修改本构模型，使用**热应变类比法**：

```
σ = C : (ε - ε_sh·I)

等价于：

σ = C : (ε - α·ΔT·I)

其中 α·ΔT = ε_sh
```

### 12.2 UFL 实现

```python
def build_shrinkage_forms(V, mesh, E, nu, rho, g, epsilon_sh):
    """
    构建含干缩的线弹性弱形式。

    与纯弹性的区别：应力 = C : (ε - ε_sh·I)
    即 σ = λ·(tr(ε) - 3ε_sh)·I + 2μ·(ε - ε_sh·I)

    Args:
        epsilon_sh: 等效干缩应变 [-]，参考值 ~1.23×10⁻⁵
    """
    mu = E / (2 * (1 + nu))
    lam = E * nu / ((1 + nu) * (1 - 2*nu))

    u = ufl.TrialFunction(V)
    v = ufl.TestFunction(V)

    def epsilon(w):
        return ufl.sym(ufl.grad(w))

    # 含初始应变的应力
    def sigma_with_shrinkage(w):
        eps = epsilon(w)
        eps_vol = ufl.tr(eps) - 3 * epsilon_sh   # 体积应变减去干缩
        eps_dev = eps - (1/3) * ufl.tr(eps) * ufl.Identity(3)  # 偏量
        return lam * eps_vol * ufl.Identity(3) + 2.0 * mu * eps_dev

    a = ufl.inner(sigma_with_shrinkage(u), epsilon(v)) * ufl.dx

    # 自重
    f = dolfinx.fem.Constant(mesh, (0.0, 0.0, -rho * g))
    L = ufl.dot(f, v) * ufl.dx

    return a, L
```

## 13. 🔴 进阶：无拉伸混凝土非线性本构

### 13.1 基本思想

当第一主应力 σ₁ > f_t 时，该方向的刚度应退化为零（或接近零）：

```
对于每个积分点：
  计算主应力 σ₁, σ₂, σ₃
  对于每个 σᵢ > f_t 的主方向：
    将该方向刚度乘以退化因子 η（如 η = 0.001）
  重新组装刚度矩阵
  迭代直到收敛（牛顿法或割线法）
```

### 13.2 简化的非线性求解框架

```python
def solve_no_tension(mesh, V, facet_tags, E, nu, rho, g, f_t,
                     max_iter=50, tol=1e-6):
    """
    无拉伸混凝土非线性求解（简化版框架）。

    这个函数展示基本结构，完整实现需要额外的细节。
    """
    import dolfinx.fem.petsc
    from petsc4py import PETSc
    import ufl

    mu = E / (2 * (1 + nu))
    lam = E * nu / ((1 + nu) * (1 - 2*nu))

    # --- 初始弹性求解 ---
    u = ufl.TrialFunction(V)
    v = ufl.TestFunction(V)

    def epsilon(w):
        return ufl.sym(ufl.grad(w))

    def sigma_elastic(w):
        eps = epsilon(w)
        return lam * ufl.tr(eps) * ufl.Identity(3) + 2.0 * mu * eps

    a = ufl.inner(sigma_elastic(u), epsilon(v)) * ufl.dx
    f = dolfinx.fem.Constant(mesh, (0.0, 0.0, -rho * g))
    L = ufl.dot(f, v) * ufl.dx

    # 边界条件（同 C2）
    bottom_facets = np.where(facet_tags.values == 700)[0]
    bottom_dofs = dolfinx.fem.locate_dofs_topological(V, 2, bottom_facets)
    u_zero = dolfinx.fem.Function(V)
    u_zero.x.array[:] = 0.0
    bc = dolfinx.fem.dirichletbc(u_zero, bottom_dofs)

    # 初始求解
    problem = dolfinx.fem.petsc.LinearProblem(a, L, bcs=[bc],
        petsc_options={"ksp_type": "preonly", "pc_type": "lu"})
    uh = problem.solve()

    # --- 非线性迭代（简化框架）---
    for iteration in range(max_iter):
        # 1. 计算应力场
        # 2. 对每个单元检查 σ₁ > f_t
        # 3. 对开裂单元修改刚度（退化因子 η）
        # 4. 重新组装 K
        # 5. 求解 Δu
        # 6. 检查收敛

        # 收敛检查
        residual_norm = 1.0   # 实际需要计算
        if residual_norm < tol:
            print(f"非线性收敛，迭代 {iteration+1} 次")
            break
    else:
        print(f"⚠️ 非线性求解未收敛（{max_iter} 次迭代后）")

    return uh
```

## 15. 常见错误与坑点

### 15.1 刚度矩阵奇异（KSP_DIVERGED）

**症状**：`PETSc error: KSP_DIVERGED` 或 `NaN detected`

**这是 FEM 中最常见的错误（概率 > 50%）。**

**根因**：边界条件不足，结构可以发生刚体位移。

**排查步骤**：
1. 检查是否所有刚体位移模式都被约束：3 个平移（X, Y, Z）和 3 个旋转
2. 对于万神殿：确保底部节点在 X, Y, Z 三个方向全约束
3. 如果是 28 周期对称模型：确保对称面上的法向位移被约束

### 15.2 位移场全为零

**症状**：求解成功但位移处处为零。

**原因**：荷载没施加。常见于忘记设置重力方向（写成了 (0,0,g) 而非 (0,0,-g)）。

### 15.3 函数空间维度不匹配

**症状**：`ValueError: Dimension mismatch`

**原因**：试函数和测试函数的函数空间不一致，或 UFL 表达式中标量/矢量不匹配。

```python
# ❌ 错误：标量空间上尝试定义矢量位移
V_scalar = dolfinx.fem.functionspace(mesh, ("Lagrange", 2))
u = ufl.TrialFunction(V_scalar)
f = dolfinx.fem.Constant(mesh, (0.0, 0.0, -1.0))  # 3D 矢量
L = ufl.dot(f, u) * ufl.dx   # 维度不匹配！

# ✅ 正确：使用矢量空间
V_vector = dolfinx.fem.functionspace(mesh, ("Lagrange", 2, (3,)))
```

### 15.4 边界条件施加在错误的物理组上

**症状**：应力分布异常（如本该受拉的地方受压）。

**排查**：确认物理组 tag 与预期一致：
```python
print("面物理组分布:")
for tag in np.unique(facet_tags.values):
    count = np.sum(facet_tags.values == tag)
    print(f"  tag={tag}: {count} 个面")
```

### 15.5 内存溢出

**症状**：进程被 kill（`Killed`）。

**原因**：网格太大，MUMPS 直接求解器的内存需求是 O(N²)。

**解决方案**：
- 减小网格（使用粗网格先测试）
- 改用迭代求解器（CG + HYPRE）
- 使用 28 周期对称模型（减少 28 倍自由度）

### 15.6 非线性不收敛（SNES 震荡）

**症状**：牛顿迭代残差震荡或递增。

**解决方案**：
- 减小荷载步长
- 使用荷载增量法（逐步增加自重）
- 放松收敛容差
- 使用弧长法（Riks method）
