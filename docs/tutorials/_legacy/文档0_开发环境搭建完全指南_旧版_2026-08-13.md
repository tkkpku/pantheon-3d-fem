## 1. 前置理解：为什么必须用 WSL2

### 1.1 FEniCSx 不能在 Windows 原生运行吗？

**能，但极度不建议。**

FEniCSx 的底层依赖是 PETSc（一个并行科学计算库）和 MPI（消息传递接口）。这两个库在 Windows 上的支持极其有限：

- PETSc 官方**不支持 Windows 原生编译**
- MPI 在 Windows 上的实现（MS-MPI）与 Linux 版本行为不完全一致
- FEniCSx 的 conda 包在 Windows 上**只提供部分功能**，许多核心模块（如 `dolfinx` 的并行求解）不可用

> **结论**：FEniCSx 的官方推荐安装方式就是 Linux（Ubuntu）+ conda 或 Docker。WSL2 是在 Windows 上运行 Linux 的最优解。

### 1.2 WSL2 是什么？

> **白话**：WSL2 = Windows 里面跑了一个**真实的 Linux 内核**。它不是虚拟机（没有独立的桌面界面），而是共享 Windows 文件系统的轻量 Linux 环境。

**类比**：像在 Windows 里打开了一个特殊的终端窗口，这个终端里运行的是 Ubuntu Linux。你可以在这个终端里 `apt install`、`pip install`，就像在一台真正的 Linux 电脑上一样。

### 1.3 为什么不用 Docker？

Docker 也是可行的方案，但对于本项目的发起人来说有几个缺点：
- 多了一层抽象，文件共享和 GPU 渲染配置更复杂
- VS Code 的 Docker 远程开发比 WSL 远程开发多一步配置
- FEniCSx 官方 Docker 镜像自带完整的 Jupyter 环境，与本项目「全代码、无 Notebook」的风格不匹配

**WSL2 方案：更简单、更直接、更适合学习。**

### 1.4 本机的角色分工

| 环境 | 做什么 | 不做什么 |
|---|---|---|
| **Windows 11 原生** | VS Code 编辑器、Git GUI（可选）、PyVista 渲染窗口、浏览器查文档 | FEM 求解、Python 环境管理 |
| **WSL2 Ubuntu 22.04** | Python 虚拟环境、Gmsh 几何建模、FEniCSx 求解、Matplotlib 绑图 | VS Code GUI（通过 Remote-SSH 连接） |

> ⚠️ **特别注意**：RTX5070Ti 显卡对 FEM 求解没有加速作用。FEniCSx 的求解器是纯 CPU 的。GPU 只在 PyVista 做三维渲染时有用。所以不用纠结 CUDA、cuDNN 这些东西——本项目不需要它们。

## 2. 步骤一：启用 WSL2 + 安装 Ubuntu 22.04

### 2.1 确认 Windows 版本

**这一步在做什么**：WSL2 需要 Windows 10 版本 2004 或更高（或 Windows 11 任意版本）。

```powershell
# 在 Windows PowerShell 或 CMD 中运行：
winver
```

弹出窗口显示版本号。如果是 Windows 11，直接继续。如果是 Windows 10，确保版本号 ≥ 2004。

### 2.2 启用 WSL 功能

**以管理员身份**打开 PowerShell（右键开始菜单 → "Windows PowerShell (管理员)" 或 "终端 (管理员)"）：

```powershell
# 这一步在做什么：启用 Windows 的 WSL 子系统功能
wsl --install
```

这个命令会自动完成四件事：
1. 启用「适用于 Linux 的 Windows 子系统」可选功能
2. 启用「虚拟机平台」可选功能
3. 下载并安装 WSL2 Linux 内核更新包
4. 将 WSL2 设为默认版本

**如果 `wsl --install` 失败**（部分旧版本 Windows 10），可以手动执行：

```powershell
# 先启用两个 Windows 功能
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

# 重启电脑
# 重启后，下载 WSL2 内核更新包：
# https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_x64.msi
# 安装 .msi 文件

# 设置 WSL2 为默认
wsl --set-default-version 2
```

**重启电脑**（如果提示的话）。

### 2.3 安装 Ubuntu 22.04

```powershell
# 这一步在做什么：从 Microsoft Store 安装 Ubuntu 22.04 LTS
wsl --install -d Ubuntu-22.04
```

安装完成后，系统会弹出 Ubuntu 终端窗口，提示你创建用户名和密码：

```
Installing, this may take a few minutes...
Please create a default UNIX user account. The username does not need to match your Windows username.
For more information visit: https://aka.ms/wslusers
Enter new UNIX username: [输入你的用户名，建议全小写英文，如 tan83]
New password: [输入密码，不会显示在屏幕上，这是正常的]
Retype new password: [再次输入]
```

> ⚠️ **这个密码很重要！** 当你在 Ubuntu 里用 `sudo` 命令时需要输入它。忘了会很麻烦。

### 2.4 验证 WSL2 安装

关闭 Ubuntu 窗口，在 Windows PowerShell 中运行：

```powershell
wsl -l -v
```

应该看到：

```
  NAME            STATE           VERSION
* Ubuntu-22.04    Running         2
```

**关键**：VERSION 那一列必须是 `2`。如果是 `1`，说明还在用旧版 WSL，执行：

```powershell
wsl --set-version Ubuntu-22.04 2
```

### 2.5 将 Ubuntu 22.04 设为默认

```powershell
wsl --set-default Ubuntu-22.04
```

之后在 PowerShell 中直接输入 `wsl` 就能进入 Ubuntu。

| `wget` / `curl` | 命令行下载工具 |
| `git` | 版本管理（文档1会详细教） |

**预计耗时**：5-10 分钟。

## 4. 步骤三：安装 Python 3.11 + 创建虚拟环境

### 4.1 为什么用 Python 3.11？

FEniCSx 0.8.x 对 Python 3.11 的支持最稳定。Python 3.12 比较新，部分依赖可能还没有预编译的 wheel 包。Python 3.10 也可以用，但 3.11 是最佳平衡点。

### 4.2 确认 Python 版本

```bash
python3 --version
```

Ubuntu 22.04 默认安装的是 Python 3.10。如果输出版本号 ≥ 3.10，可以接受（3.10 也能用）。如果你想精确使用 3.11：

```bash
# 添加 deadsnakes PPA（提供更多 Python 版本）
sudo add-apt-repository ppa:deadsnakes/ppa -y
sudo apt update
sudo apt install python3.11 python3.11-venv python3.11-dev -y
```

### 4.3 创建项目专用虚拟环境

```bash
# 这一步在做什么：创建一个「隔离的 Python 环境」
# 这个环境里的包安装不会影响系统的 Python，也不受系统 Python 变化的影响

# 进入你的项目目录（在 Ubuntu 中访问 Windows 文件系统）
cd /mnt/c/Users/tan83/Desktop

# 创建项目根目录
mkdir -p pantheon-3d-fem
cd pantheon-3d-fem

# 创建虚拟环境
python3 -m venv .venv

# 激活虚拟环境
source .venv/bin/activate
```

**关键概念——虚拟环境是什么？**

> **白话**：`.venv/` 文件夹里装了一套**独立的、自己的 Python**。你用 `source .venv/bin/activate` 激活后，所有 `pip install` 都只装在这个文件夹里。关掉终端（或 `deactivate`）就退出了。
>
> **为什么要这样**：如果不用虚拟环境，所有项目共用一套 Python，包版本冲突是必然的。A 项目要 numpy 1.24，B 项目要 numpy 1.26——不隔离就打架。本项目要装十几个包，必须隔离。

激活成功后，终端提示符前面会出现 `(.venv)`：

```bash
(.venv) tan83@DESKTOP:~/pantheon-3d-fem$
```

看到这个前缀，说明虚拟环境已激活。之后所有的 `pip install` 都在这个环境里。

```bash
# 这一步在做什么：安装科学计算三件套

# SciPy = 科学计算工具箱（稀疏矩阵、优化、插值等）
# Matplotlib = 二维绑图（文档7会详细教）
pip install numpy scipy matplotlib
```

**预计耗时**：1-3 分钟。这些包都有预编译的 wheel，不需要本地编译。

```bash
# 这一步在做什么：
```

```bash

```

### 5.5 安装 FEniCSx（最关键的一步）

FEniCSx 包含三个核心包：

| 包 | 全名 | 干什么 |
|---|---|---|
| `dolfinx` | DOLFINx | 有限元求解引擎（读取网格、组装矩阵、求解） |
| `ufl` | Unified Form Language | 弱形式描述语言（用 Python 语法写数学公式） |
| `basix` | Basix | 有限元基函数库（定义单元形状、阶次、自由度） |

**安装命令**：

```bash
# 这一步在做什么：安装 FEniCSx 全家桶 + MPI 并行支持
pip install fenics-dolfinx
```

这个命令会自动安装 `dolfinx`、`ufl`、`basix`、`mpi4py` 和 `petsc4py`。

> ⚠️ **如果 `pip install fenics-dolfinx` 失败**（预编译的 wheel 不匹配你的 Python 版本或系统架构），改用 conda 方案：
>
> ```bash
> # 方案 B：通过 conda 安装（更稳定但需要先装 conda）
> # 1. 安装 Miniconda
> wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
> bash Miniconda3-latest-Linux-x86_64.sh
> # 按提示操作（一路 yes）
> # 关掉终端重开
>
> # 2. 创建 conda 环境
> conda create -n fenicsx-env python=3.11 -y
> conda activate fenicsx-env
>
> # 3. 安装 FEniCSx
> conda install -c conda-forge fenics-dolfinx mpich pyvista -y
> ```

**预计耗时**：3-8 分钟（取决于网速和 wheel 可用性）。

```python
import dolfinx

import basix

print("✅ FEniCSx (dolfinx + ufl + basix + mpi4py) 全部正常!")
```

**预期输出**：网格单元数 32、节点数 25、自由度 25 + "✅ FEniCSx ... 全部正常!"。

**方式二**：在 Ubuntu 终端中，进入项目目录后直接输入：
```bash
code .
```
这会自动在 VS Code 中通过 WSL 连接打开当前目录。

### 7.4 选择 Python 解释器

## 9. 常见安装错误与排错

### 错误 #1：`wsl --install` 提示「请启用虚拟机平台 Windows 功能」

**原因**：BIOS/UEFI 中未启用虚拟化技术，或 Windows 功能未启用。

**解决**：
1. 重启电脑进入 BIOS（通常是开机时按 F2 / F10 / Del）
2. 找到 "Virtualization Technology" / "Intel VT-x" / "AMD SVM" → 设为 Enabled
3. 保存退出，进入 Windows
4. 以管理员身份在 PowerShell 中运行：
   ```powershell
   dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
   ```
5. 重启电脑

### 错误 #2：`pip install fenics-dolfinx` 报 `Could not find a version...`

**原因**：你的 Python 版本没有对应的预编译 wheel。

**解决**：
- 方案A：检查 Python 版本 `python3 --version`，如果不是 3.10 或 3.11，切换到这两个版本
- 方案B：改用 conda 安装（见 §5.5 的方案 B）
- 方案C：从源码编译（耗时 30-60 分钟，不推荐给新手）：
  ```bash
  pip install fenics-dolfinx --no-binary dolfinx
  ```

### 错误 #3：`import dolfinx` 报 `libpetsc.so: cannot open shared object file`

**原因**：PETSc 的动态库路径未正确设置。

**解决**：
```bash
# 找到 petsc 的安装位置
pip show petsc4py | grep Location

# 设置 LD_LIBRARY_PATH（把下面路径替换为实际路径）
export LD_LIBRARY_PATH=/path/to/petsc/lib:$LD_LIBRARY_PATH

# 永久生效：把上面这行加到 ~/.bashrc 末尾
echo 'export LD_LIBRARY_PATH=/path/to/petsc/lib:$LD_LIBRARY_PATH' >> ~/.bashrc
source ~/.bashrc
```

### 错误 #4：`import gmsh` 报 `ModuleNotFoundError: No module named 'gmsh'`

**原因**：你可能在系统 Python 中装了 gmsh，但在虚拟环境中没装。或者反过来。

**解决**：
```bash
# 确认虚拟环境已激活（终端提示符前有 (.venv)）
which python3  # 应该指向 .venv/bin/python3

# 在虚拟环境中安装
pip install gmsh

# 验证
python3 -c "import gmsh; print(gmsh.__version__)"
```

### 错误 #5：Gmsh GUI 打不开（WSL2 中）

**原因**：WSLg 未启用或 Windows 版本不支持。

**解决**：
- 这**不影响**本项目。我们的工作流是 `gmsh` Python API → 导出 `.msh` → FEniCSx 读取。图形界面只是辅助。
- 如果想看几何模型，可以用后续安装的 PyVista 直接渲染 `.msh` 文件
- 或者在 Windows 端安装 Gmsh 桌面版（[https://gmsh.info](https://gmsh.info)），把 `.msh` 文件拖进去看

### 错误 #6：`pip install` 提示 `error: externally-managed-environment`

**原因**：你用系统 Python 而非虚拟环境执行了 pip install。Ubuntu 22.04 的系统 Python 受保护。

**解决**：
```bash
# 确认虚拟环境已激活
source .venv/bin/activate  # 一定要执行这一步！
# 然后重新 pip install
```

### 错误 #7：VS Code Remote-WSL 连接失败，提示 `VS Code Server for WSL closed unexpectedly`

**原因**：WSL 中的 VS Code Server 未正确安装或版本不匹配。

**解决**：
1. 关闭 VS Code
2. 在 PowerShell 中重启 WSL：`wsl --shutdown`
3. 重新打开 Ubuntu 终端：`wsl`
4. 运行 `rm -rf ~/.vscode-server` 删除旧的 server
5. 重新打开 VS Code，再次连接 WSL

### 错误 #8：`mpi4py` 安装失败，提示找不到 MPI 编译器

**原因**：系统缺少 MPI 实现。

**解决**：
```bash
sudo apt install -y libopenmpi-dev openmpi-bin
pip install mpi4py
```

### 错误 #9：`import pyvista` 后渲染窗口全是黑的

**原因**：WSLg 的 GPU 加速未正确配置。

**解决**：
- 检查 Windows 是否安装了最新的显卡驱动
- 在 Ubuntu 中运行 `glxinfo | grep "OpenGL renderer"` 查看 WSLg 是否识别了 GPU
- 如果没有 `glxinfo`：`sudo apt install -y mesa-utils`
- 如果渲染器显示为 `llvmpipe`（软件渲染），说明 GPU 未被 WSLg 识别，但这不影响 PyVista 的离屏渲染（保存为 PNG）

### 错误 #10：WSL2 内存/磁盘占用过高

**原因**：WSL2 默认可以使用最多 50% 的系统内存，FEM 大模型可能会吃满。

**解决**：创建 `C:\Users\<用户名>\.wslconfig` 文件（Windows 端）：
```ini
[wsl2]
memory=8GB          # 限制 WSL2 最大使用 8GB 内存
processors=4        # 限制使用 4 个 CPU 核心
swap=4GB            # 交换空间
```

保存后，在 PowerShell 中运行 `wsl --shutdown`，再重新打开 WSL。

## 10. 完整安装验证脚本

将以下内容保存为 `env_check.py`，放在项目根目录（`pantheon-3d-fem/`），用于一键验证所有工具：

```python
#!/usr/bin/env python3
"""
万神殿穹顶三维FEM重构 · 环境验证脚本
运行：python3 env_check.py
所有 ✅ 通过 = 环境搭建完成
"""

import sys

def check(module_name, import_name=None, extra_test=None):
    """通用检查函数"""
    if import_name is None:
        import_name = module_name
    try:
        mod = __import__(import_name)
        version = getattr(mod, "__version__", "未知")
        print(f"  ✅ {module_name:20s} v{version}")
        if extra_test:
            extra_test(mod)
        return True
    except ImportError as e:
        print(f"  ❌ {module_name:20s} 导入失败: {e}")
        return False

def main():
    print("=" * 60)
    print("  万神殿穹顶三维FEM重构 · 环境验证")
    print("=" * 60)
    print()

    results = []

    # 基础 Python
    print(f"  Python {sys.version.split()[0]}")
    print()

    # 数值计算
    print("📐 数值计算：")
    import numpy as np
    results.append(check("numpy", extra_test=lambda m: None))
    results.append(check("scipy", extra_test=lambda m: None))
    print()

    # 绑图工具
    print("📊 绑图工具：")
    results.append(check("matplotlib"))
    print()

    # 网格与前处理
    print("🔷 网格与前处理：")
    results.append(check("gmsh"))
    results.append(check("meshio"))
    print()

    # FEM 求解
    print("🔺 有限元求解 (FEniCSx)：")
    results.append(check("dolfinx"))
    results.append(check("ufl"))
    results.append(check("basix"))
    results.append(check("mpi4py"))
    print()

    # 可视化
    print("🎨 三维可视化：")
    results.append(check("pyvista"))
    print()

    # 汇总
    print("=" * 60)
    passed = sum(results)
    total = len(results)
    if passed == total:
        print(f"  🎉 全部通过！{passed}/{total} 个工具就绪。")
        print("  环境搭建完成，可以开始项目开发！")
    else:
        print(f"  ⚠️ {passed}/{total} 通过，{total-passed} 个失败。")
        print("  请检查上方 ❌ 的项，对照第9节排错。")
    print("=" * 60)

if __name__ == "__main__":
    main()
```

**运行**：
```bash
cd /mnt/c/Users/tan83/Desktop/pantheon-3d-fem
source .venv/bin/activate
python3 env_check.py
```
