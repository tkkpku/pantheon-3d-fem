## 第一部分：从一根弹簧开始

### 1. 胡克定律：F = kx

你一定在高中物理学过这个：

```
F = k × x

其中：
  F = 弹簧的拉力（单位：牛顿 N）
  k = 弹簧刚度（单位：N/m）——弹簧越硬，k 越大
  x = 弹簧的伸长量（单位：米 m）
```

这是整个弹性力学的起点。一条弹簧被拉长 x，就会产生 kx 的力来「抵抗」这个拉长。

**关键的思维跃迁**：任何弹性体——不管是一根弹簧、一块橡皮、一座穹顶——在微观层面上都可以看作是由**无数微小弹簧**组成的。每个微小的材料单元连接着相邻的材料单元，各自有自己的「微刚度」。整个结构的力学行为 = 所有微弹簧的集体行为。

### 2. 从弹簧到材料：弹性模量 E

弹簧的刚度 k 有两个问题：
1. k 依赖弹簧的**尺寸**——同样材料的弹簧，长的比短的更软（k 更小），粗的比细的更硬（k 更大）
2. k 不能描述材料本身的属性——我们想要一个**只取决于材料**的常数

**弹性模量 E** 就是这个常数：

```
σ = E × ε

其中：
  σ = 应力 = F/A（力除以面积，单位 Pa = N/m²）
  ε = 应变 = ΔL/L₀（伸长量除以原长，无量纲）
  E = 弹性模量（单位 Pa）
```

**白话**：弹性模量 E 是材料的「固有弹簧刚度」。E 越大，材料越难变形。钢的 E ≈ 200 GPa，橡胶的 E ≈ 0.01 GPa，万神殿古罗马混凝土的 E ≈ 14.8 GPa。

> **万神殿语境**：E = 14.8 GPa 意味着什么？如果我们取一块边长 1m 的混凝土方块，上面加压 14.8 × 10⁹ N（约 150 万吨），它会被压缩到原来长度的一半——当然实际上混凝土早就碎了。这个数字只是告诉你它有多「硬」。在正常工作应力下（几 MPa），应变只有约 0.01%，肉眼根本看不出来。

### 3. 泊松比 ν：材料被拉长时会变细

这是一个容易被忽视但非常重要的现象：

```
拉一根橡皮筋 →
  长度增加 ΔL（轴向拉长）
  同时变细 Δd（横向收缩）

泊松比 ν = -(横向应变) / (轴向应变)
         = -(Δd/d₀) / (ΔL/L₀)
```

**物理直觉**：材料在保持总体积近似不变的情况下变形。拉长 → 变细，压短 → 变粗。

| 材料 | ν |
|---|---|
| 软木塞 | ≈ 0（压下去不变粗） |
| 混凝土 | 0.15–0.25 |
| 古罗马混凝土（本项目） | **0.2** |
| 橡胶 | ≈ 0.5（几乎不可压缩，拉长多少就变细多少） |
| 钢 | 0.3 |

> **万神殿语境**：穹顶在自重下，子午方向受压（缩短）→ 泊松效应导致环向「想变粗」→ 但穹顶是一个闭合环，不能自由变粗 → 产生环向张力。**穹底环向受拉的一个重要机制就是泊松效应。**

### 4. 从一维到三维：为什么需要「张量」

弹簧（F = kx）和简单拉伸（σ = Eε）都是一维的——只有一个方向。但万神殿穹顶是一个三维结构：

- 子午方向（从 Oculus 到拱脚）：受压
- 环向（围绕穹顶一圈）：底部受拉，顶部受压
- 径向（厚度方向）：被挤压

**三个方向同时存在、相互作用。** 这就是为什么我们需要「张量」而不是一个简单的数。一个标量（普通数字）只能描述一个方向上的一个分量。三维空间中，你需要一个 3×3 的矩阵才能完整描述物体内部任意一点的受力状态。这个矩阵就是**应力张量**。

## 第二部分：三维应力张量

### 5. 应力是什么：单位面积上的内力

想象你一刀把穹顶切开：

```
        切面
    ┌────┼────┐
    │    │    │
    │    │    │  ← 上半部分
    │    │    │
    ├────┼────┤  ← 切面 A（面积 A）
    │    │    │
    │    │    │  ← 下半部分
    │    │    │
    └────┴────┘
```

上半部分受到重力往下坠。它为什么没掉下来？因为切面上的材料在「拉着」它。

**应力 σ = F / A**

- F 是切面上传递的内力（单位 N）
- A 是切面面积（单位 m²）
- σ 的单位是 Pa（= N/m²）

> **关键区别**：应力不是力，是**力的密度**——单位面积上传递的力。同一物体内部，不同方向、不同位置的应力完全不同。

### 6. 应力张量的六个分量

在三维空间中，任意一点的应力状态需要 9 个数来描述（3×3 矩阵）。但由于「力矩平衡」的约束，这个矩阵是对称的——只有 6 个独立分量。

```
         σ_xx   τ_xy   τ_zx
σ_ij  =  τ_xy   σ_yy   τ_yz
         τ_zx   τ_yz   σ_zz

其中：
  σ_xx, σ_yy, σ_zz = 正应力（垂直于面的力）
  τ_xy, τ_yz, τ_zx = 剪应力（平行于面的力）

对称性：τ_xy = τ_yx, τ_yz = τ_zy, τ_zx = τ_xz
→ 总共 6 个独立分量
```

### 7. 正应力与剪应力：物理图像

```
正应力（Normal Stress）：
    ┌──────────┐
    │          │
    │    ←→    │  σ_xx：沿 x 方向拉/压垂直于 x 的面
    │          │
    └──────────┘
    拉为正（+），压为负（-）

剪应力（Shear Stress）：
    ┌──────────┐
    │    →     │
    ├──────────┤  τ_xy：沿 y 方向推/拉垂直于 x 的面
    │    ←     │  （使材料发生剪切变形）
    └──────────┘
```

**正应力**改变体积（压缩或膨胀），**剪应力**改变形状（不改变体积）。

> **万神殿语境**：
> - 穹顶底部的 σ_θθ（环向正应力）≈ **正（拉）**——穹顶自重向外推，底部环向被撑开
> - 穹顶的 σ_φφ（子午向正应力）≈ **负（压）**——穹顶自重沿子午向向下传递
> - 穹顶内部的剪应力相对较小（主承力路径沿子午向和环向，这两个方向恰好是主应力方向）

### 8. 主应力：旋转到最简形式

剪应力的存在意味着你选择了一个「不方便」的坐标系。如果你**旋转坐标系**，总能找到一个方向，使得在这个新坐标系下所有剪应力为零。这时剩下的三个正应力就叫**主应力**（Principal Stresses）。

```
旋转坐标系前：                        旋转坐标系后：
  σ_xx  τ_xy  τ_xz                    σ₁   0    0
  τ_xy  σ_yy  τ_yz        →           0    σ₂   0
  τ_xz  τ_yz  σ_zz                    0    0    σ₃

按惯例：σ₁ ≥ σ₂ ≥ σ₃
```

**物理意义**：
- σ₁（第一主应力）= 该点受到的最大拉应力（如果为正）
- σ₃（第三主应力）= 该点受到的最大压应力（如果为负）
- σ₁ 的方向告诉我们材料「最容易被拉裂的方向」

> **万神殿语境**：判断穹顶是否会开裂，关键就看 σ₁ 是否超过了混凝土的抗拉强度 f_t = 0.08 MPa。如果某点的 σ₁ > 0.08 MPa，该点就判定为开裂。穹底环向受拉，所以 σ₁ ≈ σ_θθ，裂缝沿子午方向开展——这与历史实测完全吻合。

**ASCII 示意图：万神殿穹顶主应力方向**

```
                     Oculus (φ=0°)
                        ○
                       /|\
                      / | \
                     /  |  \      σ₁（第一主应力）
                    /   |   \     ↗ 环向
                   /    |    \
                  /     |     \    σ₃（第三主应力）
                 /      |      \   ↓ 子午向（压）
                /       |       \
               /  穹顶   |        \
              /         |         \
             /          |          \
            /           |           \
           /            |            \
          /             |             \
         /   σ₁最大处   |              \
        /   （环向拉）   |               \
       /________________|________________\
      鼓座            拱脚(φ=90°)         鼓座
```

### 9. 应变是什么

应力和应变是「力」和「变形」的关系。应变 = 变形量 / 原始尺寸。

- **正应变** ε_xx：沿 x 方向的伸长/缩短比例
- **剪应变** γ_xy：直角的变化量（以弧度计）

应变也是一个对称张量，同样有 6 个独立分量。在弹性范围内，应力与应变成正比（广义胡克定律）。

### 10. 万神殿穹顶的应力分布预期

基于物理直觉和已知文献，我们对穹顶在自重下的应力分布有以下预期：

| 位置 | σ_θθ（环向） | σ_φφ（子午向） | 物理解释 |
|---|---|---|---|
| **Oculus 附近** | **负（压）** | **负（压）** | Oculus 周围的环像一根被从外面勒紧的腰带——环向压缩 |
| **穹顶中上部** | **接近零** | **负（压）** | 环向从中性面附近逐渐从压过渡到拉 |
| **穹底（拱脚附近）** | **正（拉）** ✅ | **负（压）** | 穹顶向外推，环向被撑开——这是穹顶开裂的力学根源 |
| **鼓座墙体** | — | **负（压）** | 承受穹顶下传的总重量 |

> **最重要的定性判断**：「穹底环向受拉」是一个牢不可破的物理预期。如果你的 FEM 结果显示穹底环向受压，**那一定是模型出了问题**（边界条件、荷载方向、或几何建模有误）。

## 第三部分：有限元方法核心思想

### 11. 离散化：把穹顶切成几万个小四面体

整个 FEM 的第一个核心思想：**把连续的物体切成有限个小块。**

```
连续穹顶                    离散后的穹顶
    ╱╲                          ╱╲
   ╱  ╲                        ╱▚▚╲
  ╱    ╲                      ╱▚▚▚▚╲
 ╱      ╲         →          ╱▚▚▚▚▚▚╲
╱        ╲                  ╱▚▚▚▚▚▚▚▚╲
──────────                ──────────────
                         每个 ▚ 是一个四面体
```

在数学上，连续的穹顶有无限多个点，每个点有无限小的物质。我们无法对无限多个点做计算。所以我们把它切成 **N 个小四面体**（约 5 万 ~ 80 万个），每个四面体有 4 个顶点（节点）。

- 每个节点有 3 个未知位移分量（x, y, z 方向各一个）
- 总自由度 ≈ 3 × 节点数
- 一个 20 万节点的模型 → 60 万未知数 → 需要解一个 60 万 × 60 万的方程组

**为什么用四面体而不是六面体？** 四面体可以填充任何复杂形状（特别是藻井凹角和鼓座壁龛这种不规则几何），而六面体在复杂几何中很难生成。Gmsh 默认使用四面体自动划分。

### 12. 单元内插值：用简单函数近似位移

第二个核心思想：**在每个小四面体内部，用简单的多项式函数来近似真实的位移场。**

```
真实位移（复杂曲线）：       近似位移（分段线性）：
    ~~~~~                          ╱╲  ╱╲
   ╱     ╲                        ╱  ╲╱  ╲
  ╱       ╲           →          ╱    ╲    ╲
 ╱         ╲                    ╱      ╲      ╲
```

在每个四面体内部，我们假设位移是坐标的线性函数：

```
u(x, y, z) = a₁ + b₁x + c₁y + d₁z   （x 方向位移）
v(x, y, z) = a₂ + b₂x + c₂y + d₂z   （y 方向位移）
w(x, y, z) = a₃ + b₃x + c₃y + d₃z   （z 方向位移）
```

四个顶点的位移已知 → 12 个方程 → 解出 12 个系数 (a, b, c, d) → 单元内任意点的位移都可算。

**关键权衡**：
- 🟢 **线性单元**（1 阶）：每个四面体 4 个节点，位移线性分布，计算快但精度低——在曲率大的地方容易「太硬」
- 🟡 **二次单元**（2 阶）：每个四面体 10 个节点（4 顶点 + 6 边中点），位移二次分布，计算慢但精度高——本项目采用此方案

> **万神殿语境**：穹顶是弯曲的薄壳，如果只用一阶单元，每个四面体内部是平的（线性），要很多单元才能逼近曲面。二阶单元可以「弯曲」，用更少的单元就能达到相同精度。本项目的基准模型使用二阶四面体（CG2），预计 20-50 万单元。

### 13. 组装求解：从局部到全局

第三个核心思想：**把几万个四面体的「微弹簧」组装成一个巨大的全局方程组。**

每个四面体有自己的局部刚度矩阵（10×10 或 4×4，取决于阶次）——相当于一个小弹簧系统。组装的过程就是把这些小矩阵「拼接」成全局刚度矩阵。

```
单元1 的刚度：          单元2 的刚度：         组装后的全局刚度：
[k₁₁  k₁₂]             [k₂₂  k₂₃]            [k₁₁  k₁₂    0  ]
[k₂₁  k₂₂]      +      [k₃₂  k₃₃]     =      [k₂₁  k₂₂+k₂₂' k₂₃]
                                               [  0    k₃₂   k₃₃]

节点2 同时属于单元1 和单元2 → 它的刚度是两个单元的贡献之和
```

组装完成后得到：

```
K · u = f

其中：
  K = 全局刚度矩阵（N×N 的稀疏矩阵，N ≈ 几十万）
  u = 所有节点的位移向量（我们想求的未知数）
  f = 所有节点的外力向量（自重、干缩等）
```

这是一组**线性方程组**。求解它 → 得到所有节点的位移 → 通过位移计算每个单元的应变 → 通过本构关系计算应力。

> **万神殿语境**：本项目的全局刚度矩阵大约是一个 20 万 × 20 万的稀疏矩阵（99.9% 的元素为零）。你不会手动求解——FEniCSx 调用 PETSc + MUMPS 来求解。

### 14. 什么是刚度矩阵

刚度矩阵 K 是结构的「弹簧系统描述」。K 的每一个元素 K_ij 的物理含义是：

> **「在节点 j 上施加单位位移，需要在节点 i 上施加多大的力来维持平衡。」**

如果 K 是**奇异的**（行列式为零）→ 方程组无唯一解 → 结构可以发生**刚体位移**（整体平移或旋转）→ 说明**边界条件不足**。

> **最常见的新手死法**：忘了施加边界条件 → 刚度矩阵奇异 → 求解器报错 `KSP_DIVERGED` 或 `NaN detected`。这个错误在 FEM 调试中占 50% 以上。

## 第四部分：弱形式与本构模型

### 15. 强形式 vs 弱形式

#### 15.1 强形式

原始的弹性力学偏微分方程（以平衡方程为例）：

```
∂σ_xx/∂x + ∂τ_xy/∂y + ∂τ_xz/∂z + f_x = 0
∂τ_xy/∂x + ∂σ_yy/∂y + ∂τ_yz/∂z + f_y = 0
∂τ_xz/∂x + ∂τ_yz/∂y + ∂σ_zz/∂z + f_z = 0
```

这组方程要求**每一个无穷小的点**都精确满足平衡。这在数学上是精确的，但计算机无法直接处理——计算机只能处理有限个点上的有限个变量。

#### 15.2 弱形式

**弱形式**的「弱」不是「弱化」的意思，而是「放宽要求」。做法是：

1. 把平衡方程乘以一个任意的「测试函数」v(x)
2. 在整个域上积分
3. 用分部积分把导数从应力「转移」到测试函数上

结果是一组积分方程：「对于任意测试函数 v，这个积分等式成立。」

```
∫_Ω σ : ε(v) dΩ = ∫_Ω f · v dΩ + ∫_∂Ω t · v dS

其中：
  Ω = 整个穹顶的体积域
  ∂Ω = 穹顶的边界面
  σ = 应力张量
  ε(v) = 由测试函数 v 导出的「虚应变」
  f = 体积力（自重）
  t = 面力（边界上的外力）
```

**白话类比**：

| | 强形式 | 弱形式 |
|---|---|---|
| **类比** | 监考老师检查每个学生每道题都对了 | 老师只看全班平均分是否达标 |
| **数学** | 每个点都必须满足 PDE | 积分意义上满足 PDE |
| **物理** | 每个微元都必须精确平衡 | 整体能量最小化（虚功原理） |
| **计算机** | 无法直接求解 | 可以通过有限元离散后求解 |

> **关键理解**：弱形式不是近似！对于线弹性问题，强形式和弱形式在数学上是等价的。只是弱形式「更容易被计算机理解」。

#### 15.3 在 FEniCSx 中的体现

在 FEniCSx 中，你不需要手写完整的弱形式推导。你用 **UFL（Unified Form Language）** 来描述：

```python
import ufl

# 定义位移试函数 u 和测试函数 v
u = ufl.TrialFunction(V)
v = ufl.TestFunction(V)

# 应变张量（由位移 u 导出）
def epsilon(u):
    return ufl.sym(ufl.grad(u))

# 应力张量（线弹性本构）
def sigma(u):
    return lam * ufl.div(u) * ufl.Identity(3) + 2 * mu * epsilon(u)

# 弱形式的左边（内部虚功）
a = ufl.inner(sigma(u), epsilon(v)) * ufl.dx

# 弱形式的右边（外力虚功）：自重 + 面力
f = rho * g  # 自重（体积力）
L = ufl.dot(f, v) * ufl.dx   # 暂时只考虑自重
```

这段代码就是在用 Python 语法表达：
> 「对于任意测试函数 v，内力做的虚功 = 外力做的虚功」

### 16. 线弹性本构模型

**本构模型** = 应力与应变之间的关系。

#### 16.1 广义胡克定律（三维）

在一维中：σ = Eε。在三维中，由于泊松效应，三个方向互相影响：

```
σ_xx = E/((1+ν)(1-2ν)) × [(1-ν)ε_xx + ν(ε_yy + ε_zz)]
σ_yy = E/((1+ν)(1-2ν)) × [(1-ν)ε_yy + ν(ε_xx + ε_zz)]
σ_zz = E/((1+ν)(1-2ν)) × [(1-ν)ε_zz + ν(ε_xx + ε_yy)]

τ_xy = G × γ_xy    （G = E / (2(1+ν)) 是剪切模量）
τ_yz = G × γ_yz
τ_zx = G × γ_zx
```

#### 16.2 Lamé 常数

在 FEniCSx 中，通常用 Lamé 常数 λ 和 μ 来表示本构关系：

```
λ = Eν / ((1+ν)(1-2ν))    第一 Lamé 常数
μ = E / (2(1+ν))          第二 Lamé 常数 = 剪切模量 G

对于本项目：
  E = 14.8 GPa = 14.8 × 10⁹ Pa
  ν = 0.2
  λ = 14.8e9 × 0.2 / (1.2 × 0.6) ≈ 4.11 GPa
  μ = 14.8e9 / (2 × 1.2) ≈ 6.17 GPa
```

#### 16.3 线弹性的适用范围

线弹性假设在小变形下成立（应变 < 0.1%）。万神殿穹顶在正常工作状态下的应变确实很小（弹性模量高、工作应力在 MPa 级），所以线弹性是一个很好的起点。但是，当混凝土开裂后，线弹性不再适用——受拉区的刚度应该退化。

### 17. 无拉伸混凝土模型（进阶）

#### 17.1 为什么需要这个模型

古罗马混凝土的抗拉强度极低（f_t = 0.08 MPa）。当某处的第一主应力 σ₁ 超过 f_t 时，材料开裂。开裂后，裂缝面不能再传递拉应力——该方向的刚度退化为零。

线弹性模型会继续让开裂的区域承担拉应力，这会导致：
- 拉应力被高估
- 裂缝区域被低估
- 应力重分布效应被忽略

#### 17.2 两种处理方式

**方式一（🟢 线弹性后处理判定）**：
- 用线弹性模型求解
- 求解完成后，在后处理阶段标记 σ₁ > f_t 的区域为「潜在开裂区」
- 优点：简单、稳定、计算快
- 缺点：未考虑开裂后的应力重分布

**方式二（🔴 非线性无拉伸本构）**：
- 在求解过程中，当某处 σ₁ > f_t 时，将该方向刚度设为接近零
- 求解器自动迭代，已开裂区域的应力转移到相邻未开裂区域
- 优点：物理上更真实
- 缺点：求解困难，收敛性差（牛顿法容易震荡）

> **本项目的策略**：基础目标阶段使用方式一（线弹性后处理）。进阶阶段尝试方式二。

### 18. 边界条件为什么至关重要

边界条件 = 告诉求解器「结构的哪些部分被固定住了」。

#### 18.1 物理直觉

想象一根筷子：
- 如果两端都悬空 → 筷子掉下去（刚体位移）→ 无解
- 如果一端固定 → 筷子被「钉」住了 → 有确定解
- 如果两端都固定 → 也是确定解，但变形模式完全不同

**边界条件一变，结果天差地别。** 这是 FEM 中最敏感的因素。

#### 18.2 本项目的边界条件

| 算例 | 边界位置 | 约束类型 | 含义 |
|---|---|---|---|
| **C0（球壳基准）** | 球壳底部 | **完全固支**（u=0） | 刚性基础，不参与变形 |
| **C1（纯穹顶）** | 拱脚面 | **完全固支**（u=0） | 与 V1.0 假设一致——刚性拱脚 |
| **C2（穹顶+鼓座粘结）** | 基座底部 | 完全固支（u=0） | 基座在地面上，固定不动 |
| | 穹顶-鼓座界面 | **位移连续**（绑定） | 穹顶和鼓座紧密粘结，不滑动不分离 |

**ASCII 示意图**：

```
C1（纯穹顶+刚性拱脚）：           C2（穹顶+鼓座耦合）：
      ╱╲                              ╱╲
     ╱  ╲                            ╱  ╲
    ╱ 穹 ╲                          ╱ 穹 ╲
   ╱  顶  ╲                        ╱  顶  ╲
  ╱        ╲                      ╱        ╲
 ╱──────────╲ ← 拱脚固支           ╱──────────╲ ← 穹顶-鼓座界面绑定
              (u=0)               │   鼓 座    │
                                 │            │
                                 │   基 座    │
                                 └────────────┘ ← 底部固支 (u=0)
```

**为什么 C1 → C2 结果的差异巨大？**

C1 中拱脚刚性固支，意味着穹底的环向变形被完全锁死。现实中，鼓座是可以略微变形的——穹顶向外推时，鼓座会「让」一点点。这个「让」虽然微小（可能零点几毫米），但能显著释放环向拉应力。

> **所以**：C1 的拉应力偏高（保守估计），C2 更接近真实。这就是为什么 V1.0（一维+刚性拱脚）的应力被高估了 ~3.5 倍。

## 第五部分：本项目专论

### 19. 穹顶受力的力学逻辑链

让我们把整个力学逻辑串起来，从原因到结果：

```
1. 材料 + 重力
   古罗马混凝土密度 ~1350-2100 kg/m³ × 重力加速度 9.81 m/s²
   → 自重荷载（体积力）

2. 几何形态
   半球壳 + 五层藻井 + 8.95m 直径 Oculus
   → 主要承力路径：子午方向（拱效应）+ 环向（环箍效应）

3. 自重作用下的变形趋势
   穹顶在自重下「想」往下塌、往外摊
   → 穹底向外位移（径向）
   → 穹底环向被拉伸（因为穹顶是一个闭合环，向外位移 = 环向周长增加）

4. 环向拉应力
   底部环向被拉伸 → σ_θθ > 0（拉应力）
   顶部的「腰带」被勒紧 → σ_θθ < 0（压应力）

5. 开裂
   底部 σ_θθ > f_t = 0.08 MPa
   → 混凝土开裂
   → 裂缝沿子午方向开展（垂直于环向拉应力）
   → 裂缝从底部向上延伸到 ~57° 子午角

6. 鼓座的约束效应
   鼓座参与变形 → 穹底约束减弱 → 环向拉应力降低
   → 推力部分由鼓座墙体承担 → 拱脚水平推力减少
```

每一步都有明确的物理机制。这个逻辑链是检验 FEM 结果合理性的「定性标尺」——任何一步与 FEM 结果矛盾，都应该引起警觉。

### 20. 为什么三维 FEM 比一维薄膜解更准确

V1.0 的一维模型做了几个重要简化：

| 简化 | V1.0 做了什么 | V2.0 改进 |
|---|---|---|
| **忽略弯曲刚度** | 薄膜假设：穹顶只有膜应力，不抗弯 | 三维实体单元自动包含弯曲刚度 |
| **忽略厚度方向应力** | 只有 σ_θθ 和 σ_φφ 两个分量 | 完整 6 分量应力张量 |
| **刚性拱脚** | 拱脚位移 = 0 | 鼓座参与变形，弹性约束 |
| **忽略剪切变形** | 没有 τ 分量 | 剪应力自然包含 |
| **等效刚度假设** | 藻井效应用等效刚度折减 | 藻井几何精确建模，局部应力集中自然出现 |

**一维薄膜解对绝对值的系统性高估**：薄膜假设忽略了弯曲刚度 → 变形被低估 → 应力被高估。加上刚性拱脚假设 → 约束过强 → 应力进一步高估。综合导致 V1.0 的薄膜解绝对值比 FEM 文献值高 ~3.5 倍。

但这个高估是**系统性的**——分布形态、定性趋势仍然正确。这就是为什么 V1.0 的「藻井减重 8.09%」和「JCIR = B 恒等式」仍然有价值：它们是相对量或恒等关系，对绝对值的系统偏差不敏感。

## 附录：关键公式速查

### A. 线弹性本构（Lamé 形式）

```
σ = λ·tr(ε)·I + 2μ·ε

其中：
  σ = 应力张量 (3×3)
  ε = 应变张量 (3×3)
  I = 单位矩阵
  tr(ε) = ε_xx + ε_yy + ε_zz（体积应变）
  λ = Eν / ((1+ν)(1-2ν))    （第一 Lamé 常数）
  μ = E / (2(1+ν))          （第二 Lamé 常数 = 剪切模量 G）
```

### B. 广义胡克定律（矩阵形式，Voigt 记法）

```
[σ_xx]   [λ+2μ   λ     λ    0  0  0] [ε_xx]
[σ_yy]   [  λ  λ+2μ    λ    0  0  0] [ε_yy]
[σ_zz] = [  λ    λ   λ+2μ   0  0  0] [ε_zz]
[τ_xy]   [  0    0     0    μ  0  0] [γ_xy]
[τ_yz]   [  0    0     0    0  μ  0] [γ_yz]
[τ_zx]   [  0    0     0    0  0  μ] [γ_zx]
```

### C. 应变-位移关系（小变形）

```
ε_ij = ½(∂u_i/∂x_j + ∂u_j/∂x_i)

其中 u_i 是 i 方向的位移分量
```

### D. 主应力计算

对于 3×3 的应力张量 σ，主应力是其特征值：

```
det(σ - σI) = 0

三个根 σ₁ ≥ σ₂ ≥ σ₃ 即为主应力
```

### E. 开裂判据（本项目）

```
开裂条件：σ₁ > f_t = 0.08 MPa

开裂方向：垂直于 σ₁ 的方向
（在穹底，σ₁ ≈ σ_θθ，所以裂缝沿子午向）
```
