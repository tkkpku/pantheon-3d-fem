## 1. 弹性力学研究什么

### 1.1 一句话

弹性力学回答：**一块固体，外面给它力和约束，它内部每一点的应力是多少、位移是多少、变形是多少。**

### 1.2 三大方程总览（先背这张表）

| | 方程 | 个数 | 管什么 | 出现 E 吗 |
|---|---|---|---|---|
| 平衡方程 | σ_ij,j + b_i = 0 | 3 | 力要平衡 | 否 |
| 几何方程 | ε_ij = ½(u_i,j + u_j,i) | 6 | 变形要自洽 | 否 |
| 本构方程 | σ_ij = λ ε_kk δ_ij + 2μ ε_ij | 6 | 材料说了算 | 是，只有它 |
| 合计 | | 15 个方程 | 未知量：σ(6) + ε(6) + u(3) = 15 个 | 恰好定解 |

**比喻**：给一个人量体裁衣（物体受力变形）——「力要平衡」是体重秤先归零（人不许飘）；「变形要自洽」是布料裁剪按人体曲线（相邻布料不能互相打架）；「材料说了算」是同样扯一下，棉布和牛仔布的伸长完全不同。

### 1.3 万神殿的三大方程各在哪

- 平衡方程 → 代码第 75–76 行的弱形式 a(u,v)=L(v)（虚功原理版平衡）
- 几何方程 → 代码第 69–70 行 epsilon(w) = ufl.sym(ufl.grad(w))
- 本构方程 → 代码第 55–58、72–73 行（λ、μ 换算 + sigma() 函数）

## 2. 记号速成：下标、求和约定、δ 记号

> 这是「张量本构」的数学地基。不会这个，所有公式都像天书；会了这个，弹性力学公式短一半。

### 2.1 下标 = 方向标签

- 位置坐标：(x1, x2, x3) = (x, y, z)
- 位移：u_i，i∈{1,2,3}——u1 就是沿 x 的位移 u，u2=v，u3=w
- 应力：σ_ij 两个下标——**第一个下标 i = 作用在哪个面（面的法向），第二个下标 j = 力沿哪个方向**

**比喻**：σ_xy 读作「x 面上的 y 向应力」——想象骰子贴着 x 轴的那个面，上面有沿 y 方向搓的力。

### 2.2 爱因斯坦求和约定

**同一个下标出现两次 = 自动求和**（从 1 到 3）：

a_i b_i = a1 b1 + a2 b2 + a3 b3

### 2.3 逗号求导记号

σ_ij,j = ∂σ_i1/∂x1 + ∂σ_i2/∂x2 + ∂σ_i3/∂x3

### 2.4 Kronecker δ

δ_ij = 1（i=j），0（i≠j）

作用：单位矩阵的下标写法。δ_ij a_j = a_i（「替换下标器」）。

### 手算例 2.1

算 δ_ij δ_ij：对 i,j 双求和，只有 i=j 的 3 项贡献 1，所以 =3。δ_ij δ_ij = 3 这个结果后面算体积应变会用到。

## 3. 应力与应力张量（张量部分·上）

### 3.1 为什么应力是「张量」（9 个数）

一个点的应力不是一个数也不是一个向量——**切一个面有一个应力向量，而面可以朝任意方向切**，所以需要 9 个数（3×3 矩阵）。对角元 = 正应力（拉为正、压为负），非对角元 = 剪应力。

### 3.2 剪应力互等定理

对微元取矩平衡 → σ_ij = σ_ji → 矩阵对称 → **独立分量只剩 6 个**。这就是「15 个未知量」里应力只数 6 个的原因。

### 3.3 主应力 = 特征值（你昨天问过的）

在一个点转动坐标系，总存在一个方向，面上**没有剪应力只有正应力**——这三个正应力就是主应力 σ1 ≥ σ2 ≥ σ3，是应力矩阵的**特征值**：det(σ - σI) = 0。

**代码落点**：np.linalg.eigvalsh(sigma_nodes)——eigvalsh 专用于对称矩阵，返回**升序**特征值，所以 [:, -1] = σ1（最大）、[:, 0] = σ3（最小）。

**手算例 3.1**：σ = [[2,1],[1,2]]（MPa），特征方程 (2-σ)²-1=0 → 主应力 3, 1 MPa，特征向量方向即主方向（45°）。

## 4. 应变与应变张量（张量部分·下）

### 4.1 应变张量

ε_ij = ½(u_i,j + u_j,i)

- ε_11 = ∂u1/∂x1：x 方向**伸长率**（拉 1%，就是 0.01）
- ε_12 = ½(∂u1/∂x2 + ∂u2/∂x1)：**张量剪应变** = 工程剪应变 γ12 的一半

### 4.2 ½ 的来历：转动的故事（必懂）

**位移梯度的反对称部分是刚体转动，不产生任何变形。**

小变形下任意位移梯度可分解：u_i,j = ½(u_i,j + u_j,i)（对称，真变形）+ ½(u_i,j - u_j,i)（反对称，纯转动）。

**手算例 4.1**：纯转动 u = (-ωy, ωx)。代入：ε11 = ε22 = 0，ε12 = ½(-ω+ω) = 0——应变全零。**如果把 ½ 丢掉**，纯转动会算出假应变——这就是 ½ 存在的全部理由。

**代码落点**：ufl.sym(ufl.grad(w)) 的 sym 就是取对称部分（自动带上 ½）。

### 4.3 体积应变

ε_kk = ε11 + ε22 + ε33 = ∇·u

（用 §2 手算例：δ_ij ε_ij = ε_kk）——本构方程里 λε_kk 的那一项就是它。

## 5. 平衡方程（管「力」）

σ_ij,j + b_i = 0

### 5.1 推导（微元体受力，x 方向为例）

取微元 dx dy dz，x 方向把所有力加起来（面力来自相邻微元挤压，体力 b 来自重力）：

(σ11 + ∂σ11/∂x1 · dx)·dy·dz − σ11·dy·dz + (σ21 + ∂σ21/∂x2 · dy)·dx·dz − σ21·dx·dz + (σ31 + ∂σ31/∂x3 · dz)·dx·dy − σ31·dx·dy + b1·dx·dy·dz = 0

同除 dx dy dz：

∂σ11/∂x1 + ∂σ21/∂x2 + ∂σ31/∂x3 + b1 = 0

三个方向三兄弟，写成张量式就是 σ_ij,j + b_i = 0。

**土话**：骰子六个面上所有力 + 自身重量，每个方向加起来必须 = 0，否则它飞出去。

### 5.2 关键观察：E 在哪？

**不在。** 平衡方程只有应力、坐标、体力——材料软硬完全不掺和。这就是「σ 与 E 无关」的第一块拼图。

### 5.3 边界条件（力边界）

给面力的表面：σ_ij n_j = t̄_i（n 是表面外法向）。万神殿 C1 的边界是**纯位移边界**（拱脚固支），力边界没用到——这正是「应力场与 E 无关」成立的前提之一。

## 6. 几何方程（管「变形」）

ε_ij = ½(u_i,j + u_j,i)

### 6.1 物理意义

应变是「相邻两点的位移差」的度量：

- 正应变：ε11 = ∂u1/∂x1——沿 x 走一小步，位移变了多少
- 剪应变：ε12——沿 x 的位移随 y 变化 + 沿 y 的位移随 x 变化（方块变菱形）

**土话**：每个点挪多少（u）→ 相邻点挪得不一样 → 伸长和歪斜（ε）。

### 6.2 关键观察：E 在哪？

**也不在。** 几何关系只描述「怎么挪→怎么变形」，与材料无关（橡皮和钢球用同一套几何方程）。

### 6.3 协调方程（提一句）

六个应变由三个位移导出 → 它们之间不独立，存在相容条件（圣维南协调方程）。有限元位移法**自动满足**（先假设位移再求应变），工程上不显式处理——知道有这么回事即可。

## 7. 本构方程（管「材料」）——张量本构 · 核心

σ_ij = λ ε_kk δ_ij + 2μ ε_ij

### 7.1 这是什么

**各向同性线弹性胡克定律的 Lamé 形式**：应力 = 体积变化贡献（λ 项）+ 形状变化贡献（2μ 项）。

两个 Lamé 常数与工程常数换算：

μ = E / (2(1+ν))，λ = Eν / ((1+ν)(1-2ν))，K = λ + 2μ/3 = E / (3(1-2ν))

反向：E = μ(3λ+2μ)/(λ+μ)，ν = λ/(2(λ+μ))。

| 常数 | 符号 | 物理含义 | 混凝土量级 |
|---|---|---|---|
| 杨氏模量 | E | 拉压刚度（软硬） | 14.8 GPa（Masi 2018 新参数） |
| 泊松比 | ν | 拉长时横向收缩比例 | 0.2 |
| 剪切模量 | μ (G) | 抗「搓」 | 约 E/2.4 |
| Lamé 第一常数 | λ | 数学配角（体积刚度搭档） | 凑数用 |
| 体积模量 | K | 抗均匀压缩 | E/(3(1-2ν)) |

### 7.2 展开看（把公式摊平）

六个分量各写一条（ε_kk = ε11+ε22+ε33）：

σ11 = λ(ε11+ε22+ε33) + 2μ ε11
σ12 = 2μ ε12

**观察**：剪应力只跟剪应变挂钩（系数 2μ），正应力互相牵连（λ 项让三个方向耦合）——**拉一根杆子，它横着会缩**（泊松效应），就藏在这个耦合里。

### 7.3 手算例：单轴拉伸反推泊松效应（必算）

设只有 σ11 = E ε11 ≠ 0，其余应力为 0。由 σ22 = 0：

λ ε_kk + 2μ ε22 = 0

解出 ε22 = −ν ε11（提示：把 ε_kk 写全，用 μ、λ 与 E、ν 的换算消元）。**算出来「横缩比例 = 泊松比」就过关了**，这是本构方程最重要的体检。

### 7.4 四个核心假设（何时失效）

1. **线弹性**：应力应变成比例（卸载回原样）——混凝土开裂后失效；
2. **小变形**：用变形前坐标——大转动失效；
3. **各向同性**：各方向性质一样——木纹、纤维混凝土失效；
4. **均匀性**：每点材料一样——万神殿分层密度是「分块均匀」，每块内仍成立。

**万神殿落点**：σ1 < 0.08 MPa 抗拉强度 → 线弹性不开裂 → 本构成立；若 C2+ 出现 σ1 > 0.08，就得换无拉伸/损伤本构（文档5 第 10 章）。

## 8. 三大方程怎么拼成一套题：定解与位移法

### 8.1 对账（再背一遍）

未知量：σ 6 个 + ε 6 个 + u 3 个 = 15；方程：平衡 3 + 几何 6 + 本构 6 = 15。**封闭。**

### 8.2 位移法消元（FEM 走的路）

① 几何方程代进本构 → ② 本构代进平衡 → 只剩位移的方程（**Navier 方程**）：

μ u_i,jj + (λ+μ) u_j,ji + b_i = 0

求出一个位移场 u，应变、应力全部跟着定——**这就是为什么 FEniCSx 只让你提供 u 的函数空间和弱形式**。

## 9. 从平衡方程到弱形式：虚功原理完整推导

> 目标：解释代码里 a(u,v)=L(v) 到底是什么的什么。

### 9.1 推导（四步，一步不跳）

**第 1 步**：平衡方程 σ_ij,j + b_i = 0 两边乘任意虚位移 v_i，在全域积分：

∫ σ_ij,j v_i dΩ + ∫ b_i v_i dΩ = 0

**第 2 步**：第一项用乘积求导法则拆开（「分部积分」的张量版）：

σ_ij,j v_i = (σ_ij v_i),j − σ_ij v_i,j

**第 3 步**：全散度项用高斯散度定理变成**边界积分**：

∫ (σ_ij v_i),j dΩ = ∫ σ_ij n_j v_i dS = ∫ t̄_i v_i dS

（在给面力的边界上 σ_ij n_j = t̄_i；在固支边界上虚位移 v_i = 0，此项为 0——万神殿 C1 全是固支，**这一整项直接消失**）

**第 4 步**：σ_ij v_i,j = σ_ij ε_ij(v)——因为 σ 对称，v 的梯度里反对称（转动）部分与 σ 点积为 0，只剩对称部分（应变）。

合起来：

∫ σ(u):ε(v) dΩ = ∫ b·v dΩ + ∫ t̄·v dS

**这就是 a(u,v) = L(v)**：a = 内力虚功，L = 外力虚功（体力 + 面力）。虚功原理 = 平衡方程的积分形式。

### 9.2 代码对号入座

| 代码 | 数学 |
|---|---|
| a = ufl.inner(sigma(u), epsilon(v)) * ufl.dx（75 行） | ∫ σ(u):ε(v) dΩ 内力虚功 |
| L = ufl.dot(b, v) * ufl.dx（76 行） | ∫ b·v dΩ 体力虚功（面力项 = 0） |
| b = (0,0,-rho*g)（63 行） | 体力 b = (0,0,−ρg) |
| 固支 BC（47–52 行） | 虚位移边界条件 v=0 自动满足 |

**记法**：ufl.dx = 全域体积分 dΩ；ufl.ds = 边界面积分 dS（速查 A.10 有完整说明）。

## 10. 单元分析（遗留项 1）：FEniCSx 在黑箱里替你干的活

> 文档5 §1.1 说过：「对每个四面体算单元刚度矩阵」。这一节把这句话彻底展开。

### 10.1 三步流水线

连续问题 → ① 离散化 → ② 单元分析 → ③ 组装 → K u = f

### 10.2 第 ① 步：离散化（形函数 N）

把位移场写成**节点值 × 形函数**：

u^h(x) = Σ N_a(x) u_a（a 从 1 到 n）

- N_a：第 a 号节点的「影响范围」函数——在该节点 = 1，其余节点 = 0；
- u_a：待求的节点位移（有限个未知数！连续无限维 → 有限维，这就是「有限元」的有限）；
- 代码落点：("Lagrange", 2, (3,)) = 二阶拉格朗日形函数、矢量（3 分量）。四面体 P2 有 10 个节点 → 每单元 30 个位移自由度。

### 10.3 第 ② 步：单元分析（单刚矩阵）

对每个单元：

ε = B u^e ⇒ k^e = ∫ Bᵀ C B dΩ（在单元 Ω^e 上积分）

- B：应变-位移矩阵（形函数求梯度得来，把 u^e 映射成应变）；
- C：本构矩阵（§7 本构方程的 6×6 矩阵版——**张量本构在数值实现里的真身**）；
- k^e：单元刚度矩阵（30×30）；
- 积分用高斯数值积分（单元内取几个采样点加权求和——四面体 P2 用 4 点公式即可精确）。

**弹簧打底（文档3 第 2 章回顾）**：单根弹簧 k^e = k[[1,-1],[-1,1]]，物理 =「两端位移差 × 刚度 = 力」。四面体单元是它的三维升级版：BᵀCB 取代 k，位移差变成应变。

### 10.4 第 ③ 步：组装（全局刚度矩阵）

每个单元的 k^e 按节点编号「盖章」进全局 K（共享节点的单元在该节点行/列**相加**——力的叠加）。组装完：

K u = f

K（N×N 对称稀疏，N = 总自由度）、u（全节点位移）、f（荷载向量，自重装进来）。

### 10.5 自由度对账（97 万怎么数出来的）

总 DOF = 节点数 × 3

- C1 当前 2.0m 网格：几万 DOF；
- 今天要跑的 1.0m 档：**97 万 DOF**；
- 8/31 目标 0.5m 档：约 500 万 DOF——K 是 500万×500万 稀疏矩阵（存起来几 GB，这就是要上北大 HPC 的原因）。

### 10.6 代码落点

petsc.LinearProblem(a, L, bcs=[bc], petsc_options={"ksp_type":"preonly","pc_type":"lu"})：

- FEniCSx 把 a, L 自动离散成 K, f（就是上面的三步流水线）；
- preonly+lu = 直接法（LU 分解解 Ku=f）——小规模最稳；97 万 DOF 时**必须换迭代法**（中继文档里的 cg+amg：共轭梯度 + 代数多重网格，内存 O(N) 才装得下）。

## 实战增补 · 三大方程在万神殿中的数值验证（2026-08）

> 本章基于《万神殿全解》成书卷六：三大方程不仅用于推导，还被项目**写进代码当自动校验**——这是弹性力学理论最直接的应用形态。

### 增补 1：静定结构的 E 无关性——平衡方程的直接推论

**理论**：线弹性自重下，静定结构的应力分布与弹性模量 E 无关（平衡方程 + 几何方程不涉 E；本构里的 E 只决定位移）。

**实战验证**（c1 求解器内置自动校验，8/15 实测）：

| E (GPa) | u_max (mm) | σ1 (MPa) | σ3 (MPa) | u×E 守恒 |
| --- | --- | --- | --- | --- |
| 1.0 | 12.4023 | 0.0666 | -0.7991 | 12.40 |
| 7.0 | 1.7718 | 0.0666 | -0.7991 | 12.40 |
| 14.8 | 0.8380 | 0.0666 | -0.7991 | 12.40 |

**比值 1.000**——「位移∝1/E、应力与 E 无关」的理论被三档扫描精确复现。**「把物理理论写进代码当自动校验」是弹性力学在工程中最值钱的用法**：一个比值偏离 1，立刻暴露单位错误、边界条件错误或本构错误。

### 增补 2：张量本构的 UFL 实现（三大方程 → 四行代码）

```python
def epsilon(w): return ufl.sym(ufl.grad(w))    # 几何方程：应变=对称梯度
def sigma(w):   return lam*ufl.tr(epsilon(w))*ufl.Identity(3) + 2*mu*epsilon(w)  # 本构
a = ufl.inner(sigma(u), epsilon(v)) * ufl.dx    # 虚功：内能变分
L = ufl.dot(b, v) * ufl.dx                       # 外虚功：自重
```

**逐行对应**：`ufl.sym(ufl.grad(w))` = ε=½(∇w+∇wᵀ)；`ufl.tr` = 迹 = 体积应变；`ufl.Identity(3)` = 单位张量 I；`ufl.dx` = 体积积分微元。**FEniCSx 的 UFL 语言让「写公式」和「写代码」合而为一**——三大方程学懂之后，求解器的核心只有这四行。

### 增补 3：干缩热类比的力学应变修正（本构方程的扩展）

混凝土干缩 = 自由应变 $\varepsilon_{free} = -\varepsilon_{sh}I$（收缩为负）。力学应变 = 总应变 − 自由应变：

$$\varepsilon_{mech} = \varepsilon_{tot} - \varepsilon_{free} = \varepsilon_{tot} + \varepsilon_{sh}I$$

**注意符号**：热膨胀模板是「减号」（ε_mech=ε_tot−αΔT·I），干缩是「加号」。项目 P-07 坑 = 这个符号写反，导致 sw 档应力被假性抬升 3Kε_sh≈0.182 MPa。**特殊情形自检**：两端固支杆 u=0 → σ=E(0+ε_sh)=+E·ε_sh 受拉 ✓——混凝土想缩被挡住，必然受拉，这个物理直觉就是符号的判官。

### 增补 4：量级检验——弹性力学直觉的数值化

检验清单第 1 层（项目决策「最硬一关」的姊妹检查）：

| 量 | 预期量级 | 危险信号 |
| --- | --- | --- |
| 最大位移 | mm 级 | m 级 → 单位错或 BC 缺 |
| 最大压应力 | 数 MPa | GPa 级 → 单位混乱 |
| 自重应力粗估 | σ ≈ mg/A ≈ 3 MPa（万神殿） | FEM 远大于此 → 有 bug |

**粗估公式本身**：$\sigma \approx \frac{mg}{2\pi R t} = \frac{2.46\times10^7\times9.81}{2\pi\times22\times5.9}\approx 3$ MPa——**弹性力学直觉 = 一张纸一支笔的量级估计**，跑任何算例前先手算一遍。
